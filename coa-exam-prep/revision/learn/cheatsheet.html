Last-hour cheat sheet

Gates
XOR = A'B + AB' (differ) · XNOR = A'B' + AB (equal) · NAND/NOR universal

Laws
A + AB = A · A(A + B) = A · A + A'B = A + B · AB + AB' = A
De Morgan: (AB)' = A' + B', (A + B)' = A'B'

Canonical / K-map
SOP: 1 → X, 0 → X' · POS: 0 → X, 1 → X'
Gray 00 01 11 10 · group 2ᵏ removes k variables · corners wrap

Universal gate counts
NAND: NOT 1, AND 2, OR 3, XOR 4 · NOR: NOT 1, OR 2, AND 3
SOP → NAND-NAND · POS → NOR-NOR

MUX / decoder
2:1 Y = S'I0 + SI1 · n selects → 2ⁿ inputs · decoder Dk = mk

Adders
HA: S = A⊕B, C = AB · FA: S = A⊕B⊕Cin, Cout = AB + Cin(A⊕B)
CLA: G = AB, P = A⊕B, C(i+1) = Gi + PiCi · ALU: add 0010, sub 0110

Numbers
2's range −2ⁿ⁻¹ … 2ⁿ⁻¹ − 1 · −x = invert + 1 · MSB weight −2ⁿ⁻¹
A − B = A + B' + 1 · V = C3 ⊕ C4 · CF = C4 · sign-extend = copy MSB

Latches / FFs
NOR SR: 11 forbidden · NAND SR: 00 forbidden · Q⁺ = S + R'Q
D latch: transparent when EN = 1 · D FF: Q⁺ = D at the edge
JK: Q⁺ = JQ' + K'Q · T: Q⁺ = T⊕Q · T = Q⊕Q⁺

Timing
T_c ≥ t_pcq + t_pd + t_setup · f = 1/T_c · hold: t_ccq + t_cd ≥ t_hold
ring oscillator T = 2·N·t_pd · 1/ns = 1 GHz

Counters / registers
FFs = ⌈log₂ N⌉ · ripple delay n·t_pd · bit k = f/2^(k+1)
T0 = 1, T1 = Q0, T2 = Q0Q1 · load enable Q⁺ = LD + L'Q
ring n, Johnson 2n, LFSR 2ⁿ − 1 · SIPO = UART RX, PISO = UART TX

Register file / FSM
32 × 32, 2 read + 1 write · address bits = log₂(regs)
read = MUX (combinational), write = decoder + WE (clocked)
Moore: output in circle; Mealy: on arrow · 1011: Mealy 4 states, Moore 5

Memory
SRAM 6T, no refresh, cache · DRAM 1T1C, refresh 64 ms, destructive read
refresh interval = 64 ms ÷ rows (8192 → 7.8 µs) · AMAT = hit + miss rate × penalty

Architecture
VN: one bus (bottleneck, Backus 1977) · Harvard: two buses · modern: split L1
bandwidth = bits/cycle × f ÷ 8 · RISC = fixed length + load/store · CPU time = IC × CPI × T

MIPS
R 6-5-5-5-5-6 · I 6-5-5-16 · J 6-26 · $zero 0, $v 2-3, $a 4-7, $t 8-15, $s 16-23, $sp 29, $ra 31
EA = rs + signext(imm) · branch = PC + 4 + imm×4 · jump = PC+4[31:28] ‖ addr ‖ 00
add 0x20, sub 0x22, slt 0x2A, lw 0x23, sw 0x2B, beq 4, addi 8, j 2
div: LO = quotient, HI = remainder · A[i] = base + 4i · jal: $ra = PC + 4

Datapath
R: RegDst 1, ALUSrc 0, MemtoReg 0, RegWrite 1, ALUOp 10
lw: 0, 1, 1, 1, MemRead 1, ALUOp 00 · sw: X, 1, X, 0, MemWrite 1, 00
beq: X, 0, X, 0, Branch 1, ALUOp 01 · PCSrc = Branch · Zero · lw = critical path

Pipeline
IF ID EX MEM WB · cycles = k + n − 1 · speedup → k · clock = slowest stage
stalls: 2 (no forwarding) / 0 (forwarding) / 1 (load-use)
