Unit 3 · Combinational Building Blocks

Is unit ki kahani: Unit 1–2 mein humne gates aur unhe chhota karna seekha. Par CPU ko "17 gates aise jodo" soch ke koi design nahi karta. Hum gates se kuch standard blocks banate hain: MUX (choose karna), DEMUX aur decoder (bhejna / line chunna), adder (jodna). Phir in blocks se ALU aur register file bante hain, jo Unit 13 ke CPU datapath ka dil hain. Unit 4 isi adder se subtraction aur two's complement karega.

3.1 Motivation: From Gates to Reusable Blocks

Pehle socho: Car factory har screw khud nahi dhaalti; catalogue se standard parts mangwaati hai jo pehle se tested hain. Chip designers bhi ek chhota catalogue use karte hain: MUX, decoder, adder, register (lagbhag 5 core types), jo lakhon baar repeat hote hain.
Definition: A combinational building block is a standard circuit (multiplexer, demultiplexer, decoder, adder) built from logic gates whose outputs depend only on its present inputs, and which is designed and verified once and reused throughout larger designs.
Mushkil shabd, aasaan matlab:
combinational
Output sirf abhi ke inputs pe depend karta hai; koi memory nahi. Input badla, output turant badla. (Ulta: sequential, jo yaad rakhta hai, Unit 5.)
datapath
CPU ke andar ka raasta jisme data chalta hai: register file → ALU → memory → wapas.
control point
Datapath ka ek MUX jiska select control unit set karta hai, jaise ALUSrc (ALU ko register de ya immediate).
verification
Check karna ki block sahi kaam karta hai. Ek baar test kiya, har copy pe bharosa.
Kaise kaam karta hai (blocks kyun aur kahan):
  1. Abstraction: "is input ko select karo" socho, "17 gates" nahi.
  2. Reuse: ek verified MUX har jagah lagao.
  3. Verification: block ek baar test, sab copies trusted.
  4. Scale: 2:1 MUX → 4:1 → 8:1 jodte jaao.
  5. CPU mein (Lab 3): ALU operand select (register ya immediate), PC update (PC + 4 ya branch target ya jump target), memory routing (ek bus, kai destinations).
Solved example (write the answer like this):

Explain, with two datapath examples, why multiplexers are called the fundamental routing block of a CPU. (3 marks)

  1. A MUX selects one of several sources and passes it to one output under a control (select) signal.
  2. ALUSrc MUX: chooses Read data 2 (register) or the sign-extended immediate as the ALU's second operand.
  3. PCSrc MUX: chooses PC + 4 or the branch target as the next PC. (MemtoReg MUX: ALU result or memory data for write-back.)

Answer: definition + any two datapath MUXes.

Galti mat karna: MUX kuch store nahi karta; wo railway switch hai, godown nahi. Storage register ka kaam hai.
Ek line mein: CPU = gates nahi, blocks (MUX, decoder, adder, register) ka jod; har block ek baar bana, baar baar use.

3.2 Multiplexers: 2:1, 4:1, and Cascading

Pehle socho: Railway junction pe kai patriyaan ek patri mein milti hain. Station master ka lever decide karta hai kaunsi train aage jaayegi. Lever badlo, doosri train nikal jaati hai; kuch ruka ya store nahi hota. MUX yahi hai: kai data inputs, ek output, aur select lines = lever.
Definition: A multiplexer (MUX) is a combinational circuit that selects one of 2ⁿ data inputs and passes it to a single output, according to the binary value on n select lines (a "data selector").
Mushkil shabd, aasaan matlab:
data inputs (I0, I1, I2)
Wo signals jinme se ek chuna jaayega (patriyaan).
select lines (S)
Control bits jo batate hain kaunsa input. Select ka binary value = chune gaye input ka number. S1S0 = 10 = 2 → I2.
why 2ⁿ inputs
n select bits se 2ⁿ alag numbers ban sakte hain (1 bit: 0, 1 → 2; 2 bits: 00 to 11 → 4; 3 bits → 8). Har number ek input ko point karta hai. Isliye 8:1 MUX ko 3 select lines.
cascading / tree
Chhote MUX jod ke bada MUX banana.
LUT (look-up table)
MUX jiske data inputs pe truth table ke 0/1 lage hain; select pe variables. FPGA inse bhara hota hai.
Kaise kaam karta hai:
  1. 2:1 MUX (inputs I0, I1; select S): S = 0 → Y = I0; S = 1 → Y = I1.
  2. Equation banao: "S = 0 aur I0" ya "S = 1 aur I1" → Y = S'·I0 + S·I1. Gates: 1 NOT, 2 AND, 1 OR.
  3. Check: I0 = 1, I1 = 0, S = 1 → Y = 0·1 + 1·0 = 0 (S = 1 ne I1 = 0 chuna) ✓.
  4. 4:1 MUX (I0 to I3, selects S1 S0): har input ke saath uske select number ka minterm AND karo: Y = S1'S0'·I0 + S1'S0·I1 + S1S0'·I2 + S1S0·I3.
  5. Kisi bhi time sirf ek minterm 1 hota hai, isliye sirf ek input output tak pahunchta hai.
  6. Cascading: 4:1 = teen 2:1 (pehle level pe S0, doosre pe S1). 8:1 = do 4:1 + ek 2:1 (S2 last). General: 2ⁿ:1 tree = 2ⁿ − 1 two-input MUXes.
  7. MUX se koi bhi function: variables select pe lagao, aur har data input pe truth table ka us row ka output (0 ya 1) lagao. Ek variable kam select pe ho to data inputs pe 0, 1, C ya C' lagte hain.

Formula: 2ⁿ:1 MUX → n select lines; 2:1: Y = S'I0 + SI1; 4:1: Y = S1'S0'I0 + S1'S0I1 + S1S0'I2 + S1S0I3
2ⁿ:1 from 2:1 MUXes: 2ⁿ − 1.
Verilog: assign y = sel ? b : a; (2:1 in one line).
Solved example 1 (class quiz):

(a) 2:1 MUX with A (I0) = 1, B (I1) = 0, S = 1: Y? (b) 4:1 MUX with S1 = 1, S0 = 0: which input? (c) Select lines of a 32:1 MUX? (d) 2:1 MUXes for a 16:1 MUX?

  1. (a) S = 1 → B chuna → Y = 0. (Equation: 0·1 + 1·0 = 0.)
  2. (b) S1S0 = 10 = 1×2 + 0 = 2 → I2.
  3. (c) 2ⁿ = 32 → 2⁵ = 32 → n = 5.
  4. (d) Tree: 16 inputs → 8 MUX (16 se 8), → 4 MUX (8 se 4), → 2 MUX (4 se 2), → 1 MUX (2 se 1). 8 + 4 + 2 + 1 = 15 = 16 − 1.

Answer: (a) 0; (b) I2; (c) 5; (d) 15.

Ek line mein: n select lines → 2ⁿ inputs mein se ek output pe; 4:1 = har input AND uska select-minterm, sab OR.

3.3a Demultiplexer (DEMUX)

Pehle socho: Post office ka sorting counter: ek parcel aata hai, aur pin code (select) dekh ke wo kai dabbon mein se ek mein daal diya jaata hai. Baaki dabbe khaali rehte hain. MUX ka bilkul ulta kaam: ek input, kai outputs.
Definition: A demultiplexer (DEMUX) is a combinational circuit that routes a single data input to one of 2ⁿ outputs selected by n select lines; the selected output equals the data input and all other outputs are 0.
Mushkil shabd, aasaan matlab:
data input (D)
Jo signal bhejna hai (parcel). D = 0 ya 1 kuch bhi ho sakta hai.
select lines
Address: batate hain kaunsa output. S1S0 = 11 → Y3.
route
Signal ko ek raaste pe bhejna. Chuna hua output = D, baaki = 0.
1:2, 1:4 naming
Course mein "1 input : outputs" likhte hain. 1:4 DEMUX = 1 data in, 4 out, 2 selects. "2:1 DEMUX" ulta padhta hai, mat likho.
Kaise kaam karta hai:
  1. 1:2 DEMUX (input D, select S): S = 0 → Y0 = D, Y1 = 0. S = 1 → Y0 = 0, Y1 = D.
  2. Equations: Y0 = S'·D, Y1 = S·D (1 NOT + 2 AND).
  3. 1:4 DEMUX (selects S1 S0): har output = D AND us output ke number ka select-minterm.
  4. Y0 = S1'S0'D, Y1 = S1'S0D, Y2 = S1S0'D, Y3 = S1S0D (4 three-input AND + 2 NOT).
  5. Agar D = 1 permanently laga do to chuna hua output 1 aur baaki 0: ye decoder ban jaata hai (3.3b).

Solved example 1:

A 1:4 DEMUX has D = 1, S1S0 = 10. Find Y0 to Y3. What if D = 0?

  1. S1S0 = 10 = 2 → chuna hua output Y2.
  2. Y2 = D = 1; Y0 = Y1 = Y3 = 0.
  3. D = 0: Y2 = D = 0, baaki bhi 0 → sab 0.

Answer: Y3 Y2 Y1 Y0 = 0100; with D = 0, 0000.

Solved example 2 (exam level):

Design a 1:4 DEMUX: equations, gate count, and explain how it becomes a 2-to-4 decoder.

  1. Har output = D · (select minterm): Y0 = S1'S0'D, Y1 = S1'S0D, Y2 = S1S0'D, Y3 = S1S0D.
  2. Gates: S1' aur S0' ke liye 2 NOT; har output ke liye ek 3-input AND → 4 AND.
  3. Check S1S0 = 01, D = 1: Y1 = 1·1·1 = 1; Y0 = 1·0·1 = 0; Y2 = 0; Y3 = 0 ✓.
  4. D ko "enable" naam do aur 1 pe rakho: Yk = mk (select ka minterm). Yahi 2-to-4 decoder hai; D = 0 → sab outputs 0 = decoder disabled.

Answer: 2 NOT + 4 three-input AND; decoder = DEMUX with data input tied to 1 (enable).

Galti mat karna: Na chune gaye outputs ko "purani value" ya "X" mat likho: wo 0 hote hain. Verilog mein isliye pehle sab outputs 0 kar dete hain (y = 4'b0000;) phir case.

Trick: MUX = "Many → 1" (funnel), DEMUX = "1 → Many" (sorter).

Ek line mein: DEMUX ek data input ko select ke number wale output pe bhejta hai; baaki outputs 0.

3.3b Decoder (n-to-2ⁿ)

Pehle socho: Hotel mein 4 rooms hain: 0, 1, 2, 3. Reception pe ek board hai jisme har room ki ek bulb hai. Receptionist room number binary mein daalta hai (do switch: 00, 01, 10, 11) aur sirf usi room ki bulb jalti hai, baaki teen band rehti hain. Ye kaam karne wala circuit hi decoder hai: ek "code" (binary number) leke batata hai "kaunsi line?".
Definition: A decoder is a combinational circuit that converts an n-bit binary input into 2ⁿ output lines, such that for each input combination exactly one output line is active (1) and all others are 0.
Mushkil shabd, aasaan matlab:
n-to-2ⁿ
n input bits, 2ⁿ output lines. 2 input bits → 2² = 4 outputs (2-to-4). 3 input bits → 2³ = 8 outputs (3-to-8).
one-hot
"Ek hi garam". Outputs ke group mein exactly ek bit 1 hai, baaki sab 0. Jaise 4 outputs D3 D2 D1 D0 = 0100: sirf D2 "hot" hai. 0110 one-hot NAHI hai (do 1 hain), 0000 bhi nahi (koi 1 nahi). Decoder ka output hamesha one-hot hota hai (jab enable = 1).
active / asserted
Output "ON" hai, yaani 1 (active-high decoder mein).
enable (E)
Master switch. E = 0 → saare outputs 0 (decoder band). E = 1 → normal kaam.
minterm
Ek AND term jisme har input exactly ek baar aata hai (seedha ya bar ke saath) aur jo sirf ek row mein 1 hota hai. A1'A0' sirf row 00 mein 1 hai, isliye ye minterm m0 hai.
Kaise kaam karta hai (2-to-4 decoder, inputs A1 A0):
  1. Input ek 2-bit number hai: A1A0 = 00, 01, 10 ya 11, yaani decimal 0, 1, 2 ya 3.
  2. Har number ke liye ek output line hai: D0, D1, D2, D3.
  3. Rule: input ka decimal value k hai to sirf Dk = 1.
  4. Har output ek AND gate hai jo sirf apne number pe 1 deta hai. D2 ko "10" chahiye, yaani A1 = 1 aur A0 = 0. Isliye D2 = A1 · A0' (A0 pe NOT lagao taaki A0 = 0 hone pe AND ko 1 mile).
  5. Isi tarah: D0 = A1'·A0', D1 = A1'·A0, D2 = A1·A0', D3 = A1·A0. Har output = ek minterm.
  6. Enable ho to har AND mein E bhi jod do: D2 = E·A1·A0'.

Table mein dekho: har row mein sirf ek 1 hai, aur woh diagonal pe chalta hai. Yahi "one-hot" hai.

Diagram kaise padhein: Left se A1, A0 aate hain; har ek ka NOT bhi banta hai (A1', A0'). Right mein 4 AND gates hain, har AND ko teen wire milte hain: E, A1 ya A1', A0 ya A0'. Trace karo A1A0 = 10, E = 1: sirf D2 wale AND ko (1, 1, A0' = 1) teeno 1 milte hain, to sirf D2 = 1.

Formula: n inputs → 2ⁿ outputs, Dk = mk (output k = minterm k).
Gates: 2ⁿ AND gates (each with n inputs, n + 1 with enable) + n NOT gates.
3-to-8: 8 AND gates of 3 inputs + 3 NOT gates.
Solved example 1 (direct):

A 3-to-8 decoder has inputs A2A1A0 = 101 and E = 1. Which output is 1? Write the output word D7 to D0.

  1. 101 ko decimal mein badlo: 1×4 + 0×2 + 1×1 = 4 + 0 + 1 = 5.
  2. Rule: sirf D5 = 1.
  3. D7 D6 D5 D4 D3 D2 D1 D0 likho, D5 ki jagah 1: 0 0 1 0 0 0 0 0.

Answer: D5 = 1; output = 0010 0000 (one-hot).

Solved example 2 (exam favourite):

Implement a full adder using a 3-to-8 decoder and OR gates.

  1. Full adder ke inputs A, B, Cin ko decoder ke A2, A1, A0 pe lagao. Ab decoder har row ka minterm khud bana deta hai.
  2. Sum = 1 jab 1s ki ginti odd ho: rows 001, 010, 100, 111 → decimal 1, 2, 4, 7. Isliye Sum = Σm(1, 2, 4, 7).
  3. Cout = 1 jab kam se kam do 1 hon: rows 011, 101, 110, 111 → 3, 5, 6, 7. Isliye Cout = Σm(3, 5, 6, 7).
  4. Ek 4-input OR gate lo: inputs D1, D2, D4, D7 → output Sum.
  5. Doosra 4-input OR: D3, D5, D6, D7 → output Cout.

Answer: Sum = D1 + D2 + D4 + D7; Cout = D3 + D5 + D6 + D7. (Any function = OR of the decoder outputs of its minterms.)

Galti mat karna: Decoder aur MUX ko mix mat karo. MUX data pass karta hai (many in → one out). Decoder data pass nahi karta, sirf batata hai "kaunsi line" (n in → 2ⁿ out, one-hot). DEMUX = decoder jiska enable hi data input hai.

Trick: "De-code = number padho, bulb jalao." Input ka decimal value = jalne wali bulb ka number.

Ek line mein: n-bit number in → 2ⁿ lines out → sirf us number wali line 1 (one-hot); har output ek minterm hai.

3.4 Half Adder Design

Pehle socho: Do single digits jodo: 7 + 5 = 12 → likho 2, carry 1. Binary mein bhi same: 1 + 1 = 10 (do) → likho 0, carry 1. Ek bit ke do numbers jodne wala sabse chhota circuit half adder hai. CPU ka har addition (PC + 4, address calculation, subtraction) adders se hota hai.
Definition: A half adder is a combinational circuit that adds two single bits A and B and produces a Sum bit and a Carry bit; Sum = A ⊕ B and Carry = A·B. It has no carry input.
Mushkil shabd, aasaan matlab:
Sum (S)
Jod ka right wala bit (jo isi column mein likha jaata hai). 1 + 1 = 10 → S = 0.
Carry (C)
Agle column mein jaane wala bit. 1 + 1 = 10 → C = 1.
carry-in (Cin)
Pichle column se aaya carry. Half adder mein ye input hai hi nahi, isliye "half".
Kaise kaam karta hai (truth table se derive karo):
  1. Chaaron cases jodo: 0 + 0 = 00, 0 + 1 = 01, 1 + 0 = 01, 1 + 1 = 10 (Carry Sum).
  2. Table banao (neeche).
  3. Sum column = 0, 1, 1, 0 → 1-rows 01 aur 10 → SOP: Sum = A'B + AB' = A ⊕ B (XOR ka pattern).
  4. Carry column = 0, 0, 0, 1 → sirf row 11 → Carry = A·B (AND ka pattern).
  5. Circuit: ek XOR + ek AND, dono ko A aur B milte hain.

Diagram kaise padhein: A aur B dono gates ko jaate hain (black dots = wire split). Upar XOR → Sum, neeche AND → Carry. Right mein truth table. Trace A = 1, B = 1: XOR = 0, AND = 1 → Carry Sum = 10.

Formula: Sum = A ⊕ B = A'B + AB' · Carry = A·B
Gates: 1 XOR + 1 AND. With 2-input NANDs only: 5 (4 for XOR, the first NAND (AB)' reused, 1 more NAND inverts it to AB).
Solved example 1:

Half adder inputs A = 1, B = 1. Write "Carry Sum".

  1. Sum = 1 ⊕ 1 = 0 (inputs same → 0).
  2. Carry = 1·1 = 1.
  3. Check: 1 + 1 = 2 = 10₂ ✓.

Answer: 10.

Solved example 2 (exam level):

Minimum number of 2-input NAND gates to build a half adder (Sum and Carry)?

  1. XOR from NANDs (2.5): G1 = (AB)', G2 = (A·G1)', G3 = (B·G1)', Sum = G4 = (G2·G3)' → 4 gates.
  2. Carry = AB = (G1)' → G1 already hai, bas ek NAND-inverter: G5 = NAND(G1, G1) = AB.
  3. Total = 4 + 1 = 5.
  4. Check A = 1, B = 1: G1 = 0, G2 = 1, G3 = 1, G4 = 0 (Sum), G5 = 1 (Carry) ✓.

Answer: 5 NAND gates.

Galti mat karna: Sum = A + B (OR) GALAT: 1 + 1 pe OR 1 deta hai par Sum 0 chahiye. Aur multi-bit addition ke bit 1 pe half adder nahi chalega: wahan teen bits (A1, B1, pichla carry) jodne hain. Example 11 + 01: bit 0 pe carry banta hai jo bit 1 mein jaana chahiye.
Ek line mein: Half adder: Sum = A ⊕ B, Carry = AB; carry-in nahi hai, isliye chain nahi ho sakta.

3.5 Full Adder Design (and Ripple-Carry Adder)

Pehle socho: Column addition mein har column mein teen cheezein judti hain: upar ka digit, neeche ka digit, aur pichle column ka carry. Binary mein bhi multi-bit addition ke liye har bit pe A, B aur Cin jodne padte hain. Ye full adder karta hai. n full adders ko line mein jodo to n-bit adder ban jaata hai.
Definition: A full adder adds three bits, A, B and a carry-in Cin, and produces Sum = A ⊕ B ⊕ Cin and carry-out Cout = AB + Cin(A ⊕ B). An n-bit ripple-carry adder (RCA) chains n full adders, the carry-out of each stage feeding the carry-in of the next.
Mushkil shabd, aasaan matlab:
parity (Sum)
Teen bits mein 1s ki ginti odd ho to Sum = 1. 1 + 1 + 1 = 3 = 11₂ → Sum 1.
majority (Cout)
Teen mein se kam se kam do 1 hon to Cout = 1 (voting).
ripple
Carry ek stage se agle mein lehar ki tarah chalta hai: bit 0 ka carry bit 1 mein, phir bit 2 mein.
propagation delay
Input aane ke baad output sahi hone mein laga time. Ek gate delay = ek gate paar karne ka time (Δ).
Kaise kaam karta hai (truth table se derive):
  1. 8 rows (3 inputs). Har row mein A + B + Cin jodo aur 2-bit answer Cout Sum likho.
  2. Sum = 1 rows: 001, 010, 100, 111 → Σm(1, 2, 4, 7). Cout = 1 rows: 011, 101, 110, 111 → Σm(3, 5, 6, 7).
  3. Sum ka K-map checkerboard (koi do 1 padosi nahi) → group nahi banta → Sum = A ⊕ B ⊕ Cin.
  4. Cout ka K-map: teen pairs, sab m7 ke saath: (3, 7) → B·Cin, (5, 7) → A·Cin, (6, 7) → A·B → Cout = AB + BCin + ACin.
  5. Do half adders wala form: HA1(A, B) → S1 = A ⊕ B, C1 = AB. HA2(S1, Cin) → Sum = S1 ⊕ Cin, C2 = S1·Cin. Cout = C1 + C2 = AB + Cin(A ⊕ B).
  6. C1 aur C2 kabhi saath mein 1 nahi (A = B = 1 ho to S1 = 0, to C2 = 0), isliye OR theek hai.

Diagram kaise padhein: Same circuit gate level: do XOR series mein (Sum), do AND (AB aur Cin·(A⊕B)) ek OR mein (Cout).

Diagram kaise padhein: FA0 right mein (LSB), FA3 left mein (MSB). Har FA ko upar se Ai, Bi milte hain, neeche Si nikalta hai. Carry right se left chalta hai: Cin = 0 → FA0 → C1 → FA1 → C2 → FA2 → C3 → FA3 → Cout. FA3 ka Sum tab tak sahi nahi jab tak C3 nahi aata.

Formula: Sum = A ⊕ B ⊕ Cin · Cout = AB + Cin(A ⊕ B) = AB + BCin + ACin
RCA worst-case delay = n × t(carry per stage); class model: 2 gate delays per stage → 2n gate delays (4-bit 8, 16-bit 32, 64-bit 128).
FA = 2 HA + 1 OR; n-bit RCA = n FAs = 2n HAs.
Solved example 1 (class quiz, trace):

A 4-bit RCA (Cin = 0) adds 0111 + 0001. Find the sum and Cout, showing every carry.

  1. Bit 0: A0 = 1, B0 = 1, Cin = 0 → 1 + 1 + 0 = 2 = 10₂ → S0 = 0, C1 = 1.
  2. Bit 1: A1 = 1, B1 = 0, C1 = 1 → 1 + 0 + 1 = 2 → S1 = 0, C2 = 1.
  3. Bit 2: A2 = 1, B2 = 0, C2 = 1 → 2 → S2 = 0, C3 = 1.
  4. Bit 3: A3 = 0, B3 = 0, C3 = 1 → 1 → S3 = 1, Cout = 0.
  5. Sum = S3 S2 S1 S0 = 1000. Check: 7 + 1 = 8 = 1000₂ ✓. Carry 3 stages tak ripple hua.

Answer: 1000, Cout = 0.

Solved example 2 (exam level, delay):

A 32-bit ripple-carry adder uses full adders whose carry path is 2 gate delays; one gate delay = 25 ps. (a) Worst-case carry delay? (b) Maximum clock frequency if this adder is the only logic between registers? (c) What limits its speed?

  1. (a) Gate delays = 2 × 32 = 64. Time = 64 × 25 ps = 1600 ps = 1.6 ns.
  2. (b) f = 1 / T = 1 / 1.6 ns = 0.625 GHz = 625 MHz.
  3. (c) Worst case (jaise saare 1s + 1, 4 bits mein 1111 + 0001) mein carry ko bit 0 se bit 31 tak har stage se guzarna padta hai; har stage pichle carry ka wait karta hai. Delay n ke saath linearly badhta hai.
  4. Fix: carry-lookahead adder (3.E1) jo carries parallel mein nikalta hai.

Answer: (a) 1.6 ns; (b) 625 MHz; (c) serial carry propagation, delay ∝ n.

Galti mat karna: Cout = C1 AND C2 likha to kabhi 1 nahi hoga (dono saath 1 nahi hote): OR chahiye. Cout = AB + Cin bhi galat (A = B = 0, Cin = 1 pe 1 de dega). Ripple-carry ko "fast" mat likhna: wo simple hai, fast nahi.

Trick: Sum = "odd hai to 1" (parity), Cout = "do ya zyada to 1" (majority). FA = "2 HA + 1 OR".

Ek line mein: Full adder teen bits jodta hai (Sum = A⊕B⊕Cin, Cout = majority); n FAs ki chain = RCA, delay 2n gate delays.

3.6 CPU Preview: ALU and Register File

Pehle socho: CPU ki table pe ek chhoti daraaz (register file: kuch fast slots jinme numbers rakhe hain) aur ek calculator (ALU) hai. Har instruction jaise add: daraaz se do numbers nikalo, calculator pe jodo, result wapas daraaz mein. Ye dono isi unit ke blocks (MUX, decoder, adder) se bante hain.
Definition: The ALU (Arithmetic Logic Unit) is the combinational unit of the CPU that performs arithmetic (add, subtract) and logic (AND, OR, compare) operations on two operands, selected by ALU control bits. The register file is a small, fast array of registers (32 × 32 bits in MIPS) with two read ports and one write port that supplies the ALU's operands and stores its results.
Mushkil shabd, aasaan matlab:
1-bit ALU slice
Ek bit ka ALU: AND gate, OR gate, full adder, aur ek MUX jo inme se ek result chunta hai. 32 slices = 32-bit ALU.
Operation (select)
MUX ke select bits: 00 = AND, 01 = OR, 10 = add.
Binvert
Ek 2:1 MUX jo B ya B' adder ko deta hai. B' + CarryIn = 1 se A − B banta hai (two's complement, Unit 4).
Zero flag
Output jo 1 hota hai jab result ke saare bits 0 hon. NOR of all result bits. beq isi se compare karta hai.
read port / write port
Read port = register ki value bahar dena (MUX se). Write port = ek register mein likhna (decoder + write enable, clock edge pe).
Kaise kaam karta hai:
  1. 1-bit slice ke andar a aur b (ya b') teen jagah jaate hain: AND, OR, full adder. Teeno parallel mein result banate hain.
  2. Operation MUX inme se ek ko Result pe bhejta hai.
  3. Subtract: Binvert = 1 (b' liya) aur pehle slice ka CarryIn = 1 → A + B' + 1 = A − B.
  4. 32 slices jodo: slice i ka CarryOut → slice i+1 ka CarryIn (ripple, 3.5).
  5. Zero = NOR(R31, R30, down to R0): sab 0 hon tabhi 1.
  6. 4-bit ALU control (Patterson & Hennessy): bits = Ainvert, Bnegate, Operation(2). 0000 AND, 0001 OR, 0010 add, 0110 sub (Bnegate = 1 + add), 0111 slt, 1100 NOR (A' AND B' = (A + B)').
  7. Register file → ALU → register file: har R-type instruction ka loop (Unit 7 aur 13 mein detail).

Diagram kaise padhein: Left mein Binvert MUX b ya b' chunta hai. Beech mein AND, OR aur FA (FA ko neeche se CarryIn, bahar CarryOut). Right ka MUX (Operation, 2 bits) teeno mein se Result chunta hai. Trace a = 1, b = 1, Operation = 00: AND = 1 → Result = 1.

Diagram kaise padhein: Register file ke do outputs (operand A, operand B) ALU mein. ALU control upar se aata hai (0010 = add). Result neeche se ghoom ke wapas register file mein likha jaata hai (clock edge pe). Zero flag right mein nikalta hai.

Solved example 1 (exam level):

A 4-bit ALU gets a = 0101, b = 0011 and ALU control 0110. Show how it computes the result and the Zero flag.

  1. 0110 = subtract: Binvert (Bnegate) = 1, Operation = add, CarryIn = 1.
  2. b' = 0011 ulta = 1100.
  3. a + b' + 1 = 0101 + 1100 + 1: 0101 + 1100 = 10001, 4 bits rakho → 0001; phir + 1 → 0010.
  4. Check: 5 − 3 = 2 = 0010 ✓.
  5. Result ke bits 0, 0, 1, 0: sab zero nahi → Zero = 0. (Agar a = b = 0011 hota to result 0000, Zero = 1.)

Answer: Result = 0010, Zero = 0.

Solved example 2 (write the answer like this):

Draw a 1-bit ALU for AND, OR, add and subtract. How do 32 slices form a 32-bit ALU and how is Zero produced? (5 marks)

  1. Draw D3.6a: Binvert MUX on b; AND, OR and full adder in parallel; 3:1 Operation MUX gives Result.
  2. Operation 00 = AND, 01 = OR, 10 = add; subtraction = add with Binvert = 1 and CarryIn = 1.
  3. 32 slices: CarryOut of slice i → CarryIn of slice i + 1; slice 0's CarryIn = 1 for subtract.
  4. Zero = NOR of all 32 result bits (tree of ORs + one inverter); used by beq.

Answer: diagram + subtract rule + chaining + Zero = NOR(result bits).

Galti mat karna: ALU kuch store nahi karta (combinational); storage register file hai. Subtraction mein sirf B' kaafi nahi, CarryIn = 1 bhi chahiye (warna one's complement, answer 1 kam).

Trick: "add 0010, sub 0110": sub = add + Bnegate bit (bit 2) on.

Ek line mein: ALU = AND + OR + adder + MUX per bit (sub = B' + carry 1, Zero = NOR); register file = 2 read ports (MUX) + 1 write port (decoder).

3.E1 Extra from slides: Carry-Lookahead Adder

Pehle socho: Ripple adder mein bit 31 ko apne carry ke liye bit 0 se 30 tak sabka intezaar karna padta hai, jaise line mein khade log ek ek karke message aage bolte hain. Kya har aadmi seedha shuru wale se message nahi le sakta? CLA yahi karta hai: har carry ko seedha inputs se nikal leta hai, bina wait ke.
Definition: A carry-lookahead adder (CLA) computes all carries in parallel directly from the inputs, using a generate signal Gi = Ai·Bi and a propagate signal Pi = Ai ⊕ Bi for each bit, with C(i+1) = Gi + Pi·Ci expanded into two-level logic, instead of waiting for the carry to ripple.
Mushkil shabd, aasaan matlab:
Generate Gi = Ai·Bi
"Ye bit khud carry banata hai", chahe neeche se carry aaye ya na aaye. Ai = Bi = 1 → 1 + 1 = 10 → carry pakka.
Propagate Pi = Ai ⊕ Bi
"Ye bit neeche se aaya carry aage pass kar deta hai". Ai, Bi mein ek 1: 1 + 0 + Ci → Ci = 1 ho to carry aage jaata hai.
C0
Sabse pehla carry-in (addition ke liye 0, subtraction ke liye 1).
two-level logic
AND phir OR (SOP): sirf 2 gate delays, chahe term kitne bhi hon.
Kaise kaam karta hai (C1 se C4 nikalna):
  1. Basic rule: bit i se carry tab nikalega jab bit i khud generate kare, YA propagate kare aur neeche se carry aaye: C(i+1) = Gi + Pi·Ci.
  2. i = 0: C1 = G0 + P0C0.
  3. i = 1: C2 = G1 + P1C1. C1 ki jagah upar wala daalo: C2 = G1 + P1(G0 + P0C0) = G1 + P1G0 + P1P0C0.
  4. i = 2: C3 = G2 + P2C2 = G2 + P2G1 + P2P1G0 + P2P1P0C0.
  5. i = 3: C4 = G3 + P3C3 = G3 + P3G2 + P3P2G1 + P3P2P1G0 + P3P2P1P0C0.
  6. Har carry ab sirf G, P aur C0 pe depend karta hai, kisi doosre carry pe nahi. Isliye sab carries ek saath bante hain.
  7. Sum: Si = Pi ⊕ Ci.
  8. Delay: G, P (1 gate) → saare carries (AND-OR = 2 gates) → Sum (1 XOR) ≈ 4 gate delays, bit position se independent. 4-bit RCA mein carry ke liye 8.
  9. Keemat: zyada gates (C4 mein 5-input AND tak), isliye area badhta hai; real CPUs 4-bit CLA blocks jodte hain ya hybrid adders use karte hain.

Diagram kaise padhein: Upar chaar boxes, har bit ke liye Gi = AiBi aur Pi = Ai⊕Bi. Sab neeche ek bade "lookahead" box mein jaate hain jo C1, C2, C3 ek saath nikalta hai (C4 neeche likha hai). Koi carry arrow ek box se doosre mein nahi jaata: yahi ripple se farak hai.

Formula: Gi = AiBi, Pi = Ai ⊕ Bi, C(i+1) = Gi + PiCi, Si = Pi ⊕ Ci
C1 = G0 + P0C0 · C2 = G1 + P1G0 + P1P0C0 · C3 = G2 + P2G1 + P2P1G0 + P2P1P0C0
C4 = G3 + P3G2 + P3P2G1 + P3P2P1G0 + P3P2P1P0C0
Solved example 1 (exam level):

A = 1011, B = 0110, C0 = 0. Find all Gi, Pi, the carries C1 to C4 with the lookahead equations, and the sum.

  1. Bit by bit (bit 0 = right): A0 = 1, B0 = 0 → G0 = 0, P0 = 1. A1 = 1, B1 = 1 → G1 = 1, P1 = 0. A2 = 0, B2 = 1 → G2 = 0, P2 = 1. A3 = 1, B3 = 0 → G3 = 0, P3 = 1.
  2. C1 = G0 + P0C0 = 0 + 1·0 = 0.
  3. C2 = G1 + P1G0 + P1P0C0 = 1 + 0 + 0 = 1.
  4. C3 = G2 + P2G1 + P2P1G0 + P2P1P0C0 = 0 + 1·1 + 0 + 0 = 1.
  5. C4 = G3 + P3G2 + P3P2G1 + P3P2P1G0 + P3P2P1P0C0 = 0 + 0 + 1·1·1 + 0 + 0 = 1.
  6. Sums: S0 = P0 ⊕ C0 = 1 ⊕ 0 = 1; S1 = 0 ⊕ 0 = 0; S2 = 1 ⊕ 1 = 0; S3 = 1 ⊕ 1 = 0.
  7. Check: 1011 = 11, 0110 = 6, 11 + 6 = 17 = 1 0001₂ → C4 = 1, S = 0001 ✓.

Answer: C1 C2 C3 C4 = 0 1 1 1; Sum = 0001 with carry-out 1.

Solved example 2 (write the answer like this):

Explain generate and propagate and why a CLA is faster than a ripple-carry adder. (5 marks)

  1. Gi = AiBi: bit i produces a carry by itself. Pi = Ai ⊕ Bi: bit i passes an incoming carry to the next bit.
  2. C(i+1) = Gi + PiCi; substituting repeatedly gives each carry in terms of G, P and C0 only (write C1 to C4).
  3. All carries are therefore computed in parallel by two-level AND-OR logic, after one level for G and P.
  4. Delay ≈ constant (about 4 gate delays for a 4-bit block) instead of 2n for ripple; cost is more gates (area, fan-in).

Answer: G/P meaning + equations + parallel carries → speed, at the cost of area.

Galti mat karna: G aur P ulta mat karo: G = AND (generate), P = XOR (propagate). Kuch books P = A + B likhti hain, wo carry ke liye chalta hai par Sum = P ⊕ C ke liye nahi; course XOR use karta hai. Aur CLA "kam gates" wala nahi hai: zyada gates, kam delay.

Trick: "G = Ghar ka carry (khud banaya), P = Pass karo." Ck ka pattern: "G + P·(pichla carry)" ko khol do.

Ek line mein: CLA: G = AB, P = A⊕B, C(i+1) = G + PC ko kholke saare carries ek saath; area zyada, delay kam.
