Unit 1 · Boolean Algebra & Gates

Is unit ki kahani: Computer andar se sirf switches ka dher hai: switch ON = 1, OFF = 0. Is unit mein hum seekhte hain ki ye 0/1 kaise "socha" jaata hai: gates (AND, OR, NOT, XOR), unki truth tables, aur Boolean laws jinse ek bada circuit chhota ho jaata hai. Saath mein Verilog, jisme hum circuit ko text ki tarah likhte hain. Unit 2 inhi laws ko K-map se fast banata hai, aur Unit 3 inhi gates se MUX, decoder, adder jaise bade blocks banata hai.

1.1 Course Introduction and Roadmap

Pehle socho: Ek building ka naksha (kitne kamre, kahan darwaza, kahan switch) residents ko dikhta hai. Deewar ke andar ki wiring aur plumbing nahi dikhti. Do buildings ka naksha same ho sakta hai par wiring alag. Computer mein bhi yahi do cheezein hain: jo programmer ko dikhta hai (architecture) aur jo andar chhupa hai (organisation).
Definition: Computer architecture is the set of attributes of a computer visible to the programmer, mainly the instruction set architecture (ISA): instructions, registers, data types and memory model ("what" the machine does). Computer organisation is the hidden implementation of that architecture: pipelines, caches, clock rate, control signals ("how" it does it).
Mushkil shabd, aasaan matlab:
ISA (Instruction Set Architecture)
CPU ki "vocabulary": kaun kaun se instructions hain (ADD, LOAD), kitne registers hain. Jaise "is CPU mein ADD instruction hai" ek ISA statement hai.
organisation / microarchitecture
Same cheez ke do naam: ADD andar se kaise bana hai. Jaise "ADD ek cycle mein is adder se hota hai" ya "L1 cache 48 KB hai".
programmer-visible
Jo cheez program ke result pe asar daale. Register count visible hai (program usse use karta hai). Cache size visible nahi (program same chalega, bas speed badlegi).
Kaise kaam karta hai (course ka raasta):
  1. Course CSA222 gates se shuru hokar AI accelerator tak jaata hai: 12 weeks, 24 lectures, 6 modules.
  2. M1 Digital Foundations (gates, Boolean algebra, combinational blocks, numbers) → M2 Sequential & Memory (flip-flops, registers, counters, FSM).
  3. M3 Organisation & ISA (MIPS, C → machine code) → M4 Datapath & Pipelining (CPU banana, fast karna).
  4. M5 Memory Hierarchy (cache) → M6 Parallelism (multicore, GPU, TPU).
  5. Grading: end-sem 40%, mid-sem 20%, contests 20%, projects 10%, assignments 10%. Tools: Verilog simulation (M1, M2), MARS MIPS simulator (M3).

Diagram kaise padhein: Upar ki row M1 → M2 → M3, neeche ki row M4 → M5 → M6; arrow batata hai ki har module pichle wale pe khada hai. Har box mein top line module ka naam aur weeks hai, neeche ki lines topics.

Solved example (write the answer like this):

Differentiate between computer architecture and computer organisation with two examples of each. (5 marks)

  1. Architecture: attributes visible to the programmer, the hardware/software contract (ISA). It answers "what does the machine do?".
  2. Organisation: the operational units and their interconnections that implement the architecture. It answers "how does it do it?".
  3. Architecture examples: instruction set and formats, number of registers, addressing modes, data types.
  4. Organisation examples: pipelining, cache size, clock rate, adder type (ripple vs lookahead), control signals.
  5. Impact: changing the architecture breaks old software; changing the organisation keeps programs running, only speed and cost change. Example: Intel and AMD x86-64 chips share the architecture but differ in organisation.

Answer: Architecture = what (ISA, visible); Organisation = how (implementation, hidden).

Galti mat karna: "L1 cache 48 KB hai" ya "pipeline 5 stage ki hai" ko architecture mat bolna. Program ka result in pe depend nahi karta, sirf speed karti hai, isliye ye organisation hai.
Ek line mein: Architecture = programmer ko kya dikhta hai (ISA); Organisation = andar se kaise bana hai (pipeline, cache, clock).

1.2 Why Architecture Matters: the Abstraction Stack

Pehle socho: Car chalate waqt aap steering aur brake use karte ho; engine ke andar petrol kaise jalta hai, ye jaanne ki zaroorat nahi. Har layer neeche wali layer ki details chhupa deti hai. Computer bhi aise hi layers mein bana hai, warna ek program likhne ke liye transistors yaad rakhne padte.
Definition: The abstraction stack is the set of layers from which a computer system is built, each layer using the one below it while hiding its details: AI/ML models → applications & languages → operating system → ISA → datapath & control → logic gates → transistors.
Mushkil shabd, aasaan matlab:
abstraction
Details chhupa ke sirf kaam ki cheez dikhana. Steering wheel = engine ka abstraction.
ISA as contract
Software (compiler, OS) ISA ke hisaab se likha jaata hai, hardware ISA ko implement karta hai. Dono contract maante rahein to dono alag alag badal sakte hain: purana program naye chip pe chalta hai.
datapath & control
Datapath = registers, ALU, MUX jinse data chalta hai. Control = signals jo batate hain kab kya karna hai.
transistor
Silicon ka switch: ON = 1, OFF = 0. Gates transistors se bante hain.
Moore's law
Chip pe transistors ki ginti lagbhag har 2 saal mein double hoti hai. Ye clock speed ke baare mein NAHI hai.
VLSI flow
Chip banane ke steps: Specification → RTL (Verilog) → Simulation → Synthesis → Gate netlist → Place & Route → Physical verification (DRC/LVS/STA) → Fabrication → Post-silicon validation.
Kaise kaam karta hai (ek line code har layer se guzarti hai):
  1. Aap likhte ho A[i] = B[i] + C[i] (Python / C layer).
  2. Compiler isse 4 MIPS instructions banata hai: lw (B[i] lao), lw (C[i] lao), add, sw (A[i] mein rakho). Ye ISA layer hai.
  3. Datapath: register file do numbers ALU ko deta hai, ALU jodta hai, result wapas register file mein likha jaata hai.
  4. ALU ka adder XOR aur AND gates se bana hai (carry logic).
  5. Har gate transistors (switches) se bana hai.
  6. Ye course beech ki layers chadhta hai: gates → datapath → ISA.

Diagram kaise padhein: Neeche sabse chaudi patti transistors, upar sabse abstract (AI/ML). Highlight wali patti ISA hai: uske upar sab software, neeche sab hardware. Left ka arrow upar ki taraf "more abstract" dikhata hai.

Diagram kaise padhein: Upar se neeche padho: ek hi line pehle source code, phir lw/lw/add/sw, phir regfile → ALU → regfile, aur aakhir mein XOR/AND gates. Har arrow = ek layer neeche jaana.

History jo slides mein hai: 1847 Boole (algebra of logic), 1937 Shannon (switching circuits Boolean algebra follow karte hain), 1947 transistor ne vacuum tube ki jagah li (ENIAC: lagbhag 18,000 tubes, 30 ton), 1958 Kilby ka pehla IC, 1971 Intel 4004: pehla single-chip CPU, lagbhag 2,300 transistors, 740 kHz, 4-bit. Apple M2 (2022): lagbhag 20 billion transistors.

Solved example (write the answer like this):

Explain the abstraction stack using A[i] = B[i] + C[i]. Why is the ISA called the hardware/software contract? (5 marks)

  1. Draw the seven layers: AI/ML → applications → OS → ISA → datapath & control → gates → transistors.
  2. Compiler maps the statement to lw, lw, add, sw (4 MIPS instructions).
  3. Control unit sets the datapath: register file sends two operands to the ALU, sum is written back.
  4. The ALU adder is built from XOR/AND gates (full adders); gates are CMOS transistors acting as switches.
  5. ISA = contract: everything above is written to it, everything below must implement it; both sides can evolve independently.

Answer: labelled stack + trace through 4 layers + contract line.

Galti mat karna: OS ko ISA ke neeche mat rakhna; OS ISA ke upar chalta hai. Aur Moore's law = transistor count double, clock speed double nahi.
Ek line mein: Har layer neeche wali ko chhupati hai; ISA beech mein hardware/software ka contract hai.

1.3 Boolean Logic Basics: AND, OR, NOT, XOR Gates

Pehle socho: Ek bulb aur do switch. Switch series mein lagao: bulb tabhi jalega jab dono ON hon (AND). Parallel mein lagao: koi bhi ek ON ho to jalega (OR). Ek ulta switch jo dabane pe band ho jaaye: NOT. Pura computer inhi teen ideas se bana hai.
Definition: A logic gate is an electronic circuit that performs a Boolean function on one or more binary inputs (0 = LOW/false, 1 = HIGH/true) and produces a single binary output.
Mushkil shabd, aasaan matlab:
binary signal (0/1)
1 = TRUE = HIGH (lagbhag 3.3 V ya 5 V), 0 = FALSE = LOW (0 V). Sirf "voltage hai / nahi hai" pehchanna hota hai, isliye reliable.
bubble
Gate symbol pe chhota gola = NOT (ulta karna). AND + bubble = NAND.
"+" aur "·"
Boolean mein + ka matlab OR, · ka matlab AND. Isliye 1 + 1 = 1 (2 nahi).
universal gate
Aisa gate jisse akele har doosra gate ban jaaye. NAND aur NOR universal hain. Jaise NOT A = A NAND A.
parity
1s ki ginti odd hai ya even. XOR = 1 jab 1s ki ginti odd ho.
Kaise kaam karta hai (har gate ka rule, ek 0/1 example ke saath):
  1. NOT (Y = A'): input ulta. A = 1 → Y = 0.
  2. AND (Y = A·B): 1 sirf jab saare inputs 1. A = 1, B = 0 → Y = 0.
  3. OR (Y = A + B): 1 jab kam se kam ek input 1. A = 1, B = 0 → Y = 1.
  4. NAND = AND phir NOT: Y = (AB)'. Sirf 1,1 pe 0, baaki sab pe 1.
  5. NOR = OR phir NOT: Y = (A + B)'. Sirf 0,0 pe 1, baaki sab pe 0.
  6. XOR (Y = A ⊕ B = A'B + AB'): 1 jab inputs alag hon. 1,0 → 1; 1,1 → 0.
  7. XNOR (Y = (A ⊕ B)' = A'B' + AB): 1 jab inputs barabar hon (equality detector). 1,1 → 1.

Table mein dekho: NAND column = AND column ulta; NOR = OR ulta; XNOR = XOR ulta. OR aur XOR sirf last row (1,1) mein alag hain.

Diagram kaise padhein: AND = "D" shape (seedhi peeth). OR = curved peeth, nukeeli naak. XOR = OR ke peeche ek extra curve. Output pe bubble ho to ulta: NAND, NOR, XNOR. NOT = triangle + bubble. Har symbol ke neeche uska formula likha hai.

Formula: AND A·B · OR A + B · NOT A' · NAND (AB)' · NOR (A + B)' · XOR A'B + AB' · XNOR A'B' + AB
Verilog operators: & AND, | OR, ~ NOT, ^ XOR, ~^ XNOR.
n-input XOR = 1 when the number of 1s is odd.
Solved example 1 (class quick check):

For A = 1, B = 0, which of AND, OR, NAND, NOR, XOR, XNOR give 1?

  1. AND: dono 1 chahiye, B = 0 hai → 0.
  2. OR: ek 1 kaafi hai → 1.
  3. NAND = AND ulta = 0 ulta → 1.
  4. NOR = OR ulta = 1 ulta → 0.
  5. XOR: inputs alag (1 aur 0) → 1. XNOR = XOR ulta → 0.

Answer: OR, NAND, XOR give 1.

Solved example 2:

(a) A 3-input XOR gets 1, 1, 1. Output? (b) Which gate is assign y = ~(a ^ b);?

  1. (a) 1s ki ginti = 3, jo odd hai. XOR rule: odd → 1. Step by step: 1 ⊕ 1 = 0, phir 0 ⊕ 1 = 1.
  2. (b) ^ = XOR, uske bahar ~ = NOT. NOT of XOR = XNOR.

Answer: (a) 1; (b) XNOR.

Galti mat karna: "+" ko jod mat samjho: A + 1 = 1, 2 nahi. Aur OR ko XOR mat samjho: 1,1 pe OR = 1 par XOR = 0. NAND ≠ AND (bubble bhoolna common galti hai).

Trick: AND = series, OR = parallel. XOR = "alag ho to 1", XNOR = "same ho to 1".

Ek line mein: AND sab 1 maange, OR ek 1 maange, XOR alag maange; bubble lagao to ulta.

1.4 Truth Tables

Pehle socho: Dukaan ki poori price list: har item ka daam likha hai, kuch chhoota nahi. Truth table bhi ek circuit ki poori list hai: har possible input ke liye output. Agar do expressions ki truth table same hai, to dono circuits same kaam karte hain, chahe dikhne mein alag hon.
Definition: A truth table lists the output of a logic function for every possible combination of its inputs. For n inputs it has 2ⁿ rows, written in binary counting order.
Mushkil shabd, aasaan matlab:
row
Inputs ka ek combination. 3 inputs (A, B, C) → 000, 001, 010, 011, 100, 101, 110, 111 = 8 rows.
2ⁿ rows
Har input 0 ya 1 (2 choices). n inputs → 2 × 2 × 2 (n baar) = 2ⁿ. 4 inputs → 16 rows.
MSB (first variable)
Sabse left wala bit, sabse bada weight. ABC = 101 mein A = MSB, value = 4 + 0 + 1 = 5.
row number / minterm index
Row ka decimal value. Row ABC = 011 → 0 + 2 + 1 = 3, isko m3 bolte hain (Unit 2 mein detail).
helper column
Beech ka column jaise BC, taaki bada expression tukdon mein bane.
Kaise kaam karta hai (expression se truth table banana):
  1. Variables gino: n. Rows = 2ⁿ.
  2. Inputs binary counting order mein likho: 000 se 111 tak (A = MSB).
  3. Har chhote tukde (jaise BC) ka helper column banao.
  4. Helper columns ko jod ke final output column banao.
  5. Jin rows mein output 1 hai, unke numbers likho: yahi Σm list hai.

Example: Y = A + BC (L01 homework).

A = 1 wali chaaron rows mein Y = 1 (OR mein ek 1 kaafi). A = 0 pe Y = BC, jo sirf row 3 mein 1 hai. Isliye Y = Σm(3, 4, 5, 6, 7).

Diagram kaise padhein: Pehle do columns A, B ki chaar rows (00, 01, 10, 11) hain; baaki har column ek gate ka output. Kisi gate ko pehchanna ho to uska column upar se neeche padho: AND = 0001, OR = 0111, XOR = 0110, NAND = 1110, NOR = 1000, XNOR = 1001.

Formula: rows = 2ⁿ; distinct Boolean functions of n variables = 2^(2ⁿ).
n = 2: 2² = 4 rows, functions = 2⁴ = 16. n = 3: 2³ = 8 rows, functions = 2⁸ = 256.
Solved example 1 (direct):

(a) Rows in the truth table of a 5-input circuit? (b) How many distinct Boolean functions of 3 variables exist?

  1. (a) 2⁵ = 2 × 2 × 2 × 2 × 2 = 32 rows.
  2. (b) Rows = 2³ = 8. Har row ka output 0 ya 1 ho sakta hai, to output column ke 2 × 2 × (8 baar) = 2⁸ = 256 alag pattern.

Answer: (a) 32; (b) 256.

Solved example 2 (exam level):

Construct the truth table of F = AB' + A'C + BC' and express F in Σm form. (5 marks)

  1. 3 variables → 8 rows. Helper columns: AB', A'C, BC'.
  2. AB' = 1 sirf jab A = 1, B = 0: rows 100, 101.
  3. A'C = 1 jab A = 0, C = 1: rows 001, 011.
  4. BC' = 1 jab B = 1, C = 0: rows 010, 110.
  5. F = OR of three: rows 1, 2, 3, 4, 5, 6 mein 1; rows 0 (000) aur 7 (111) mein 0.

Galti mat karna: Rows random order mein likhoge to minterm numbers galat ho jaayenge. Hamesha 000, 001, 010 counting order. Aur 4 inputs = 16 rows, 8 nahi.
Ek line mein: n inputs → 2ⁿ rows, counting order mein; same truth table = same circuit.

1.5 Boolean Laws & Simplification

Pehle socho: Normal maths mein "x × 1 = x", "x + 0 = x" jaise rules se lamba expression chhota karte ho. Boolean mein bhi aise rules (laws) hain. Chhota expression = kam gates = kam area, kam power, zyada speed. Achhi baat: har variable sirf 0 ya 1 ho sakta hai, isliye har law ko A = 0 aur A = 1 daal ke khud check kar sakte ho.
Definition: Boolean algebra is the algebra of variables that take only the values 0 and 1, with the operations AND (·), OR (+) and NOT ('). Its laws allow an expression to be rewritten into a simpler equivalent expression with the same truth table.
Mushkil shabd, aasaan matlab:
literal
Variable ka ek appearance, seedha ya bar ke saath. AB' + C mein 3 literals (A, B', C).
complement (A')
A ka ulta. A = 1 → A' = 0.
dual
Law ka "mirror": + ko · se, · ko + se, 0 ko 1 se, 1 ko 0 se badlo (variables same rakho). A + 0 = A ka dual A · 1 = A. Ek law sahi hai to uska dual bhi sahi.
perfect induction
Law ko proof karna har possible 0/1 value daal ke. Sirf 2 ya 4 cases hote hain, isliye easy.
Kaise kaam karta hai (har law + "kyun sahi hai" 0/1 se):
LawFormulaKyun sahi hai (0/1 daal ke)
IdentityA + 0 = A; A·1 = AA = 0: 0 + 0 = 0; A = 1: 1 + 0 = 1. Dono baar answer = A.
NullA + 1 = 1; A·0 = 0OR mein ek 1 ho to output 1, chahe A kuch bhi ho. AND mein ek 0 ho to output 0.
IdempotentA + A = A; A·A = A0 + 0 = 0, 1 + 1 = 1 (OR, jod nahi). Isliye 2A jaisa kuch nahi hota.
ComplementA + A' = 1; A·A' = 0A aur A' mein ek hamesha 1 hai (OR → 1) aur ek hamesha 0 hai (AND → 0).
Involution(A')' = ADo baar ulta = seedha: 1 → 0 → 1.
CommutativeA + B = B + A; AB = BAGate ko farak nahi padta kaunsa wire upar laga hai.
Associative(A + B) + C = A + (B + C)OR = "koi ek 1?"; brackets kahin bhi, jawab same. AND ke liye bhi.
Distributive 1A(B + C) = AB + ACA = 0: dono side 0. A = 1: dono side B + C.
Distributive 2A + BC = (A + B)(A + C)A = 1: dono side 1. A = 0: left = BC, right = B·C. Same! (Normal maths mein ye nahi hota.)
AbsorptionA + AB = A; A(A + B) = AA = 1: 1 + B = 1 = A. A = 0: 0 + 0 = 0 = A. B ka koi role nahi.
Redundant literalA + A'B = A + BA = 1: dono side 1. A = 0: left = 1·B = B, right = B. Same.
De Morgan(AB)' = A' + B'; (A + B)' = A'B'(AB)' sirf A = B = 1 pe 0 hai; A' + B' bhi sirf tab 0 jab A' = B' = 0, yaani A = B = 1. Same row.
ConsensusAB + A'C + BC = AB + A'CBC = 1 matlab B = C = 1. Tab A = 1 ho to AB = 1, A = 0 ho to A'C = 1. BC kabhi akela kaam nahi aata, isliye hata do.
Formula (sabse zyada use hone wale): A + AB = A · A + A'B = A + B · A + BC = (A + B)(A + C) · (AB)' = A' + B' · (A + B)' = A'B'
Duality: + ↔ ·, 0 ↔ 1. A + 0 = A ↔ A·1 = A.
Solved example (write the answer like this):

Prove (i) A + AB = A and (ii) A + A'B = A + B using the basic laws, naming each law. (5 marks)

  1. (i) A + AB = A·1 + A·B   [Identity: A = A·1]
  2. = A(1 + B)   [Distributive: take A common]
  3. = A·1   [Null: 1 + B = 1]
  4. = A   [Identity]
  5. (ii) A + A'B = (A + A')(A + B)   [Distributive 2: X + YZ = (X + Y)(X + Z)]
  6. = 1·(A + B)   [Complement: A + A' = 1]
  7. = A + B   [Identity]
  8. Check by truth table: both sides of (ii) are 0 only at A = B = 0, 1 elsewhere.

Answer: (i) A + AB = A (absorption); (ii) A + A'B = A + B.

Galti mat karna: (AB)' = A'B' likhna GALAT hai. De Morgan mein bar todne ke saath sign bhi badalta hai: (AB)' = A' + B'. Aur A + A = 2A nahi, A hai.

Trick: De Morgan = "bar todo, sign badlo". Koi law yaad na aaye to A = 0 aur A = 1 daal ke check kar lo, 30 second lagte hain.

Ek line mein: Har Boolean law 0/1 daal ke check ho sakta hai; sabse kaam ke: A + AB = A, A + A'B = A + B, aur De Morgan.

1.6 Worked Simplification Examples

Pehle socho: L01 ka example: Y = AB + AB'. Isko seedha banao to 2 AND, 1 OR, 1 NOT = 4 gates. Par AB + AB' = A(B + B') = A·1 = A. Matlab poora circuit sirf ek wire hai! Simplification ka yahi fayda hai: same kaam, kam hardware.
Definition: Simplification is the process of reducing a Boolean expression to fewer terms and literals (hence fewer gates) by applying Boolean laws, while keeping the same truth table.
Mushkil shabd, aasaan matlab:
term
+ ke beech ka tukda. AB' + BC mein do terms: AB' aur BC.
common factor
Jo variable do terms mein common hai, use bahar nikalo: AB'C + AB'C' = AB'(C + C').
complement pair
X aur X' saath mein: X + X' = 1 (OR mein), X·X' = 0 (AND mein). Yahi variable ko "cancel" karta hai.
Kaise kaam karta hai (5-step strategy):
  1. Aise do terms dhoondo jo sirf ek variable mein alag hon (ek mein X, doosre mein X').
  2. Common factor bahar nikalo, andar X + X' = 1 bachega, wo variable gayab.
  3. Absorption (A + AB = A) aur A + A'B = A + B lagao.
  4. Kisi group ke upar bar ho to De Morgan se bar todo, andar tak.
  5. Final answer ko truth table (ya 2 rows) se check karo.

Diagram kaise padhein: Left se B aur C ek AND gate mein jaate hain (output BC). Phir A aur BC ek OR gate mein jaate hain, output Y = A + BC. Trace: A = 0, B = 1, C = 1 → BC = 1 → Y = 0 + 1 = 1.

Solved example 1 (class quiz):

Simplify F = AB'C + A'BC + ABC + AB'C'.

  1. F = AB'C + AB'C' + A'BC + ABC   [Commutative: rearrange so matching terms are together]
  2. = AB'(C + C') + BC(A' + A)   [Distributive: take AB' and BC common]
  3. = AB'·1 + BC·1   [Complement: C + C' = 1, A' + A = 1]
  4. = AB' + BC   [Identity]
  5. Check: F should be 1 at rows 100, 101 (AB') and 011, 111 (BC) = m4, m5, m3, m7. Original terms are exactly m5, m3, m7, m4. ✓

Answer: F = AB' + BC.

Solved example 2 (class quiz, product of sums):

Simplify F = (A' + B)(A' + B')(A + B).

  1. (A' + B)(A' + B') = A' + B·B'   [Distributive 2: (X + Y)(X + Z) = X + YZ, with X = A']
  2. = A' + 0   [Complement: B·B' = 0]
  3. = A'   [Identity]
  4. Now F = A'(A + B) = A'A + A'B   [Distributive 1]
  5. = 0 + A'B   [Complement: A'A = 0]
  6. = A'B   [Identity]
  7. Check A = 0, B = 1: (1 + 1)(1 + 0)(0 + 1) = 1·1·1 = 1, and A'B = 1·1 = 1. ✓

Answer: F = A'B.

Solved example 3 (exam level, Lab 2 Q27):

Simplify F = ((A + B)'·C)' + (A·B)' and draw the circuit.

  1. Inner bar: (A + B)' = A'B'   [De Morgan]
  2. So first term = (A'B'C)' = A + B + C'   [De Morgan for 3 variables: (XYZ)' = X' + Y' + Z', and (A')' = A]
  3. Second term: (AB)' = A' + B'   [De Morgan]
  4. F = A + B + C' + A' + B'   [just write both together]
  5. = (A + A') + (B + B') + C'   [Commutative / associative: regroup]
  6. = 1 + 1 + C'   [Complement]
  7. = 1   [Null: anything + 1 = 1]

Answer: F = 1 always; the "circuit" is the output tied to logic 1 (VDD), zero gates.

Solved example 4 (Lab 2 Q12):

Simplify F = A'B'C + A'BC + AB'C + ABC + A'B.

  1. A'B'C + A'BC = A'C(B' + B) = A'C   [Distributive, Complement, Identity]
  2. AB'C + ABC = AC(B' + B) = AC   [same three laws]
  3. A'C + AC = C(A' + A) = C   [same three laws]
  4. F = C + A'B   [nothing more combines: A'B has no C]

Answer: F = C + A'B.

Galti mat karna: Pehla grouping karke ruk mat jao; har step ke baad dobara dekho ki absorption ya complement pair bacha to nahi. Aur factor nikalte waqt koi term gum na ho: wapas multiply karke check karo.

Trick: Exam mein har line ke aage bracket mein law ka naam likho; marks usi ke milte hain.

Ek line mein: Common factor nikalo → X + X' = 1 se variable udao → absorption/De Morgan → truth table se check.

1.E1 Extra from slides: Verilog & HDL Fundamentals

Pehle socho: Ek billion gates ka chip haath se draw nahi ho sakta. Isliye engineers circuit ko text mein likhte hain (jaise code), phir software usse test karta hai (simulation) aur asli gates mein badalta hai (synthesis). Par dhyan: ye "program" nahi hai jo line by line chale; ye ek wiring diagram hai jisme sab gates ek saath kaam karte hain.
Definition: A Hardware Description Language (HDL) such as Verilog describes the structure and behaviour of digital circuits as text, so that they can be simulated (behaviour checked over simulated time) and synthesised (converted into a gate-level netlist for fabrication).
Mushkil shabd, aasaan matlab:
module / endmodule
Ek hardware block ka dabba, ports (input/output) ke saath. Jaise module and_gate (input a, input b, output y);
wire
Asli taar: jo usse chala raha hai uski value hamesha dikhata hai. assign ke saath use hota hai.
reg
Variable jo always ya initial block ke andar value paata hai aur agle assignment tak rakhta hai. reg ka matlab hamesha flip-flop nahi hai.
assign
Continuous assignment: assign y = a & b; matlab y hamesha a AND b hai; a ya b badle to y turant badle.
always @(*)
Combinational block: koi bhi input badle to block dobara chale. Har case cover karna zaroori (default), warna latch ban jaata hai.
always @(posedge clk)
Sequential block: sirf clock ke 0→1 edge pe chale. Andar <= (non-blocking) use karo.
testbench
Bina ports wala module jo design (DUT) ko inputs deta hai aur outputs print karta hai. #10 = 10 time units ruko.
simulation vs synthesis
Simulation (iverilog/vvp, waveform GTKWave mein) = check karna, kuch banta nahi. Synthesis (Synopsys DC, Cadence Genus) = asli gate netlist banana.
Kaise kaam karta hai (Lab 1 ka flow):
  1. Design file likho, jaise and_gate.v.
  2. Testbench likho (and_tb.v) jo saare input combinations deta hai.
  3. Compile: iverilog -o and.vvp and_gate.v and_tb.v (saari files ek saath).
  4. Run: vvp and.vvp (text output aata hai, aur VCD waveform file banti hai).
  5. Waveform dekho: gtkwave and.vcd.
// 2-input AND gate
module and_gate (
    input  wire a,
    input  wire b,
    output wire y
);
    assign y = a & b;   // y updates whenever a or b changes
endmodule

Line by line:

  1. // 2-input AND gate: comment, compiler ignore karta hai.
  2. module and_gate (: naya hardware block shuru, naam and_gate.
  3. input wire a, input wire b: do input taar a aur b.
  4. output wire y: ek output taar y.
  5. assign y = a & b;: y ko hamesha a AND b se jod do. Ye ek AND gate ban jaata hai.
  6. endmodule: block khatam.
module y_abc (input a, b, c, output y);
    assign y = a | (b & c);        // Y = A + BC, version 1
endmodule

module y_abc_v2 (input a, b, c, output reg y);
    always @(*)                    // re-run when a, b or c changes
        y = a | (b & c);           // same circuit, version 2 (y must be reg)
endmodule

Dono modules same circuit (D1.6a) banate hain. Version 2 mein y ko reg declare kiya kyunki usse always block ke andar value mil rahi hai.

Diagram kaise padhein: Left mein ek hi Verilog file. Upar ka raasta: simulator → waveform (sirf check). Neeche ka raasta: synthesis tool → gate netlist → asli silicon. Same language, do kaam.

Solved example 1 (lab MCQ):

a = 4'b0101, b = 4'b0010. Find a & b and a && b.

  1. & bitwise hai: bit by bit AND. 0101 AND 0010: bit3 0·0 = 0, bit2 1·0 = 0, bit1 0·1 = 0, bit0 1·0 = 0 → 0000.
  2. && logical hai: poora number zero hai ya nahi. a = 5 (non-zero → true), b = 2 (non-zero → true). true AND true = 1 (ek bit).

Answer: a & b = 4'b0000; a && b = 1'b1.

Solved example 2 (write the answer like this):

Differentiate wire and reg, and simulation and synthesis. (5 marks)

  1. wire: a net driven continuously (by assign or a module output); it has no memory.
  2. reg: a variable assigned inside always/initial; it holds its value until the next assignment.
  3. Simulation runs the HDL on a computer over simulated time to check behaviour (waveforms); nothing is built.
  4. Synthesis converts the same RTL into a gate-level netlist for fabrication or FPGA.
  5. Example: assign y1 = a & b; (wire) and always @(*) y2 = a & b; (reg) both synthesise to one AND gate.

Answer: wire ↔ assign, reg ↔ always/initial; simulation checks, synthesis builds.

Galti mat karna: always ke andar wire ko assign karna error hai (reg chahiye). always @(*) mein case ka default bhoole to latch ban jaata hai. Waveform khaali aaye to check karo $dumpfile aur $dumpvars dono likhe hain.

Trick: "assign → wire, always → reg". Verilog padhte waqt socho "ye taar kahan jud raha hai", "pehle ye line chalegi" nahi.

Ek line mein: Verilog = circuit ka text roop; assign se wire, always se reg; simulation check karta hai, synthesis gates banata hai.
