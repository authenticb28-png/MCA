Unit 7 · Register Files & Finite State Machines

Is unit ki kahani: Unit 5–6 mein humne flip-flop aur register (flip-flops ki row) banaye. Ab do bade sawaal: (1) CPU ke andar 32 registers hain, instruction unhe number se bulata hai, to inhe ek saath kaise organise karein? Jawab: register file (decoder se likho, MUX se padho, Unit 3 ke blocks). (2) CPU har cycle kya kare, ye kaun decide karta hai? Jawab: ek Finite State Machine (FSM), jo yaad rakhti hai "abhi main kahan hoon" aur input dekh ke aage badhti hai. Unit 8 mein register file se badi memory (SRAM, DRAM) aayegi, aur Unit 13 mein register file + FSM (control) milke poora CPU banayenge.

7.1 From Registers to Register Files

Pehle socho: Instruction add R1, R2, R3 ka matlab hai: R2 aur R3 padho, jodo, jawab R1 mein likho. Isme 2 registers padhne hain aur 1 likhna hai, aur sab ek hi clock cycle mein. Agar har register alag-alag wire se juda ho to 32 registers ke liye wiring ka jungle ban jayega. Socho railway station ke numbered lockers ki deewar: tum locker ka number bolte ho aur woh khul jaata hai. Is deewar mein do "dekhne ki khidkiyan" hain (do lockers ek saath dekh sakte ho) aur ek "daalne ka slot" hai (ek locker mein saamaan rakh sakte ho). Yahi register file hai.
Definition: A register file is an array of registers inside the CPU with address-based access, which allows several registers to be read and one register to be written in the same clock cycle. The MIPS / RISC-V register file has 32 registers of 32 bits each, with 2 read ports and 1 write port.
Mushkil shabd, aasaan matlab:
register
Flip-flops ki ek row jo ek saath ek word (jaise 32 bits) store karti hai. 32-bit register = 32 D flip-flops, sabka clock same.
address (register number)
Register ka "locker number" binary mein. 32 registers hain to number 0 se 31 tak. R5 ka address = 00101.
port
Register file ka ek "darwaza" jisse ek register padha ya likha jaata hai. 2 read ports = ek saath do alag registers padh sakte ho. 1 write port = ek cycle mein ek register likh sakte ho.
width (word size)
Ek register mein kitne bits hain. MIPS mein 32. Width aur number of registers alag cheezein hain: "32 × 32" ka pehla 32 = kitne registers, doosra 32 = har ek ki width.
log₂
"2 ko kitni baar multiply karein ki ye number mile". log₂ 32 = 5 kyunki 2×2×2×2×2 = 32. Isi se pata chalta hai address ke kitne bits chahiye.
Kaise kaam karta hai:
  1. CPU ke paas 32 registers hain: R0 se R31.
  2. Har register ko number (address) se bulaya jaata hai. 32 alag numbers banane ke liye kitne bits? 2⁵ = 32, isliye 5 bits (00000 se 11111).
  3. add R1, R2, R3 aaya: Read address 1 = 00010 (R2), Read address 2 = 00011 (R3), Write address = 00001 (R1).
  4. Dono read ports R2 aur R3 ka data turant ALU ko de dete hain.
  5. ALU jodta hai, aur clock edge pe jawab write port se R1 mein chala jaata hai.
  6. Isliye ports ki ginti instruction se match karti hai: 2 source padhne = 2 read ports, 1 destination likhna = 1 write port.
  7. Speed: register file sabse tez storage hai (ns ka ek hissa), phir L1 cache, L2, RAM (Unit 8).
Formula: Address bits per port = log₂(number of registers)  ·  Total storage bits (= flip-flops) = registers × width
32 registers → log₂ 32 = 5 bits. 32 × 32 = 1024 bits.
Solved example 1 (direct):

A register file is designed with exactly 64 registers. What is the minimum number of bits required for the write address?

  1. Sawaal: 64 alag numbers banane ke liye kitne bits?
  2. 2 ki powers likho: 2¹ = 2, 2² = 4, 2³ = 8, 2⁴ = 16, 2⁵ = 32, 2⁶ = 64.
  3. 2⁶ = 64, isliye log₂ 64 = 6.

Answer: 6 bits.

Solved example 2 (exam-level, class quiz):

A register file has 16 registers, each 8 bits wide. How many flip-flops does it contain, and how wide must each read address be? Also find the total storage of the MIPS file (32 × 32) and of a 64 × 32 file.

  1. Har bit = ek flip-flop. Flip-flops = registers × width = 16 × 8 = 128.
  2. Read address: log₂ 16. 2⁴ = 16, isliye 4 bits.
  3. MIPS: 32 × 32 = 1024 bits.
  4. 64 × 32: 64 × 32 = 2048 bits (address 6 bits, kyunki 2⁶ = 64).

Answer: 128 flip-flops, 4-bit address; MIPS = 1024 bits; 64 × 32 = 2048 bits.

Galti mat karna: "Number of registers" aur "width" ko mix mat karo. Address bits sirf number of registers se aate hain (16 registers → 4 bits), width se nahi. 16 × 8 file mein address 8 bits NAHI hai, 4 bits hai. Width (8) sirf data wires aur total bits mein aati hai.

Trick: "Ginti → address, chaudai → data." Kitne registers (ginti) se address bits; kitne bits per register (chaudai) se data bus.

Ek line mein: Register file = number se chunne wale registers ka bank; MIPS: 32 × 32-bit, 5-bit address, 2 read + 1 write port, kyunki add rd, rs, rt do padhta hai aur ek likhta hai.

7.2 Register File Architecture (1 Write, 2 Read Ports)

Pehle socho: Locker wali deewar mein do kaam hain. Saamaan daalna (write): pehle decide karo kaunse locker mein (number), phir decide karo daalna hai ya nahi (permission). Dekhna (read): number bolo, aur us locker ka saamaan khidki mein dikh jaaye. Unit 3 ke do blocks bilkul yahi karte hain: decoder number leke ek hi line ON karta hai (kaunsa locker), aur MUX number leke us ek input ko output pe bhej deta hai (khidki).
Definition: The write port of a register file uses an n-to-2ⁿ decoder whose one-hot outputs are ANDed with the write-enable signal (RegWrite) to load exactly one register at the clock edge (synchronous write). Each read port is a 2ⁿ:1 multiplexer whose select lines are the read address, so read data appears after the gate delay without any clock (combinational read).
Mushkil shabd, aasaan matlab:
decoder (5-to-32)
5-bit number andar, 32 lines bahar, sirf us number wali line 1. Input 00011 → sirf line 3 = 1.
one-hot
Lines ke group mein exactly ek line 1, baaki sab 0. Jaise 0000 1000: sirf line 3 "garam" hai.
RegWrite / WE (write enable)
Ek control bit: 1 = "is cycle mein likhna hai", 0 = "kuch mat likho". sw ya beq jaise instructions register nahi likhte, unke liye RegWrite = 0.
load enable
Register ka apna "haan, nayi value lo" signal. Enable = 1 to clock edge pe naya data andar, enable = 0 to purani value rakhe (Unit 6).
MUX (32:1)
32 inputs mein se ek ko output pe bhejne wala switch. Kaunsa? Ye 5 select bits batate hain (2⁵ = 32). Select = 00010 → input 2 bahar.
combinational
Output sirf abhi ke inputs pe depend karta hai, clock ka intezaar nahi. Input badla to thodi der (gate delay) baad output badal gaya.
synchronous
Kaam sirf clock edge (0 → 1 hone ke pal) pe hota hai. Beech mein inputs badalte rahein, register nahi badalta.
hardwired zero
R0 ($zero, RISC-V mein x0) hamesha 0 padhta hai, usme likhoge to ignore ho jaata hai.
Kaise kaam karta hai (WRITE port, synchronous):
  1. Write register address (5 bits, jaise 00001 = R1) 5-to-32 decoder mein jaata hai.
  2. Decoder ki 32 output lines mein se sirf line 1 = 1 (one-hot). Ye batata hai KAHAN likhna hai.
  3. Har decoder line ek 2-input AND gate mein jaati hai; AND ka doosra input RegWrite hai. Isliye 32 AND gates.
  4. AND ka output = us register ka load enable. en1 = D1 · RegWrite = 1 · 1 = 1. Baaki sab en = 0 (kyunki unki decoder line 0 hai).
  5. Write data (32 bits) saare 32 registers tak wire se pahunchta hai, lekin sirf jiska enable 1 hai woh clock edge pe use pakadta hai.
  6. Agar RegWrite = 0 to saare AND outputs 0: koi register nahi badlega. Decoder batata hai KAHAN, RegWrite batata hai KYA LIKHNA HAI YA NAHI.

Diagram kaise padhein: Left mein lamba box = 5-to-32 decoder, andar 5-bit "Write reg" aata hai. Har decoder output (D0, D1, D2, D31) ek AND gate mein jaata hai; upar se aane wali RegWrite line har AND ka doosra input hai. AND ka output (en0, en1) us register box (32 FFs) ka enable hai. Right mein Write data ki ek lambi line saare registers ko chhooti hai. Trace: Write reg = 00010, RegWrite = 1 → D2 = 1 → en2 = 1 → sirf R2 clock edge pe naya data lega.

Kaise kaam karta hai (READ ports, combinational):
  1. Har register ka 32-bit output do jagah jaata hai: MUX 1 aur MUX 2 (dono 32:1).
  2. Read register 1 (5 bits) MUX 1 ka select hai; Read register 2 (5 bits) MUX 2 ka select hai.
  3. Read register 1 = 00010 → MUX 1 R2 ko "Read data 1" pe bhejta hai. Read register 2 = 00011 → MUX 2 R3 ko "Read data 2" pe bhejta hai.
  4. Koi clock nahi: address diya, gate delay ke baad data aa gaya. Isliye ALU ko operands usi cycle mein mil jaate hain.
  5. "32 bits wide" MUX ka matlab: asal mein 32 chhote 1-bit 32:1 MUX side-by-side, sabka select same 5 bits.

Diagram kaise padhein: Left mein register boxes R0, R1, R2, R31. Har box se line nikal ke DONO trapezium (32:1 MUX) mein jaati hai, isliye har register ka dot (fan-out) dikhta hai. Upar wala MUX ka select = Read register 1, neeche wale ka = Read register 2. Trace: Read register 1 = 00001 → upar wala MUX R1 ko "Read data 1" pe nikalta hai, koi clock arrow nahi hai.

Diagram kaise padhein: Ye poore register file ka bahar se dikhne wala box hai (exam mein yahi sabse pehle banao). Left: Read register 1 (rs, 5 bits), Read register 2 (rt, 5), Write register (rd ya rt, 5), Write data (32). Right: Read data 1 (ALU ka input A), Read data 2 (ALU input B ya memory). Upar RegWrite, neeche CLK jo sirf write ke liye hai. Wire pe tircha slash aur number = us wire mein kitne bits (5 ya 32).

Ek cycle ki kahani (add R1, R1, R2): cycle shuru → purana R1 aur R2 padha (combinational) → ALU ne joda → clock edge pe jawab R1 mein likha. Agar write bhi bina clock ke hota, to naya R1 turant read port pe aata, ALU phir se jodta, phir likhta: ek hi cycle mein value baar-baar badalti (race). Clock edge isko rokta hai. Yahi read-before-write hai.

Formula (n registers, w bits each): address bits k = log₂ n  ·  write decoder = k-to-n  ·  AND gates = n  ·  read MUX = n:1, w bits wide, k select lines, one per read port  ·  storage = n × w bits.
MIPS: 5-to-32 decoder, 32 AND gates, two 32:1 MUXes (32-bit wide, 5 select bits each), 1024 bits.
Solved example 1 (class homework):

An 8 × 16 register file (8 registers, 16 bits each) has 1 write and 2 read ports. Find the address width, decoder size and number of decoder output lines, MUX size, and total bits.

  1. Registers = 8 → address bits = log₂ 8 = 3 (2³ = 8).
  2. Write decoder: 3 inputs, 2³ = 8 outputs → 3-to-8 decoder, 8 output lines.
  3. AND gates with RegWrite: ek per register = 8.
  4. Read ports: 2 MUXes, har ek 8:1, 16 bits wide, 3 select lines.
  5. Total bits = 8 × 16 = 128.

Answer: 3-bit address, 3-to-8 decoder (8 outputs), two 16-bit 8:1 MUXes, 128 bits.

Solved example 2 (mock: 4 × 32 file drawing):

Draw / describe a register file with 4 registers of 32 bits, one write port and two read ports. Label the decoder, write enable and MUX select widths. What does it output if the hardwired-zero version is written with FACEFACE at address 00 and then address 00 is read?

  1. Address bits = log₂ 4 = 2 (2² = 4).
  2. Write side: 2-to-4 decoder; 4 AND gates (decoder line · WE) → load enables of R0 to R3; 32-bit write data bus to all 4.
  3. Read side: two 4:1 MUXes, 32 bits wide, each with a 2-bit select (rd_addr1, rd_addr2).
  4. Write on posedge clk only if WE = 1; reads are plain assign statements (combinational).
  5. Hardwired zero: write to address 00 is dropped, and reading 00 always gives 0.

Answer: 2-to-4 decoder + WE ANDs, two 32-bit 4:1 MUXes with 2-bit selects; reading R0 gives 00000000.

always @(posedge clk)                  // WRITE: only at the clock edge
    if (we) reg_file[wr_addr] <= wr_data;
assign rd_data1 = reg_file[rd_addr1];   // READ: combinational (no clock)
assign rd_data2 = reg_file[rd_addr2];
Galti mat karna: (1) Read port ko clock mat karo: operand ek cycle late milega. (2) RegWrite bhoolna: phir har cycle har register overwrite ho jayega. (3) 32:1 MUX ka select 32 bits NAHI, 5 bits hai. (4) Write side pe MUX aur read side pe decoder likh dena ulta hai: write = decoder, read = MUX.

Trick: "Likhne ke liye Decoder, Dekhne ke liye MUX." Decoder ek line jalata hai (kahan rakhun), MUX ek cheez dikhata hai (kya hai).

Ek line mein: Write = k-to-n decoder (kahan) AND RegWrite (likhun ya nahi), clock edge pe; Read = har port ka ek n:1 MUX, address = select, bina clock.

7.3 Introduction to Finite State Machines

Pehle socho: Vending machine socho: ek drink ₹10 ki, tum ₹5 ke coin daalte ho. Pehla coin daala, kuch nahi nikla, par machine ko yaad hai "₹5 aa chuke". Doosra coin daala, ab drink nikli. Matlab machine ka jawab sirf abhi ke coin pe nahi, pichli history (jo yaad hai) pe bhi depend karta hai. Ye "yaad" hi state hai. Traffic light bhi aisi hi hai: GREEN hai, timer khatam hua to YELLOW, phir RED, phir GREEN. Har light ek state hai. CPU ka control unit bhi yahi karta hai: fetch → decode → execute → write-back.
Definition: A finite state machine (FSM) is a sequential circuit that has a finite number of states, moves from one state to another (a transition) according to its present state and inputs, and produces outputs. Formally it is the 5-tuple (S, I, O, δ, λ): S = set of states, I = inputs, O = outputs, δ = next-state (transition) function, λ = output function.
Mushkil shabd, aasaan matlab:
state
Machine ki "yaad", yaani history ka summary. Vending machine: "₹0 aaye", "₹5 aaye". Hardware mein state flip-flops mein binary number ke roop mein rehti hai.
transition
Ek state se doosri state pe jaana, clock edge pe, input ke hisaab se. Diagram mein arrow.
present state / next state
Present = abhi flip-flops mein kya hai. Next = agli clock edge pe kya hoga.
next-state logic (δ)
Combinational circuit: (present state, input) leke next state nikalta hai. Traffic: (GREEN, T = 1) → YELLOW.
state register
Flip-flops jo present state store karte hain; clock edge pe next state andar le lete hain. FSM ka sirf yahi hissa clocked hai.
output logic (λ)
Combinational circuit jo state (aur Mealy mein input bhi) dekh ke output banata hai. Traffic: state RED → output "Stop".
state diagram
Circle = state, arrow = transition, arrow pe input likha hota hai.
state table
Wahi diagram table mein: har row = ek present state, har column = ek input value, cell mein next state.
encoding
Har state ko binary code dena. Binary: G = 00, Y = 01, R = 10. One-hot: G = 001, Y = 010, R = 100 (har state ka apna flip-flop, ek hi 1).
⌈ ⌉ (ceiling)
"Upar ki taraf round karo". ⌈2.32⌉ = 3, ⌈3⌉ = 3.
reset state
Power on hone pe machine kahan se shuru kare (S0). Diagram mein bahar se aata arrow.
Kaise kaam karta hai (hardware ke 3 blocks):
  1. State register (flip-flops) mein present state rakhi hai, jaise 00 = GREEN.
  2. Next-state logic present state + input dekhta hai: GREEN aur T = 1 → next = 01 (YELLOW).
  3. Clock edge aata hai: state register 01 le leta hai. Ab present state = YELLOW.
  4. Output logic state dekh ke output deta hai: YELLOW → "Slow".
  5. Present state wapas next-state logic mein jaati hai (feedback), aur cycle chalta rehta hai.

Diagram kaise padhein: Teen box left se right: next-state logic → state register (neeche CLK, sirf isme flip-flops) → output logic. State register ke output se ek arrow neeche ghoom ke wapas next-state logic mein jaata hai: yahi "yaad" ka feedback hai. Upar ka highlighted arrow (inputs se seedha output logic tak) sirf Mealy mein hota hai; Moore mein output logic sirf state dekhta hai. Neeche likha hai: Moore output = λ(state), Mealy output = λ(state, input).

Diagram kaise padhein: Teen circle = teen states, har circle mein state ka naam aur output (GREEN/Go, YELLOW/Slow, RED/Stop). Bahar se aata arrow GREEN pe = reset state. Arrow pe "T" = timer khatam hua to aage jao; har circle pe chhota loop "T'" = timer abhi chal raha hai to wahin raho. Trace: GREEN, T = 0 → GREEN; T = 1 → YELLOW; T = 1 → RED; T = 1 → GREEN. Output circle ke andar hai, isliye ye Moore machine hai.

FSM design karne ka step-by-step tarika (traffic light pe poora karke):
  1. Spec samjho: Input T (timer khatam = 1). Output: Go, Slow ya Stop. Order GREEN → YELLOW → RED → GREEN, T = 0 pe wahin ruko.
  2. States list karo (meaning ke saath): G = "green chal raha hai", Y = "yellow", R = "red". Reset state = G.
  3. State diagram banao (D7.3b): har state se har input value ka arrow (T = 0 aur T = 1), dono.
  4. State table banao:
    PresentT = 0T = 1Output

  5. Encoding karo: 3 states → ⌈log₂ 3⌉ = 2 flip-flops (Q1 Q0). G = 00, Y = 01, R = 10. Code 11 kabhi use nahi hota (don't care).
  6. Encoded table + equations:
    Q1 Q0TQ1⁺ Q0⁺
    00 (G)000

Formula: Flip-flops (binary encoding) = ⌈log₂ N⌉  ·  Flip-flops (one-hot) = N
N = number of states. Shortcut: sabse chhoti power of 2 dhoondo jo N ke barabar ya badi ho; uska exponent = flip-flops.
Solved example 1 (flip-flop count):

Find the minimum number of flip-flops (binary encoding) and the number for one-hot encoding for FSMs with 3, 5, 6 and 9 states.

  1. Powers of 2: 2¹ = 2, 2² = 4, 2³ = 8, 2⁴ = 16.
  2. N = 3: 2 se zyada, 4 tak fit → 2² → 2 FFs. One-hot: 3.
  3. N = 5: 4 se zyada, 8 tak fit → 2³ → 3 FFs. One-hot: 5.
  4. N = 6: 8 tak fit → 3 FFs. One-hot: 6.
  5. N = 9: 8 se zyada (2³ = 8 sirf 8 codes deta hai), 16 tak fit → 2⁴ → 4 FFs. One-hot: 9.

Answer: 3 → 2 / 3; 5 → 3 / 5; 6 → 3 / 6; 9 → 4 / 9 (binary / one-hot).

Solved example 2 (write the answer like this):

What is a finite state machine? Draw its general hardware block diagram. (3 marks)

  1. A finite state machine is a sequential circuit with a finite set of states S, inputs I and outputs O; δ gives the next state and λ gives the output.
  2. It has three blocks: next-state logic (combinational), the state register (flip-flops, clocked) and output logic (combinational).
  3. The present state is fed back to the next-state logic, so the next state depends on the present state and the input.
  4. In a Moore machine the output depends on the state only; in a Mealy machine also on the input.
  5. Draw D7.3a. Example: traffic light (GREEN → YELLOW → RED on timer T), or the CPU control unit.

Answer: definition + (S, I, O, δ, λ) + 3-block diagram with feedback + one example.

Diagram kaise padhein: Left box CONTROL ek FSM hai; right box DATAPATH (registers, ALU, MUX, memory) asli kaam karta hai. Upar ka dashed arrow = control signals (RegWrite, ALUSrc, MemWrite) control se datapath ko. Neeche ka arrow = status flags (Zero, overflow, opcode) datapath se control ko wapas. Isliye ALU ka Zero flag ek status signal hai, control signal nahi.

Galti mat karna: (1) Reset state bhoolna. (2) Kisi state se kisi input ka arrow chhod dena: har state se har input value ka arrow chahiye (traffic light mein T' self-loops bhi). (3) One-hot ke liye ⌈log₂ N⌉ likhna: one-hot mein N flip-flops lagte hain. (4) 9 states ke liye 3 FFs bolna: 3 FFs sirf 8 codes dete hain.

Trick: FSM = "Socho (next-state logic) → Yaad rakho (state register) → Bolo (output logic)". Sirf "yaad rakho" wale dabbe mein clock hai.

Ek line mein: FSM = states + inputs + transitions + outputs; hardware = next-state logic → state register (clock) → output logic, state ka feedback; FFs = ⌈log₂ N⌉ (binary) ya N (one-hot).

7.4 Moore vs Mealy Machines

Pehle socho: Do tarah ke chowkidar. Moore chowkidar sirf apni "position" dekh ke bolta hai: woh gate pe khada hai to "andar aao" bolega, bas. Uska jawab tab badalta hai jab woh position badalta hai (agla clock edge). Mealy chowkidar position + tumhara chehra (abhi ka input) dono dekhta hai, aur turant bol deta hai, position badalne ka intezaar nahi karta. Isliye Mealy ek cycle pehle jawab deta hai, par agar input hil-dul raha ho (glitch) to uska jawab bhi hilta hai.
Definition: In a Moore machine the outputs depend only on the present state, λ = f(state). In a Mealy machine the outputs depend on the present state and the present inputs, λ = f(state, input).
Mushkil shabd, aasaan matlab:
output in the circle (Moore)
State diagram mein output state ke circle ke andar likha jaata hai: "S4 / 1". Us state mein ho to output 1, chahe input kuch bhi ho.
output on the arrow (Mealy)
Arrow pe "input / output" likhte hain: "1/1" = input 1 aaya to output 1 aur is arrow pe jao.
glitch
Signal mein galti se aaya chhota sa spike, jaise input ek pal ke liye 0 → 1 → 0 ho gaya. Mealy output input se seedha juda hai, isliye ye spike output mein bhi aa sakta hai.
registered output
Output ke aage ek flip-flop laga dena; glitch hat jaata hai par output ek cycle late ho jaata hai (Moore jaisa).
Kaise kaam karta hai (timing ka farak):
  1. Maan lo detector ko "1011" dhoondhna hai aur abhi "101" dekh chuka hai (state S3).
  2. Ab bit 4 = 1 aata hai, clock edge abhi nahi aaya.
  3. Mealy: output logic ko state S3 aur input 1 dono dikh rahe hain, to usi cycle mein output = 1 (arrow S3 —1/1→).
  4. Moore: output sirf state se aata hai. Abhi state S3 hai jiska output 0. Clock edge pe state S4 banti hai, tab output = 1, yaani agle cycle mein.
  5. Isliye Moore ko ek extra state (S4, "match ho gaya") chahiye jisme output 1 likha ho. Mealy mein ye kaam arrow kar deta hai.
  6. Dono same pattern pakadte hain; farak sirf kab output aata hai aur kitni states lagti hain.

Solved example (write the answer like this):

Compare Moore and Mealy machines (any five points). (5 marks)

  1. Moore: output is a function of the present state only; Mealy: output is a function of the present state and the present input.
  2. Moore writes the output inside the state circle; Mealy writes input/output on each transition arrow.
  3. Mealy output responds in the same cycle as the input; Moore output appears one clock cycle later.
  4. Moore output is glitch-free; Mealy output can glitch when the input glitches.
  5. Mealy usually needs fewer states (1011 detector: Mealy 4, Moore 5).

Mealy → Moore conversion (class homework): jis Mealy state mein alag-alag outputs wale arrows aate hain, use har output ke liye do copies mein tod do (ek copy "out 0", ek "out 1"). 1011 Mealy mein S1 do tarah se aata hai: S0 —1/0→ S1 aur S3 —1/1→ S1. Galti mat karna: (1) Ek hi diagram mein output circle mein BHI aur arrow pe BHI likh dena: ek notation choose karo. (2) Ye kehna ki Moore aur Mealy alag patterns detect karte hain: pattern same, sirf timing alag. (3) "Mealy late hai" bolna: ulta, Mealy ek cycle pehle output deta hai.

Trick: Moore = "O" = gol circle ke andar output. Mealy = arrow pe output. Mealy "jaldi bolta hai" (same cycle), Moore "soch ke bolta hai" (agle cycle).

Ek line mein: Moore = output sirf state se (circle mein, ek cycle baad, glitch-free, zyada states); Mealy = output state + input se (arrow pe, same cycle, glitch ho sakta hai, kam states).

7.5 Worked Example: Sequence Detector 1011

Pehle socho: Tum ek lambi line mein aane wale bits dekh rahe ho: 1, 0, 1, 1, 0, 1, 1, 0. Kaam: jab bhi aakhri 4 bits "1011" hon, ghanti bajao. Tumhe saare purane bits yaad rakhne ki zarurat nahi, sirf itna ki "abhi tak pattern ka kitna hissa match ho chuka hai". Jaise password type karte waqt: "maine pehle 3 letters sahi daale hain". Galat letter aaya to zero se shuru karna zaruri nahi: ho sakta hai galat letter ke saath ka aakhri hissa naye password ki shuruaat ho. Telecom mein frame ki shuruaat dhoondhne ke liye yahi detector use hota hai (DS1 pattern 001011, SONET 11110110).
Definition: A sequence detector is an FSM that receives one bit per clock cycle on a serial input and outputs 1 when a specified bit pattern has just appeared. With overlapping detection, the end of one match may be the beginning of the next match; with non-overlapping detection, the machine starts afresh after every match.
Mushkil shabd, aasaan matlab:
serial input
Ek wire, har clock pe ek bit. Stream 10110110 ka matlab: pehle 1, phir 0, phir 1 (bit 1 sabse pehle).
prefix
Pattern ki shuruaat ke tukde. 1011 ke prefixes: "1", "10", "101", "1011".
suffix
Ab tak aaye input ke aakhri ke tukde. "1010" ke suffixes: "0", "10", "010", "1010".
longest suffix that is a prefix
Aakhri wale tukdon mein se sabse lamba jo pattern ki shuruaat bhi ho. "1010" mein: "10" prefix hai (1011 bhi "10" se shuru hota hai), "010" nahi. To jawab "10". Yahi batata hai galti ke baad kahan jaana hai.
overlap
Match ke aakhri bits agle match mein reuse ho sakte hain. Stream 1011011: bits 1–4 = 1011 aur bits 4–7 = 1011, bit 4 dono mein. Overlap: 2 matches. Non-overlap: 1.
fall-back edge (failure arrow)
Galat bit aane pe peeche ki state pe jaane wala arrow.
