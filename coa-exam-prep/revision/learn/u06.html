Unit 6 · Registers, Counters & Shift Registers

Is unit ki kahani: Unit 5 mein ek D flip-flop = 1 bit ki memory bani. Ab inhe jodte hain. Ek line mein rakho, ek clock do → register (poora word, jaise PC). Thodi logic jodo jo next value banaye → counter (0, 1, 2, 3 ginta hai; timers, PC). Ek ka Q agle ke D mein do → shift register (bits ek ek karke khisakte hain; serial ↔ parallel, UART). Unit 7 in registers se register file aur FSM banayega, aur Unit 13 ka datapath inhi pe chalta hai.

6.1 Scaling from flip-flops to registers

Pehle socho: Ek flip-flop sirf 1 bit yaad rakhta hai. Par CPU ko poora number yaad rakhna hai, jaise 32-bit address. To 32 flip-flops ek line mein lagao aur sabko ek hi clock do, taaki saare bits ek hi instant pe ek saath save hon. Jaise ek board pe 8 switches jinhe ek hi haath ek saath dabata hai.
Definition: A register is a group of n flip-flops sharing a common clock that stores an n-bit word; all n bits are captured simultaneously at the active clock edge.
Mushkil shabd, aasaan matlab:
word
Bits ka group jo ek unit ki tarah use hota hai: 8, 16, 32 ya 64 bits.
common clock
Ek hi CLK wire jo har flip-flop ke clock pin tak jaati hai.
PC / IR
Program Counter (agle instruction ka address), Instruction Register (abhi fetch hua instruction). Dono registers hain.
pipeline register
Pipeline ke do stages ke beech ka register (Unit 14), jaise IF/ID.
Kaise kaam karta hai:
  1. n-bit register = n D flip-flops, ek bit ke liye ek.
  2. Har flip-flop ka apna D input (D0, D1, D2, D3) aur apna Q output (Q0 se Q3).
  3. Clock sab ka common. Rising edge pe: Q3Q2Q1Q0 ← D3D2D1D0, ek saath.
  4. Example: D = 1010 aur edge aaya → Q = 1010. Agle edge pe D = 0110 → Q = 0110.
  5. Problem: ye plain register har edge pe naya D le leta hai, value hold nahi kar sakta. Isliye real registers mein load enable aur reset chahiye (6.2).
  6. Cost linear hai: 32-bit register = 32 flip-flops. Isliye registers kam hote hain aur badi memory SRAM/DRAM se banti hai (Unit 8).

Diagram kaise padhein: Chaar D-FF boxes ek line mein. Har box ka D upar/left se, Q right se bahar. Neeche ek horizontal CLK line jo har box ke clock pin ko chhooti hai. Ek hi CLK line = ek hi instant pe sab load.

Solved example (4 marks, model answer):

What is a register? Draw a 4-bit register using D flip-flops and name four registers found in a CPU. How many flip-flops does a 32-bit register need?

  1. Definition: "A register is a group of n D flip-flops sharing one clock that stores an n-bit word, all bits being loaded at the same clock edge."
  2. Draw D6.1a.
  3. CPU registers: PC, IR, general-purpose registers ($t0, $s0), pipeline registers (IF/ID).
  4. 32-bit → ek bit ek FF → 32 flip-flops.

Answer: definition + diagram + PC, IR, GPRs, pipeline registers; 32 flip-flops.

Galti mat karna: Har bit ke liye alag clock mat banao; common clock hi register ka matlab hai. Aur Q → D chain mat banao (wo shift register hai, 6.5). ALU register nahi hai (wo combinational hai).
Ek line mein: Register = n D flip-flops + ek common clock, jo n-bit word ek saath store karta hai.

6.2 Registers: load enable, reset, CPU preview

Pehle socho: Locker socho. Ghanti (clock) har second bajti hai, par locker ka saamaan tabhi badalta hai jab tum darwaza kholte ho (LOAD = 1). Darwaza band ho (LOAD = 0) to ghanti chahe kitni baar baje, andar wahi rehta hai. RESET = locker khaali karna (sab 0). Plain register har edge pe overwrite karta tha; load enable usse hold karna sikhata hai.
Definition: Load enable lets a register either capture new data or keep its present value at each clock edge; it is built with a 2:1 multiplexer in front of each flip-flop that selects D when LOAD = 1 and the flip-flop's own Q when LOAD = 0. Reset forces the register to a known value (all 0s): a synchronous reset acts at the next active clock edge, an asynchronous reset acts immediately.
Mushkil shabd, aasaan matlab:
2:1 MUX
Do inputs mein se ek chunne wala switch. Select = 1 → input 1 bahar, select = 0 → input 0 bahar.
feedback (Q → MUX)
Flip-flop ka apna output MUX ke input 0 pe wapas. LOAD = 0 pe flip-flop apni hi value dobara load karta hai, yaani hold.
LOAD (ld)
Control bit: 1 = naya data lo, 0 = purana rakho.
synchronous / asynchronous reset
Sync: rst = 1 karke agle edge ka wait. Async: rst = 1 hote hi turant 0, clock ka wait nahi.
clock gating
Clock ko AND gate se rokna. Yahan galat tareeka: delay (skew) aur glitch laata hai.
priority
Dono ek saath aayein to kaun jeetega. Labs mein: reset > load > hold.
Kaise kaam karta hai:
  1. Har bit ke D pin ke aage ek 2:1 MUX. MUX input 1 = naya data, input 0 = us flip-flop ka apna Q. Select = LOAD.
  2. LOAD = 1 → MUX naya data deta hai → edge pe Q = data.
  3. LOAD = 0 → MUX Q hi wapas deta hai → edge pe Q = Q (wahi value dobara) → hold.
  4. Equation: Q⁺ = LOAD·D + LOAD'·Q (yahi 2:1 MUX ka formula hai).
  5. Clock ko kabhi mat roko (AND(CLK, LOAD) mat banao); clock saaf rakho aur MUX se decide karo.
  6. Reset upar se: rst = 1 → Q⁺ = 0, chahe LOAD kuch bhi ho.
  7. Verilog (sync reset): always @(posedge clk) if (rst) q <= 0; else if (ld) q <= d; (else nahi likha → hold). Async: always @(posedge clk or posedge rst).

Solved example (5 marks):

Explain load enable and reset in a register. Draw one bit with a 2:1 MUX and write Verilog for an 8-bit register with synchronous reset and load.

  1. Draw D6.2a; write Q⁺ = LOAD·D + LOAD'·Q.
  2. "LOAD = 1 selects the new data; LOAD = 0 feeds Q back so the register reloads its own value and holds. The clock itself is never gated."
  3. Reset: "Synchronous reset clears the register at the next active edge; asynchronous reset clears it immediately without the clock (used for power-on)."
  4. Verilog: 
    module register_8bit_rst (input clk, rst, ld, input [7:0] d, output reg [7:0] q);
    always @(posedge clk)
        if (rst)     q <= 8'b0;     // highest priority
        else if (ld) q <= d;        // load
                                    // else: hold
endmodule

Answer: MUX per bit with Q feedback; priority rst > ld > hold; sync reset waits for the edge.

Galti mat karna: (1) LOAD = 0 pe MUX "0" bhejta hai samajhna: nahi, wo Q bhejta hai (0 bhejega to wo reset ban jaayega). (2) Sync reset ko turant maan lena: t = 30 pe rst = 1 hua par q t = 35 (edge) pe hi 0 hua. (3) if-else mein load ko reset se pehle likhna.

Trick: "Load band = apna hi Q wapas."

Ek line mein: Har bit ke aage 2:1 MUX: LOAD = 1 naya D, LOAD = 0 apna Q (hold); reset sabse upar, sync reset edge ka wait karta hai, async turant.

6.3 Asynchronous (ripple) vs synchronous counters

Pehle socho: Binary mein ginti dekho: 0111 → 1000. Koi bit kab badalta hai? Jab uske neeche (right) ke saare bits 1 hon. Do tarike se ye kara sakte hain. Ripple: dominoes ki line, pehla gira tab doosra, phir teesra: sasta par slow, aur girte waqt beech mein galat ginti dikhti hai. Synchronous: soldiers jo drum beat pe sab ek saath kadam rakhte hain: thoda extra logic, par fast aur saaf.
Definition: A counter is a sequential circuit that steps through a fixed sequence of states (usually binary counting) on successive clock pulses. In an asynchronous (ripple) counter only the first flip-flop receives the clock and each later flip-flop is clocked by the output of the previous one; in a synchronous counter all flip-flops share the same clock and logic decides which bits toggle.
Mushkil shabd, aasaan matlab:
T flip-flop (reminder)
T = 1 → har active edge pe ulta (toggle); T = 0 → hold.
propagation delay tpd
Clock aane se Q badalne tak ka time (ek flip-flop ka). Jaise 10 ns.
ripple
Lahar: badlav ek flip-flop se agle, phir agle tak, ek ke baad ek pahunchta hai.
settle time
Clock ke baad sahi final count dikhne mein lagne wala time. Ripple: n × tpd.
glitch / false state
Thodi der ke liye dikhne wala galat count (jaise 7 → 8 ke beech 6, 4, 0).
divide-by-2
Toggle FF ka output clock ki aadhi frequency pe chalta hai: 2 clock pulses = ek poora output cycle.
Kaise kaam karta hai:
  1. Counting rule: Q0 har clock pe badalta hai; Q1 tab jab Q0 = 1; Q2 tab jab Q1 = Q0 = 1. Isliye Q0 = clock ÷ 2, Q1 = ÷ 4, Q2 = ÷ 8; bit k ki frequency = fclk / 2k+1.
  2. Ripple build: saare T = 1 (sab toggle karne ko ready). Sirf FF0 ko clock. FF1 ka clock = Q0, FF2 ka clock = Q1. Flip-flops falling-edge (bubble) wale hain, to FF1 tab toggle karta hai jab Q0 1 → 0 girta hai. Ye "neeche ke bits 1 se 0 hue = carry" hi hai.
  3. Ripple trace (3-bit, 0 → 7 → 0): clock 1: Q0 0 → 1 → 001. Clock 2: Q0 1 → 0 (gira) → Q1 toggle 0 → 1 → 010. Clock 3: Q0 → 1 → 011. Clock 4: Q0 gira → Q1 1 → 0 gira → Q2 0 → 1 → 100. Isi rule se 101, 110, 111, aur clock 8 pe teeno girte hain → 000.
  4. Ripple delay: clock 4 jaise case mein Q2 tab badalta hai jab Q1 badal chuka, jo Q0 ke baad badla: 3 delays. n-bit mein worst case n × tpd. Clock period isse lamba hona chahiye: fmax = 1 / (n × tpd).
  5. False states (4-bit, 7 → 8): neeche table. Har step ek tpd baad.
  6. Synchronous: sab FFs ko same clock. T inputs AND gates se: T0 = 1, T1 = Q0, T2 = Q0·Q1, T3 = Q0·Q1·Q2 (6.4). Edge pe jo bits badalne hain sab ek saath badalte hain → koi false state nahi; delay = ek FF delay + AND chain, n ke saath nahi badhta.

Formula: Ripple settle time = n × tpd; fmax = 1 / (n × tpd); bit k frequency = fclk / 2k+1.
1 / ns = GHz = 1000 MHz. So f (MHz) = 1000 / T (ns).
Solved example 1 (class quiz type):

(i) A 4-bit ripple counter has tpd = 10 ns. Max frequency? (ii) A 12-bit ripple counter with 0.6 ns flip-flops? (iii) Mock: 12-bit with 2 ns? (iv) 3-bit with 5 ns: worst settling time?

  1. (i) 4 × 10 = 40 ns → f = 1000 / 40 = 25 MHz.
  2. (ii) 12 × 0.6 = 7.2 ns → f = 1000 / 7.2 = 138.9 MHz ≈ 139 MHz.
  3. (iii) 12 × 2 = 24 ns → f = 1000 / 24 = 41.67 MHz.
  4. (iv) 3 × 5 = 15 ns.

Answer: 25 MHz; ≈ 139 MHz; 41.67 MHz; 15 ns.

Solved example 2 (divide-by):

(i) A binary counter is driven by a 16 MHz clock. Frequency of Q2? (ii) How many T flip-flops divide a 32,768 Hz watch crystal down to 1 Hz?

  1. (i) Q2 = f / 22+1 = 16 / 8 = 2 MHz.
  2. (ii) Har T flip-flop ÷2 karta hai. 32,768 = 2¹⁵ (2¹⁰ = 1024, × 32 = 32,768). To 15 baar ÷2 → 1 Hz → 15 flip-flops.

Answer: 2 MHz; 15 flip-flops.

Galti mat karna: (1) "Ripple counter mein clock hai, to synchronous hai" galat: clock sirf FF0 ko milta hai. (2) Ripple delay ko sirf tpd likhna: ye n × tpd hai. (3) Rising-edge FF ka clock seedha Q se dena: wo down counter ban jaata hai; up ke liye falling-edge FF (ya Q') chahiye.

Trick: "Ripple = dominoes, sync = drum pe march." 7 → 8 ripple: "7, 6, 4, 0, 8" (har baar ek aur bit gira).

Ek line mein: Ripple counter mein har FF pichhle ke Q se clock hota hai (sasta, n × tpd delay, false states); synchronous mein sab ek clock pe, AND logic se toggle (fast, glitch-free).

6.4 4-bit synchronous up-counter design

Pehle socho: Synchronous counter mein sab flip-flops ek saath clock hote hain, to har flip-flop ko pehle se batana padega: "agle edge pe tum badloge ya nahi?" T flip-flop ke liye ye bas T input hai: T = 1 → badlo. Kaam: har bit ke liye T ka formula nikalna. Rule wahi: bit tab badalta hai jab neeche ke saare bits 1 hon, isliye T = neeche ke saare Q ka AND.
Definition: A synchronous up-counter is designed by writing the count sequence as a present-state/next-state table, finding each flip-flop input from the flip-flop's excitation table, minimising each input with a K-map, and wiring all flip-flops to a common clock. For T flip-flops this gives T0 = 1, T1 = Q0, T2 = Q0·Q1, T3 = Q0·Q1·Q2.
Mushkil shabd, aasaan matlab:
present state / next state
Abhi ka count (Q) aur agle edge ke baad ka count (Q⁺). 0101 ka next state 0110.
excitation table (reminder)
Q → Q⁺ ke liye input kya do. T flip-flop: T = Q ⊕ Q⁺ (bit badalna hai to 1). D flip-flop: D = Q⁺.
count enable (EN)
EN = 0 → counter ruka; EN = 1 → ginta hai. Har T mein EN AND kar do.
terminal count (tc)
Output jo sirf aakhri count (1111) pe 1 hota hai. Agle counter ko enable karne ke kaam aata hai (cascading).
⌈log₂ N⌉
Wo sabse chhota k jisme 2ᵏ ≥ N. N = 12 → 2⁴ = 16 ≥ 12 → 4.
Kaise kaam karta hai (design steps, class flow):
  1. Step 1, sequence: 0000 → 0001 → 0010, har edge pe +1 karte hue 1111 tak, phir wapas 0000 (16 states, 4 FFs).
  2. Step 2, state table: har present state ke saamne next state (present + 1) likho.
  3. Step 3, excitation: har bit ke liye T = Q ⊕ Q⁺: jo bit badla wahan 1, jo nahi badla wahan 0.
  4. Step 4, minimise: T columns dekho (neeche table). T0 column mein sab 1 → T0 = 1. T1 sirf un rows mein 1 jahan Q0 = 1 → T1 = Q0. T2 sirf jahan Q1 = Q0 = 1 (0011, 0111, 1011, 1111) → T2 = Q1·Q0. T3 sirf 0111 aur 1111 mein, yaani Q2 = Q1 = Q0 = 1 → T3 = Q2·Q1·Q0. (K-map mein bhi: T2 ke 1s 4 cells ka group banate hain jahan Q1 = Q0 = 1, Q3 aur Q2 cancel.)
  5. Step 5, wire: 4 T-FFs, common clock; T0 = 1 (ya EN), T1 se Q0, ek AND (Q0, Q1) se T2, doosra AND (pichhla AND, Q2) se T3. Ye "AND chain" hai.

Doosra AND pehle AND ka output aur Q2 leta hai → T3. Trace count = 0011: T1 = 1, AND1 = 1·1 = 1 → T2 = 1, AND2 = 1·0 = 0 → T3 = 0. Edge pe Q0, Q1, Q2 toggle → 0100 ✓.

Formula: Up: T0 = 1, T1 = Q0, T2 = Q0·Q1, T3 = Q0·Q1·Q2 (with enable: AND every T with EN).
D flip-flops: D = Q ⊕ T → D0 = Q0', D1 = Q1 ⊕ Q0, D2 = Q2 ⊕ Q1Q0, D3 = Q3 ⊕ Q2Q1Q0.
Down: T0 = 1, T1 = Q0', T2 = Q0'·Q1'. Up/down: T1 = UP·Q0 + UP'·Q0'. tc = Q3Q2Q1Q0. FFs for mod-N = ⌈log₂ N⌉.
Solved example 1 (mock 6 marks, D flip-flops):

Design a 3-bit synchronous up-counter using D flip-flops: state table, next-state equations and circuit.

  1. State table: 000 → 001 → 010 → 011 → 100 → 101 → 110 → 111 → 000.
  2. D flip-flop excitation: D = Q⁺, isliye D2 D1 D0 = next state column.
  3. Bit 0 har baar ulta: D0 = Q0'.
  4. Bit 1 tab ulta jab Q0 = 1: "ulta jab X = 1" = Q ⊕ X → D1 = Q1 ⊕ Q0.
  5. Bit 2 tab ulta jab Q1 = Q0 = 1 → D2 = Q2 ⊕ (Q1·Q0).
  6. Check 011: D0 = 0, D1 = 1 ⊕ 1 = 0, D2 = 0 ⊕ 1 = 1 → 100 ✓. Check 111: D0 = 0, D1 = 0, D2 = 1 ⊕ 1 = 0 → 000 ✓.
  7. Circuit: 3 D-FFs on one clock; inverter Q0 → D0; XOR(Q1, Q0) → D1; AND(Q1, Q0) → XOR with Q2 → D2.

Answer: D0 = Q0', D1 = Q1 ⊕ Q0, D2 = Q2 ⊕ Q1Q0.

Solved example 2 (down counter + FF count):

(i) Find the T equations of a 3-bit synchronous DOWN counter. (ii) Minimum flip-flops for mod-12, mod-20 and for dividing 1 MHz to 1 kHz?

  1. (i) Down count mein bit tab badalta hai jab neeche ke saare bits 0 hon (100 → 011: teeno badle). T0 = 1, T1 = Q0', T2 = Q0'·Q1'.
  2. Check 100 → 011: T0 = 1, T1 = 1 (Q0 = 0), T2 = 1·1 = 1 → teeno toggle → 011 ✓. Check 010 → 001: T1 = 1, T2 = Q0'Q1' = 1·0 = 0 → Q1, Q0 toggle → 001 ✓.
  3. (ii) mod-12: 2³ = 8 < 12 ≤ 16 = 2⁴ → 4. mod-20: 16 < 20 ≤ 32 → 5. 1 MHz → 1 kHz = ÷1000 → mod-1000: 512 < 1000 ≤ 1024 → 10.

Answer: T0 = 1, T1 = Q0', T2 = Q0'Q1'; 4, 5, 10 flip-flops.

Galti mat karna: T2 = Q1 likhna (galat; T2 = Q0·Q1, saare neeche ke bits). Down counter mein Q ki jagah Q' use karna bhool jaana. Mod-N ke FFs N/2 ya log₂ N ko round-down karna: hamesha round up.

Trick: "Neeche sab 1 → main palat jaata hoon" (up). Down mein "neeche sab 0".

Ek line mein: Synchronous up-counter: common clock, T0 = 1 aur har agla Tk = neeche ke saare Q ka AND (T1 = Q0, T2 = Q0Q1, T3 = Q0Q1Q2).

6.5 Shift registers: SISO, SIPO, PISO, PIPO

Pehle socho: Aag bujhane wali bucket line socho: har whistle (clock) pe har aadmi apni bucket agle ko de deta hai. Bits bhi aise hi ek flip-flop se agle mein khisakte hain. Kyun chahiye? Bahut se cables sirf ek wire pe data bhejte hain (USB, UART): CPU ke paas 8-bit byte hai (parallel) aur wire pe ek ek bit bhejna hai (serial). Shift register yahi badalta hai: parallel ↔ serial.
Definition: A shift register is a chain of flip-flops on a common clock in which the output of each flip-flop drives the input of the next, so the stored bits move one position per clock pulse. By how data enters and leaves it is classified as SISO, SIPO, PISO or PIPO.
Mushkil shabd, aasaan matlab:
serial
Ek wire, ek time pe ek bit. 4 bits bhejne mein 4 clocks.
parallel
n wires, saare bits ek saath, 1 clock.
SISO / SIPO / PISO / PIPO
Serial-In Serial-Out, Serial-In Parallel-Out, Parallel-In Serial-Out, Parallel-In Parallel-Out. Pehla shabd = data kaise andar, doosra = kaise bahar.
UART
Serial communication port. Transmitter (TX) = PISO, Receiver (RX) = SIPO.
Shift/Load' (sh_ld)
PISO ka control: ek value pe parallel load, doosri pe shift. Portal code: sh_ld = 0 load, 1 shift.
delay line
Signal ko kuch clocks late karna. 4-bit SISO = 4 clock delay.
Kaise kaam karta hai:
  1. SISO: 4 D-FFs chain: serial in → FF0 → FF1 → FF2 → FF3 → serial out (Q3). Har edge pe har bit ek aage. Verilog: q <= {q[2:0], serial_in}; serial_out = q[3];
  2. SIPO: wahi chain, par har Q bahar nikala (taps). 4 clocks baad poora word Q3Q2Q1Q0 pe ek saath padh lo.
  3. PISO: har D ke aage 2:1 MUX. Load mode: MUX parallel bit chunta hai, ek edge pe poora word andar. Shift mode: MUX pichhle FF ka Q chunta hai, har edge pe ek bit bahar. Plain chain parallel data le hi nahi sakti, isliye MUX zaroori.
  4. PIPO: koi chain nahi; ye bas load wala register hai (buffer).

Solved example 2 (lab MCQ type):

6.E1 Ring, Johnson, mod-N, divide-by-N, LFSR

Pehle socho: Shift register ke last output ko wapas pehle input mein jod do to bits gol gol ghoomte rehte hain, jaise musical chairs. Isse aise counters bante hain jinhe decode karna aasaan hai (ring, Johnson). Kabhi 16 states nahi, sirf 6 ya 10 chahiye (ghadi ke seconds, decimal digit): mod-N counter. Aur feedback mein XOR daalo to "random jaisa" sequence milta hai (LFSR), jo testing aur CRC mein kaam aata hai.
Definition: A ring counter is a shift register whose last output is fed back to its first input, circulating a single 1 through n states. A Johnson (twisted-ring) counter feeds back the complement of the last output and has 2n states. A mod-N counter counts 0 to N − 1 and then returns to 0. An LFSR (linear feedback shift register) feeds back the XOR of selected bits; a maximal-length n-bit LFSR cycles through 2ⁿ − 1 non-zero states.
Mushkil shabd, aasaan matlab:
preset
Shuru mein ek fixed value daal dena (ring counter mein 0001). Bina preset ke 0000 → 0000 hi ghoomta rahega.
one-hot
Exactly ek bit 1 (0100). Ring counter ka har state one-hot hai, isliye decoder ki zarurat nahi.
mod-N
N states wala counter. Mod-6: 0, 1, 2, 3, 4, 5, 0.
decode & reset
Jab counter N pe pahunche, AND gate se pehchaano aur clear kar do.
unused / invalid states
Patterns jo sequence mein kabhi nahi aate. 4-bit Johnson: 16 − 8 = 8.
tap
LFSR ke wo bits jinka XOR feedback banta hai.
Kaise kaam karta hai:
  1. Ring counter (4-bit): SISO chain + Q3 → D0. Preset 0001. Har edge pe 1 ek jagah left khisakta hai, Q3 ka bit wapas Q0 mein: 0001 → 0010 → 0100 → 1000 → 0001. n FFs = n states (4).
  2. Johnson counter (4-bit): feedback Q3' (ulta) → D0. Start 0000. Trace: 0000 (Q3 = 0, Q3' = 1 andar) → 0001 → 0011 → 0111 → 1111 (ab Q3 = 1, andar 0 jaata hai) → 1110 → 1100 → 1000 → 0000. 8 states = 2n. Har step mein sirf ek bit badalta hai, isliye 2-input gate se glitch-free decode.
  3. 3-bit Johnson (mock): 000 → 001 → 011 → 111 → 110 → 100 → 000: 6 states = 2 × 3.
  4. Mod-N, method A (detect N, async reset): normal binary counter, aur jaise hi count N banta hai, AND gate use pehchaan ke saare FFs clear kar deta hai. N thodi der (few ns) ke liye dikhta hai: glitch state.
  5. Mod-N, method B (detect N − 1, synchronous reset / parallel load): jab count N − 1 ho, agle edge pe 0 load karo. Koi glitch state nahi, isliye production designs mein preferred. Verilog: if (q == N-1) q <= 0; else q <= q + 1;
  6. Divide-by-N: mod-N counter ka terminal count (ya MSB) har N clocks mein ek baar → f / N. Binary counter ka bit k = f / 2k+1.
  7. LFSR (4-bit, x⁴ + x³ + 1): shift left, naya Q0 = Q3 ⊕ Q2. Start 0001: 0001 → 0010 → 0100 → 1001 → 0011 → 0110 → 1101 → 1010 → 0101 → 1011 → 0111 → 1111 → 1110 → 1100 → 1000 → 0001. 15 states = 2⁴ − 1. 0000 kabhi nahi aata: 0000 se 0 ⊕ 0 = 0, hamesha 0000 (lock-up), isliye wo exclude.

Solved example 1 (mod-6 counter):

Design a mod-6 counter (0 to 5) from a binary up-counter. Give the reset logic for both methods and the counting sequence.

  1. FFs: ⌈log₂ 6⌉ = 3 (2³ = 8 ≥ 6).
  2. Sequence: 000 → 001 → 010 → 011 → 100 → 101 → 000 (6 states).
  3. Method A (class: reset at 6): 6 = 110. 0 se 6 tak sirf 6 mein Q2 = Q1 = 1 (7 = 111 kabhi aata hi nahi). To CLR = Q2·Q1 → async clear. 110 bas kuch ns dikhta hai, phir 000.
  4. Method B (sync, no glitch): 5 = 101. 0 se 5 mein sirf 5 mein Q2 = Q0 = 1. Jab Q2·Q0 = 1 → agle edge pe 000 load.
  5. Check method B: 100 pe Q0 = 0 → normal count → 101. 101 pe Q2·Q0 = 1 → edge pe 000 ✓.

Answer: 3 FFs; async clear = Q2·Q1 (detect 6) or sync reset when Q2·Q0 = 1 (detect 5); sequence 0 to 5.

Solved example 2 (mod-10 / decade counter):

Design a mod-10 counter. How many flip-flops, and what reset logic?

  1. FFs: 2³ = 8 < 10 ≤ 16 = 2⁴ → 4 FFs.
  2. Sequence 0000 to 1001 (0 to 9), phir 0000.
  3. Method A: 10 = 1010. Counting upar jaate hue Q3 = Q1 = 1 pehli baar 1010 pe hota hai (8 = 1000, 9 = 1001 mein Q1 = 0). CLR = Q3·Q1.
  4. Method B: 9 = 1001. 0 se 9 mein sirf 9 mein Q3 = Q0 = 1 (8 = 1000 mein Q0 = 0). Sync reset jab Q3·Q0 = 1.
  5. Unused states: 16 − 10 = 6 (1010 se 1111).

Answer: 4 FFs; CLR = Q3·Q1 (async, detect 10) or sync reset on Q3·Q0 (detect 9).

Solved example 3 (quiz NAT/MCQ):

(i) States of a 5-bit Johnson counter? (ii) Unused states of a 4-bit Johnson counter? (iii) States of an 8-bit maximal LFSR? (iv) A 4-bit ring counter preset to 1000 rotating left: next state?

  1. (i) 2n = 2 × 5 = 10.
  2. (ii) 2⁴ − 2 × 4 = 16 − 8 = 8.
  3. (iii) 2⁸ − 1 = 255.
  4. (iv) Rotate left: {q[2:0], q[3]} = 000 followed by 1 → 0001.

Answer: 10; 8; 255; 0001.

Galti mat karna: (1) Ring counter ko preset na karna (0000 hamesha 0000). (2) Johnson ke states 2ⁿ likhna: 2n hai. (3) LFSR ke 2ⁿ states likhna: all-zero exclude → 2ⁿ − 1. (4) "Decode & reset" ko glitch-free bolna: async clear mein N thodi der dikhta hai; parallel-load / sync method glitch-free hai.

Trick: 4 FFs ke liye "4, 8, 15, 16" = ring, Johnson, LFSR, binary.

Ek line mein: Ring = n states (Q3 → D0), Johnson = 2n (Q3' → D0), LFSR = 2ⁿ − 1 (XOR feedback); mod-N = count N (async clear) ya N − 1 (sync reset, no glitch) detect karke 0 pe wapas.
