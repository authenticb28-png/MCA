Unit 2 · Logic Minimisation & Universal Gates

Is unit ki kahani: Unit 1 mein laws se expression chhota kiya, par har baar "kaunsa law lagaun?" sochna padta tha. Is unit mein ek seedha tareeka hai: truth table → Σm/ΠM → K-map pe gole banao → minimum expression. Phir De Morgan aur bubble pushing se wahi circuit sirf NAND ya sirf NOR gates se banana seekhte hain, kyunki factory mein NAND sabse sasta hai. Unit 3 mein inhi tricks se MUX, decoder aur adders design honge.

2.1 Motivation for Minimisation (Cost/Power)

Pehle socho: Ek hi cake ki do recipes: ek mein 16 steps, doosri mein 2. Cake same bana, par doosri mein mehnat, gas, samay sab kam. Circuit mein bhi same truth table kai tarah se ban sakti hai; jisme kam gates hon wo chhota, sasta, thanda aur fast.
Definition: Logic minimisation is the process of finding the simplest circuit (fewest gates, gate inputs, literals and logic levels) that implements a given Boolean function, i.e. with the same truth table.
Mushkil shabd, aasaan matlab:
literal
Variable ka ek appearance (seedha ya bar wala). AB + AB' + A'B = 6 literals.
area
Chip pe gates ki jagah. Chhota die → ek wafer pe zyada chips → sasta.
dynamic power
Gates ke switch (0↔1) hone mein lagne wali bijli. Kam gates → kam switching → kam power.
propagation delay
Input badalne ke baad output badalne mein lagne wala time. Gate ki chain jitni lambi, delay utna zyada.
logic levels
Input se output tak kitne gates paar karne padte hain. AND-OR = 2 levels.
logic synthesis
Software (Synopsys Design Compiler, Cadence Genus) jo Verilog ko minimum gates mein badalta hai, automatically.
Kaise kaam karta hai (cost kaise naapte hain):
  1. Expression likho, terms (products) gino.
  2. Literals gino: har variable appearance = 1.
  3. Gates gino: har product term ek AND, terms ko jodne ke liye ek OR, har alag bar wala variable ek NOT.
  4. Simplify karo (laws ya K-map) aur dobara gino.
  5. Chaar fayde likho: area, power, speed (delay), cost.

Class slide: ek typical 4-variable function lagbhag 16 gates se 2 gates tak aa sakta hai. Apple M3 mein 98 billion transistors (TSMC N3E) hain, isliye 1% bachat bhi bahut paisa hai. CMOS NAND = 4 transistors, CMOS AND = NAND + inverter = 6 transistors.

Solved example 1:

F = AB + AB' + A'B. Count literals before and after simplification, and the gates saved.

  1. Before: AB (2) + AB' (2) + A'B (2) = 6 literals.
  2. Gates before: 3 two-input ANDs + 1 three-input OR + 2 NOTs (A', B') = 6 gates.
  3. Simplify: AB + AB' = A(B + B') = A·1 = A.
  4. F = A + A'B = A + B (redundant-literal law, 1.5).
  5. After: A + B = 2 literals, 1 OR gate.

Answer: 6 literals → 2 literals; 6 gates → 1 gate.

Solved example 2 (write the answer like this):

Why is logic minimisation important in VLSI design? (5 marks)

  1. Area: each gate occupies silicon; fewer gates give a smaller die, more dies per wafer and higher yield.
  2. Power: dynamic power ∝ switched capacitance × V² × f; fewer gates switch less capacitance.
  3. Delay: fewer levels and shorter paths reduce the critical path, allowing a higher clock frequency.
  4. Cost: silicon area and yield dominate chip cost; at billions of gates even 1% matters.
  5. Example: F = AB + AB' = A removes four gates; synthesis tools (Design Compiler, Genus) do this automatically.

Answer: area, power, delay, cost + one example.

Galti mat karna: "Kam terms = hamesha kam literals" nahi hota; dono gino. Aur kabhi kabhi speed (kam levels) ke liye zyada gates lagaye jaate hain.
Ek line mein: Same truth table, kam gates → kam area, kam power, zyada speed, kam cost.

2.2 Canonical Forms: SOP and POS

Pehle socho: Ek alarm ka rule do tarah likh sakte ho. (1) "In situations mein bajna chahiye" (list of 1s) = SOP. (2) "In situations mein chup rehna chahiye" (list of 0s) = POS. Dono same alarm describe karte hain. Truth table se seedha expression likhne ka yahi standard tareeka hai.
Definition: A minterm is a product (AND) term containing every variable exactly once (true or complemented) that equals 1 for exactly one input row. A maxterm is a sum (OR) term containing every variable exactly once that equals 0 for exactly one row. Canonical SOP (sum of products) is the OR of the minterms of the rows where F = 1; canonical POS (product of sums) is the AND of the maxterms of the rows where F = 0.
Mushkil shabd, aasaan matlab:
product term
Variables ka AND, jaise AB'C. "Product" = AND.
sum term
Variables ka OR, jaise (A + B' + C). "Sum" = OR.
minterm mₖ
Row k ka AND term, sirf row k pe 1. Rule: bit 1 → X, bit 0 → X'. Row 101 = 5 → m5 = AB'C (A = 1, B = 0, C = 1 daalo: 1·1·1 = 1).
maxterm Mₖ
Row k ka OR term, sirf row k pe 0. Rule ulta: bit 0 → X, bit 1 → X'. Row 010 = 2 → M2 = A + B' + C (A = 0, B = 1, C = 0 daalo: 0 + 0 + 0 = 0).
canonical
"Standard, poora": har term mein har variable hai. Chhota nahi kiya gaya.
Σm( ) aur ΠM( )
Shorthand. Σ = OR of minterms, Π = AND of maxterms. F = Σm(1, 3) matlab F = m1 + m3.
Kaise kaam karta hai (truth table → Σm → expression, aur ΠM):
  1. Truth table mein F = 1 wali rows dhoondo, unke decimal numbers likho → Σm list.
  2. Har aisi row ka minterm likho (1 → X, 0 → X'), sabko + se jodo → canonical SOP.
  3. F = 0 wali rows ke numbers → ΠM list (ye Σm list ke bache hue numbers hi hain).
  4. Har aisi row ka maxterm likho (0 → X, 1 → X'), brackets ko AND karo → canonical POS.
  5. Check: Σm list + ΠM list = 0 se 2ⁿ − 1 tak har number exactly ek baar.

Diagram kaise padhein: Har row mein pehle m (row number), phir A B C, phir F. F = 1 wali rows (highlighted) pe minterm likha hai, F = 0 wali rows pe maxterm. Row 3 dekho: 011, F = 1 → m3 = A'BC. Row 2: 010, F = 0 → M2 = A + B' + C. Isliye F = Σm(1, 3, 5, 7) = ΠM(0, 2, 4, 6).

Formula: minterm: 1 → X, 0 → X' · maxterm: 0 → X, 1 → X'
F = Σm(1-rows) = ΠM(0-rows); F' = Σm(0-rows); mₖ' = Mₖ.
n variables: number of maxterms = 2ⁿ − (number of minterms). 4 variables with 6 minterms → 16 − 6 = 10 maxterms.
Solved example 1 (identify terms):

(a) Minterm for A = 1, B = 0, C = 1, D = 0. (b) Maxterm for A = 0, B = 1, C = 1.

  1. (a) 1010 = 8 + 0 + 2 + 0 = 10. Minterm rule (1 → X, 0 → X'): A B' C D'. So m10 = AB'CD'.
  2. (b) 011 = 0 + 2 + 1 = 3. Maxterm rule (0 → X, 1 → X'): A, B', C'. So M3 = A + B' + C'.
  3. Check (b): put 0, 1, 1 → 0 + 0 + 0 = 0. Maxterm sirf apni row pe 0 hota hai. ✓

Answer: m10 = AB'CD'; M3 = (A + B' + C').

Solved example 3 (expression → Σm, mock NAT):

How many minterms are 1 in F(A, B, C) = A + B'C? Write F in Σm and ΠM.

  1. Term A: A = 1, B and C kuch bhi → rows 100, 101, 110, 111 = 4, 5, 6, 7.

  3. Union (5 do baar aaya, ek baar gino): 1, 4, 5, 6, 7 → 5 minterms.
  4. Bache hue: 0, 2, 3 → ΠM(0, 2, 3).

Galti mat karna: Maxterm mein minterm wala rule lagana THE trap hai. M2 (row 010) = A + B' + C hai, A'BC' nahi. Yaad rakho: maxterm us row pe 0 dena chahiye, to har literal 0 hona chahiye.

Trick: "SOP = 1s = m = seedha 1; POS = 0s = M = seedha 0." Jo bit term ko "seedha" (bina bar) likhwata hai: minterm mein 1, maxterm mein 0.

Ek line mein: SOP = 1-rows ke minterms ka OR; POS = 0-rows ke maxterms ka AND; dono lists milke saare rows cover karti hain.

2.3 Karnaugh Maps: 2, 3, and 4 Variables

Pehle socho: Laws se simplify karne mein asli trick ek hi hai: XY + XY' = X (jo variable badal raha hai wo cancel). Problem: aise pairs dhoondna mushkil. K-map truth table ko aise ghar mein rakh deta hai ki padosi cells mein sirf ek variable badle. Ab pair dhoondna = padosi 1s pe gola banana. Maths ki jagah pattern dekhna.
Definition: A Karnaugh map (K-map) is a grid arrangement of a truth table in which adjacent cells (including wrap-around at the edges) differ in exactly one variable, so that adjacent 1s can be grouped in rectangles of 1, 2, 4, 8 or 16 cells to obtain a minimal SOP expression.
Mushkil shabd, aasaan matlab:
cell
Map ka ek dabba = truth table ki ek row. Andar F ki value (0, 1 ya X) likhte hain.
Gray code
Aisi counting jisme agla number sirf ek bit badalta hai: 00 → 01 → 11 → 10. Binary 01 → 10 mein do bits badalte hain, isliye binary order K-map mein nahi chalta.
adjacent (padosi)
Upar-neeche ya left-right wale cells (diagonal nahi). Map ke edges mude hue maano: left edge right edge ka padosi, top bottom ka, aur 4-variable map ke chaaron corners ek doosre ke padosi.
group / implicant
Padosi 1s ka rectangle. Size: pair (2), quad (4), octet (8).
wrap-around
Map ko ek "donut" ki tarah socho: right se nikle to left mein aa gaye.
Kaise kaam karta hai:

(A) Map draw karna, cell numbers ke saath (cell ke andar row number = minterm index likha hai):

Dhyan do: Gray order ki wajah se columns mein 3 pehle aata hai, 2 baad mein (0 1 3 2), aur rows mein 12 pehle, 8 baad mein. Cell number nikalna: row bits + column bits jodo, jaise row 11, column 01 → 1101 = 8 + 4 + 0 + 1 = 13.

(B) Grouping rules:

  1. Sirf 1s (aur zaroorat ho to X) ko gher lo; 0 kabhi group mein nahi.
  2. Group ka size 2 ki power: 1, 2, 4, 8, 16. 3 ya 6 cells ka group illegal.
  3. Group rectangle hona chahiye; diagonal nahi.
  4. Wrap-around allowed: left-right edge, top-bottom edge, aur chaaron corners (4-variable) ek group.
  5. Groups jitne bade ho sakein utne bade banao (bada group = kam literals).
  6. Groups overlap kar sakte hain; har 1 kam se kam ek group mein ho.
  7. Groups jitne kam ho sakein; jo group poora doosron se already cover ho, use hata do.

(C) Group ko term mein padhna:

  1. Group ke saare cells ke liye har variable ki value dekho.
  2. Jo variable group ke andar badalta hai (kahin 0 kahin 1) → wo drop (X + X' = 1).
  3. Jo constant rehta hai: 1 hai to X likho, 0 hai to X'.
  4. Bache variables ka AND = us group ka term. Saare terms ka OR = answer.

(D) Poora procedure: map bharo → pehle wo 1s dekho jinka group sirf ek tarah ban sakta hai → sabse bade groups gher lo → har 1 cover karo → har group ka term likho → OR karo.

Diagram kaise padhein: Row = A (0, 1), columns = BC Gray order mein (00, 01, 11, 10). 1s beech ke do columns (01 aur 11) mein hain, dono rows mein = quad. Quad mein A badalta hai (0, 1), B badalta hai (0, 1), C hamesha 1 → F = C.

Diagram kaise padhein: Rows AB, columns CD, dono Gray order. Row 01 poori 1 → quad A'B (A = 0, B = 1 constant, C, D badalte hain). Beech ka 2×2 block (cells 5, 7, 13, 15) → B = 1, D = 1 → BD. Column 00 aur 10 ke upar ke do rows (cells 0, 2, 4, 6) edge se wrap hote hain → A = 0, D = 0 → A'D'. F = A'B + BD + A'D'.

Diagram kaise padhein: Chaaron corners (0, 2, 8, 10) ek hi group hain kyunki map mudta hai. Corners mein B = 0 aur D = 0 hamesha → B'D'. Beech ka quad (5, 7, 13, 15) → BD. F = B'D' + BD.

Formula: n-variable map mein 2ᵏ cells ka group → n − k literals.
4-variable: pair (k = 1) → 3 literals, quad (k = 2) → 2 literals, octet (k = 3) → 1 literal, all 16 → F = 1.
Solved example 1 (3-variable, Lab 2 Q16):

Minimise F(A, B, C) = Σm(0, 2, 3, 5) using a K-map.

  1. Map bharo (cells 0, 2, 3, 5 mein 1):

  1. m5 ke padosi: m1 (0), m4 (0), m7 (0). Koi padosi 1 nahi → m5 akela group: A = 1, B = 0, C = 1 → AB'C.
  2. m0 ke padosi 1: sirf m2 (wrap-around: column 00 aur column 10 padosi hain). Pair m0, m2: A = 0, C = 0 constant, B badalta → A'C'.
  3. m3 ka padosi 1: m2. Pair m2, m3: A = 0, B = 1 constant, C badalta → A'B.
  4. Saare 1s cover: m0, m2 (A'C'), m3 (A'B), m5 (AB'C).

Answer: F = A'C' + A'B + AB'C.

Solved example 2 (4-variable, exam level, mock 6 marks):

  1. Map bharo:

  2. Cells 0, 1, 8, 9 (rows 00 aur 10 wrap, columns 00, 01) → quad. B = 0, C = 0 constant → B'C'.
  3. m5 bacha. Padosi: m1 (1), m4 (0), m7 (0), m13 (0). Sirf pair m1, m5 → A = 0, C = 0, D = 1 constant, B badalta → A'C'D.
  4. SOP: F = B'D' + B'C' + A'C'D.
  5. POS ke liye 0s ko group karo (F' ka SOP): 0s at 3, 4, 6, 7, 11, 12, 13, 14, 15.
  6. Zero-group 1: row 11 poori (12, 13, 14, 15) → A = 1, B = 1 → AB.
  7. Zero-group 2: column 11 poora (3, 7, 15, 11) → C = 1, D = 1 → CD.

Galti mat karna: Columns ko 00, 01, 10, 11 (binary) likhna sabse common galti hai. 3 cells ka group, diagonal group, aur corners/edges miss karna bhi. Ek group jo poora doosre groups se cover hai, wo extra term hai: hata do.

Trick: Gray order: "00, 01, 11, 10": beech mein 11 pehle. Group padhte waqt bolo: "jo badla wo gaya."

Ek line mein: Gray order map, 2 ki power ke rectangles (wrap allowed), sabse bade groups, badalne wala variable drop.

2.4 DeMorgan's Theorems and Bubble Pushing

Pehle socho: "Chai aur coffee dono mil gaye, aisa NAHI hua" = kam se kam ek nahi mila (chai nahi YA coffee nahi). "Na chai mili na coffee" = chai nahi AUR coffee nahi. Ye roz ki baat hi De Morgan hai. Circuit mein isi se NOT ko gates ke andar-bahar khiskaate hain, aur AND-OR circuit ko sirf NAND se bana dete hain.
Definition: De Morgan's theorems state that the complement of a product equals the sum of the complements, (AB)' = A' + B', and the complement of a sum equals the product of the complements, (A + B)' = A'B'. Bubble pushing is the graphical use of these theorems: moving inversion bubbles from a gate's output to its inputs (or back) while changing AND to OR or OR to AND.
Mushkil shabd, aasaan matlab:
bubble
Gate ke input ya output pe chhota gola = NOT.
complement of a function
F' = F ka ulta: jahan F = 1 tha wahan 0. Nikalne ke liye: har literal ulta karo aur + ↔ · badlo (0 ↔ 1 bhi).
double bubble
Ek wire pe do NOT = kuch nahi: (A')' = A. Do bubbles cancel.
Kaise kaam karta hai:
AB(AB)'A' + B'(A + B)'A'B'
001111
011100
101100
110000

Columns 3 = 4 aur 5 = 6: dono theorems truth table se proved.

  1. Algebra mein: sabse bahar wala bar pehle tod do: bar ke neeche ke har tukde pe bar lagao aur sign badlo (· → +, + → ·).
  2. Andar koi bar bacha ho to wahi step dobara. Double bar mile to hata do.
  3. Picture mein (bubble pushing): gate ke output ka bubble uthao, gate ke har input pe bubble lagao, aur gate badlo (AND ↔ OR).
  4. Isliye NAND = OR with inverted inputs aur NOR = AND with inverted inputs.
  5. Ek wire pe do bubbles aa jaayein (ek gate ke output pe, agle ke input pe) to dono cancel. Yahi AND-OR ko NAND-NAND banata hai (2.5).

Diagram kaise padhein: Left: NAND (AND + output bubble). Right: OR jiske dono inputs pe bubble. Beech mein ≡ = dono same. Trace A = 1, B = 1: NAND → 0; right side: A' = 0, B' = 0, OR = 0. ✓

Diagram kaise padhein: Left: NOR (OR + output bubble). Right: AND with bubbled inputs. Trace A = 0, B = 0: NOR → 1; right: 1·1 = 1. ✓

Solved example 1 (class slide):

Simplify ~(A·B + C).

  1. Bahar ka bar: (AB + C)' = (AB)'·C' (OR tha → AND, har tukde pe bar).
  2. Andar bacha (AB)': = A' + B'.
  3. Result: (A' + B')·C'.

Answer: (~A + ~B)·~C.

Solved example 2 (exam level, Lab 2 Q30):

Simplify F = ((A' + B)' + (A·C)')'.

  1. Andar ke tukde: (A' + B)' = A''·B' = AB' (De Morgan, double bar hataya).
  2. (AC)' = A' + C' (De Morgan).
  3. F = (AB' + A' + C')'.
  4. Bahar ka bar (teen terms ka OR → teeno ke complement ka AND): F = (AB')'·(A')'·(C')'.
  5. = (A' + B)·A·C (De Morgan on (AB)', involution on the others).
  6. = A·C·(A' + B) = AA'C + ABC = 0 + ABC (distributive, complement).

Answer: F = ABC.

Solved example 3 (complement of a function, Lab 2 Q13):

Find the complement of F = (A + B)(A' + C).

  1. F' = [(A + B)(A' + C)]' = (A + B)' + (A' + C)' (product ka complement = complements ka sum).
  2. (A + B)' = A'B'; (A' + C)' = A·C'.

Answer: F' = A'B' + AC'.

Galti mat karna: (AB)' = A'B' GALAT; sign badalna zaroori: A' + B'. Sirf bahar ka bar tod ke ruk mat jao, andar ke bars bhi tod do. Function ka complement lete waqt constants bhi badlo (0 ↔ 1).

Trick: "Bar tod do, sign badlo." Picture mein: "bubble khiskao, gate badlo."

Ek line mein: (AB)' = A' + B', (A + B)' = A'B'; NAND = bubbled-input OR, NOR = bubbled-input AND.

2.5 Universal Gates (NAND/NOR) Demonstration

Pehle socho: Ek LEGO set jisme sirf ek hi shape ki brick hai, phir bhi usse kuch bhi ban sakta hai. Factory ke liye ye best hai: ek hi cell design karo, perfect karo, lakhon baar copy karo. CMOS mein NAND sirf 4 transistors ka hai (AND 6 ka), isliye chips zyada NAND se bante hain.
Definition: A set of gates is functionally complete if every Boolean function can be built from it; {AND, OR, NOT} is such a set. A universal gate is a single gate type that is functionally complete by itself; NAND and NOR are universal gates.
Mushkil shabd, aasaan matlab:
functionally complete
Is set se koi bhi truth table ban sakti hai. {AND, OR} complete nahi, kyunki NOT nahi ban sakta.
NAND-NAND form
Do levels, dono NAND. AND-OR (SOP) circuit ka NAND version.
NOR-NOR form
OR-AND (POS) circuit ka NOR version.
inputs tie karna
Gate ke dono inputs ek hi signal se jodna. NAND(A, A) = (A·A)' = A'.
Kaise kaam karta hai (NAND se NOT, AND, OR):
  1. NOT: NAND ke dono inputs pe A: (A·A)' = A'. Check A = 1: (1·1)' = 0. → 1 gate.
  2. AND: NAND(A, B) = (AB)', phir ek NAND-inverter: ((AB)')' = AB. → 2 gates.
  3. OR: pehle A' = NAND(A, A), B' = NAND(B, B); phir NAND(A', B') = (A'B')' = A + B (De Morgan). → 3 gates.
  4. NOR se (mirror): NOT = NOR(A, A) (1); OR = NOR phir NOR-inverter (2); AND = NOR(A', B') = (A' + B')' = AB (3).
  5. XOR: 4 NANDs (D2.5c), 5 NORs.
BuildNAND onlyNOR only

SOP → NAND-NAND (steps):

  1. Minimal SOP likho (K-map se). Circuit = level 1 ANDs, level 2 ek OR.
  2. Har AND ke output pe ek bubble aur OR ke har input pe ek bubble lagao (wire pe 2 bubbles = koi farak nahi).
  3. Ab AND + output bubble = NAND. OR + input bubbles = NAND (2.4). Sab NAND.
  4. Agar koi akela literal (jaise C) seedha OR mein jaa raha tha, to ab use C' karke daalo (uska bubble cancel karne wala koi nahi).
  5. Complemented inputs (A', B') available nahi to har ek ke liye NAND(X, X) inverter jodo.

POS → NOR-NOR: same steps, OR ki jagah NOR (level 1), AND ki jagah NOR (level 2).

Diagram kaise padhein: Left: ek NAND, dono inputs A se jude → A'. Beech: NAND(A, B) ka output agle NAND ke dono inputs pe → AB (2 gates). Right: A aur B pehle alag alag NAND-inverters se A', B' bante hain, phir teesra NAND → A + B (3 gates). Trace OR with A = 0, B = 1: A' = 1, B' = 0, NAND(1, 0) = 1 ✓.

Diagram kaise padhein: Pehla NAND G1 = (AB)'. G1 do NANDs mein jaata hai: G2 = (A·G1)', G3 = (B·G1)'. Last NAND G4 = (G2·G3)' = A ⊕ B. Trace A = 1, B = 0: G1 = 1, G2 = (1·1)' = 0, G3 = (0·1)' = 1, G4 = (0·1)' = 1 ✓ (1 ⊕ 0 = 1).

Solved example 1 (mock MCQ):

Minimum 2-input NAND gates for a 2-input OR? Verify with a truth table.

  1. OR = (A'B')' (De Morgan). A' = NAND(A, A), B' = NAND(B, B), result = NAND(A', B').
  2. Check all rows: 00 → A' = 1, B' = 1 → NAND = 0. 01 → 1, 0 → 1. 10 → 0, 1 → 1. 11 → 0, 0 → 1. Column 0111 = OR ✓.

Answer: 3 NAND gates.

Solved example 2 (exam level, mock 6 marks, second half):

Implement F = B'D' + B'C' + A'C'D (from 2.3, example 2) using only NAND gates. Only true inputs A, B, C, D are available.

  1. SOP circuit: AND1 = B'D', AND2 = B'C', AND3 = A'C'D (3-input), OR of three.
  2. Bubble push: har AND → NAND, OR (bubbled inputs) → NAND. F = ((B'D')'·(B'C')'·(A'C'D)')'.
  3. Complements banao: A' = NAND(A, A), B' = NAND(B, B), C' = NAND(C, C), D' = NAND(D, D) → 4 gates.
  4. Level 1: N1 = NAND(B', D'), N2 = NAND(B', C'), N3 = NAND(A', C', D) (3-input) → 3 gates.
  5. Level 2: F = NAND(N1, N2, N3) (3-input) → 1 gate.
  6. Check A = 0, B = 1, C = 0, D = 1 (m5, should be 1): N1 = NAND(0, 0) = 1, N2 = NAND(0, 1) = 1, N3 = NAND(1, 1, 1) = 0, F = NAND(1, 1, 0) = 1 ✓.

Answer: F = NAND(NAND(B', D'), NAND(B', C'), NAND(A', C', D')): 4 inverter NANDs + 3 + 1 = 8 NAND gates.

Solved example 3 (NOR only):

Implement F = (A + B)(C + D) using only 2-input NOR gates.

  1. POS circuit: OR1 = A + B, OR2 = C + D, AND of both.
  2. Bubble push: OR + output bubble = NOR; AND with bubbled inputs = NOR.
  3. F = ((A + B)' + (C + D)')' = NOR(NOR(A, B), NOR(C, D)).
  4. Check A = 1, B = 0, C = 0, D = 0 (F should be (1)(0) = 0): NOR(1, 0) = 0, NOR(0, 0) = 1, NOR(0, 1) = 0 ✓.

Answer: 3 NOR gates. (Similarly AB + CD = NAND(NAND(A, B), NAND(C, D)) = 3 NANDs.)

Galti mat karna: NAND "zyada powerful" nahi, sirf self-sufficient hai. NAND-NAND mein akela literal (jaise AB + C mein C) seedha mat daalo: C' daalna padta hai, F = ((AB)'·C')'. Aur sirf 2-input gates allowed hon to 3-input term ke liye extra gates lagenge.

Trick: NAND: 1-2-3 (NOT-AND-OR). NOR: 1-3-2. SOP ↔ NAND-NAND, POS ↔ NOR-NOR ("S-N-A, P-N-O").

Ek line mein: NAND/NOR akele har circuit bana sakte hain; SOP ko NAND-NAND, POS ko NOR-NOR bubble pushing se.

2.6 Don't-Cares in K-Maps

Pehle socho: Menu mein ek dish hai jo koi kabhi order hi nahi karta. Chef us dish ke liye jo chahe maan le, kisi ko farak nahi padta. Circuit mein bhi kuch input combinations kabhi aate hi nahi (jaise BCD mein 1010 se 1111). Unka output hum apni suvidha se 0 ya 1 maan sakte hain, taaki groups bade ho jaayein.
Definition: A don't-care (written X or d) is an input combination whose output does not matter, because it never occurs or its output is never used. In a K-map it may be treated as 1 or 0, whichever gives a simpler expression.
Mushkil shabd, aasaan matlab:
X / d( )
Don't-care ka nishan. F = Σm(5, 6, 7) + d(10, 11) matlab 5, 6, 7 pe F = 1 aur 10, 11 pe "kuch bhi".
BCD
Binary Coded Decimal: ek decimal digit (0 to 9) ko 4 bits mein likhna. 4 bits 16 values bana sakti hain, par sirf 0000 to 1001 use hote hain; 1010 to 1111 (10 to 15) kabhi nahi aate → don't-cares.
Kaise kaam karta hai:
  1. Map mein 1s, 0s aur X sab bharo.
  2. Har X ke liye socho: kya isse 1 maan ke koi group bada hota hai? Haan → 1 maano. Nahi → 0 maano.
  3. Sirf X ka group kabhi mat banao (wo koi 1 cover nahi karta, bekar term).
  4. X ko cover karna zaroori nahi; sirf saare 1s cover hone chahiye.
  5. Groups ko normal tareeke se padho (badalne wala variable drop).

Diagram kaise padhein: Row 00 mein m0, m1 = 1, m3 = X; row 01 mein m5, m7 = X. Cells 1, 3, 5, 7 ka quad (X ko 1 maana) → A = 0, D = 1 → A'D. m0 bacha → pair m0, m1 → A'B'C'. F = A'D + A'B'C'. X ki wajah se ek pair ki jagah quad mila.

Solved example 1 (3-variable):

Minimise F(A, B, C) = Σm(0, 1, 6) + d(2, 3, 7).

  2. m6 bacha. Cells 2, 3, 6, 7 (columns 11, 10 dono rows) = X, X, 1, X → quad, B = 1 constant → B.
  3. Saare 1s (0, 1, 6) cover.

Answer: F = A' + B (2 literals). Without don't-cares it would be A'B' + ABC'.

Solved example 2 (4-variable, exam level):

A circuit gets a BCD digit ABCD and outputs 1 when the digit is 5 or more. F = Σm(5, 6, 7, 8, 9) + d(10, 11, 12, 13, 14, 15). Minimise.

2.E1 Extra from slides: Prime Implicants, EPIs and the Consensus Theorem

Pehle socho: K-map pe gole banate waqt sawaal aata hai: "kaunse group zaroori hain aur kaunse optional?" Jaise ek class mein kuch students hi kisi ek topic ko padha sakte hain: jo topic sirf ek student jaanta hai, us student ko team mein lena hi padega. Wahi "essential" hai.
Definition: An implicant is any product term (group of 1s and don't-cares) for which F = 1. A prime implicant (PI) is an implicant that cannot be enlarged (combined into a bigger group). An essential prime implicant (EPI) is a prime implicant that covers at least one 1 that no other prime implicant covers. A minimal SOP contains all EPIs plus the fewest additional PIs needed to cover the remaining 1s.
Mushkil shabd, aasaan matlab:
implicant
Koi bhi valid group (1, 2, 4 cells). Jaise m0, m2 ka pair.
prime implicant
Group jo aur bada nahi ho sakta. Agar m0, m2 ka pair ek quad (0, 2, 8, 10) ka hissa hai to pair prime nahi; quad prime hai.
essential PI
Prime group jo kisi ek 1 ko akela cover karta hai. Us 1 ke liye koi aur option nahi, to ye answer mein hona hi chahiye.
cyclic map
Map jisme har 1 do PIs se cover hota hai, koi EPI nahi. Choice trial se karte hain.
consensus term
XY aur X'Z se bana YZ (X hata ke baaki ka AND). Ye redundant hota hai.
Kaise kaam karta hai (PIs aur EPIs dhoondna):
  1. Map bharo. Har 1 ke liye uska sabse bada possible group dhoondo. Ye saare alag alag groups = PIs.
  2. Har 1 ke liye gino: kitne PIs isko cover karte hain?
  3. Jis 1 ko sirf ek PI cover karta hai, wo PI = EPI. Use answer mein daalo.
  4. EPIs se jo 1s bach gaye, unhe kam se kam extra PIs se cover karo.
  5. Koi EPI na mile (cyclic) → ek PI choose karo, baaki chain ki tarah follow karo.

Diagram kaise padhein: 6 ones ek ring mein: m0, m1, m5, m7, m6, m2. Har 1 ke do padosi 1 hain, isliye har 1 do pairs mein aa sakta hai. Teen alternate pairs chuno: A'B' (0, 1), AC (5, 7), BC' (2, 6). Saare 6 cover, 3 terms.

Solved example 1 (EPIs present):

Find all PIs and EPIs of F = Σm(0, 1, 2, 5, 8, 9, 10) (map of 2.3, example 2).

  1. PIs: B'D' (0, 2, 8, 10), B'C' (0, 1, 8, 9), A'C'D (1, 5). Koi aur group inse bada ya alag nahi banta.
  2. m5 ko kaun cover karta hai? Sirf A'C'D → EPI.
  3. m9: sirf B'C' (m13, m11 = 0, isliye koi aur group nahi) → EPI.
  4. m2 aur m10: sirf B'D' → EPI.
  5. Teeno EPIs saare 1s cover karte hain, extra PI nahi chahiye.

Answer: 3 PIs, all 3 essential; F = B'D' + B'C' + A'C'D.

Solved example 2 (cyclic, Lab 2 Q23):

F(A, B, C) = Σm(0, 1, 2, 5, 6, 7). How many PIs and EPIs? Give a minimal SOP.

  1. Har 1 ke pairs: m0: (0, 1) A'B', (0, 2) A'C'. m1: (1, 0), (1, 5) B'C. m5: (5, 1), (5, 7) AC. m7: (7, 5), (7, 6) AB. m6: (6, 7), (6, 2) BC'. m2: (2, 0), (2, 6).
  2. Koi quad nahi banta (har quad mein koi 0 aata hai). To PIs = 6 pairs: A'B', A'C', B'C, AC, AB, BC'.
  3. Har 1 do PIs se cover hai → koi EPI nahi (0).
  4. A'B' chuno (0, 1). Bache 2, 5, 6, 7: AC (5, 7) + BC' (2, 6) le lo → sab cover.

Answer: 6 PIs, 0 EPIs; F = A'B' + AC + BC' (other valid cover: A'C' + B'C + AB).

Consensus theorem: XY + X'Z + YZ = XY + X'Z
Why: YZ = 1 means Y = Z = 1; then X = 1 makes XY = 1, X = 0 makes X'Z = 1, so YZ never adds a new 1.
Example (Lab 2 Q11): (A + B)(A' + C) = AA' + AC + A'B + BC = AC + A'B + BC = AC + A'B (BC is the consensus of AC and A'B).
Galti mat karna: "PIs ki ginti = EPIs ki ginti" hamesha nahi (cyclic map mein 6 PIs, 0 EPI). EPI kabhi drop nahi hota. Don't-care PI ke andar ho sakta hai, par sirf don't-care cover karne se koi PI essential nahi banta.
Ek line mein: PI = sabse bada group; EPI = kisi 1 ka akela sahara, hamesha answer mein; consensus term YZ redundant.
