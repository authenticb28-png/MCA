Unit 1 · Boolean Algebra & Gates

1.1 Course introduction & roadmap

Computer architecture is the study of how a computer is designed and organised — from logic gates up to the instruction set that software uses.
  • Architecture = the “what”: what the programmer sees (instructions, registers, memory model).
  • Organisation = the “how”: hidden implementation (how ADD is built, pipelines, caches, clock).
  • Six course modules: digital foundations → sequential logic & memory → organisation & ISA → datapath & pipelining → memory hierarchy → parallelism.
Yaad rakho: Architecture = what (ISA). Organisation = how (implementation).

1.2 Why architecture matters — the abstraction stack

An abstraction stack is the set of layers through which a computer is built, each layer hiding the details of the one below it: applications & languages → operating system → ISA → datapath & control → logic gates → transistors.
  • The ISA (Instruction Set Architecture) is the contract between software and hardware.
  • Example: A[i] = B[i] + C[i] in Python → MIPS lw, lw, add, sw → register file and ALU → XOR/AND gates → transistors.
  • Chip flow (VLSI): spec → RTL (Verilog) → simulation → synthesis → netlist → place & route → verification → fabrication.
Yaad rakho: ISA sits between the OS and the datapath — the hardware/software contract.

1.3 Boolean logic basics — AND, OR, NOT, XOR (+ NAND, NOR, XNOR)

A logic gate is an electronic circuit that performs a Boolean function on one or more binary inputs (0 = LOW/false, 1 = HIGH/true) and produces a single binary output.
  • AND: 1 only if ALL inputs are 1. OR: 1 if ANY input is 1. NOT: inverts.
  • NAND = NOT of AND, NOR = NOT of OR (output 1 only when all inputs are 0).
  • XOR: 1 when inputs are DIFFERENT; XNOR: 1 when inputs are EQUAL.
  • NAND and NOR are universal gates (can build any circuit).
AND Y = A·B  |  OR Y = A + B  |  NOT Y = A'  |  NAND Y = (AB)'  |  NOR Y = (A + B)'
XOR Y = A ⊕ B = A'B + AB'  |  XNOR Y = (A ⊕ B)' = A'B' + AB

Trick: XOR = “odd number of 1s → 1”. A = 1, B = 0: only OR, XOR and NAND give 1.

Yaad rakho: XOR(1,1) = 0. NAND/NOR = AND/OR + bubble.

1.4 Truth tables

A truth table lists the output of a logic function for every possible combination of its inputs.
  • n inputs → 2ⁿ rows (2 inputs → 4 rows, 3 → 8, 4 → 16).
  • Write inputs in binary counting order: 000, 001, 010, … so no row is missed.
  • Truth table is the final check of any simplification.
Yaad rakho: rows = 2ⁿ, always in binary counting order.

1.5 Boolean laws & simplification

Boolean algebra is the algebra of variables that take only the values 0 and 1, with the operations AND (·), OR (+) and NOT ('); its laws let us rewrite an expression into a simpler equivalent one.
Identity A + 0 = A, A·1 = A  ·  Null A + 1 = 1, A·0 = 0  ·  Idempotent A + A = A, A·A = A
Complement A + A' = 1, A·A' = 0  ·  Involution (A')' = A
Distributive A(B + C) = AB + AC and A + BC = (A + B)(A + C)
Absorption A + AB = A, A(A + B) = A  ·  A + A'B = A + B
De Morgan (AB)' = A' + B', (A + B)' = A'B'  ·  Consensus XY + X'Z + YZ = XY + X'Z
Example — why A + AB = A: take A common → A(1 + B) → 1 + B = 1 → A · 1 = A.

Trick: De Morgan = “break the bar, change the sign” (+ becomes ·, · becomes +).

Yaad rakho: “+” is OR, so A + 1 = 1 (not 2). A + A'B = A + B is the most used shortcut.

1.6 Worked simplification examples

Simplification means reducing a Boolean expression to fewer terms and literals (so fewer gates) while keeping the same truth table.
AB + AB' = A(B + B') = A·1 = A
A(A + B) = AA + AB = A + AB = A
A'B'C + A'BC + AB'C + ABC + A'B → first four all have C → C(all four AB combos = 1) = C → C + A'B
Yaad rakho: look for a common factor, then use X + X' = 1 to kill the changing variable.

1.E1 Verilog & HDL basics (from the labs)

A Hardware Description Language (HDL) such as Verilog describes the structure and behaviour of digital circuits as text, so they can be simulated (behaviour checked) and synthesised (converted into real gates).
  • module … endmodule; ports input/output. wire is driven by assign; reg is assigned inside always/initial.
  • Combinational: assign y = a & b; or always @(*) (with a default in case, else a latch is inferred).
  • Sequential: always @(posedge clk) q <= d; — use non-blocking <=.
  • Testbench: no ports, #10 delay, $monitor, $dumpfile/$dumpvars, $finish.
Yaad rakho: software runs one line at a time; hardware (HDL) runs all statements in parallel.

Unit 2 · Logic Minimisation & Universal Gates

2.1 Motivation for minimisation

Logic minimisation is the process of finding the simplest circuit (fewest gates and inputs) that implements a given Boolean function.
  • Fewer gates → less area, less power, more speed, lower cost.
  • Industry tools (Synopsys Design Compiler, Cadence Genus) do it automatically for billions of transistors.
Yaad rakho: 4 reasons — area, power, speed, cost.

2.2 Canonical forms: SOP and POS

A minterm is an AND (product) term containing every variable once, true for exactly one input row. A maxterm is an OR (sum) term containing every variable once, false for exactly one row. SOP (Sum of Products) = OR of the minterms where F = 1; POS (Product of Sums) = AND of the maxterms where F = 0.

Hinglish: SOP mein hum sirf un rows ko dekhte hain jahan output 1 hai, aur har row ka ek AND term banate hain. Rule: bit 1 hai toh variable seedha likho (A), bit 0 hai toh bar lagao (A'). POS mein ulta: sirf un rows ko dekho jahan output 0 hai, har row ka ek OR term banao, aur rule bhi ulta — bit 0 hai toh seedha (A), bit 1 hai toh bar (A'). Exam mein sabse zyada galti isi ulte rule mein hoti hai.

SOP rule: 1 → X, 0 → X'.   Row 101 → m5 = AB'C
POS rule: 0 → X, 1 → X'.   Row 011 → M3 = (A + B' + C')
F = Σm(1's rows) = ΠM(0's rows); together they cover 0 to 2ⁿ − 1.
Example: F = Σm(1, 3, 5, 7) → ΠM(0, 2, 4, 6). SOP = A'B'C + A'BC + AB'C + ABC = A'C + AC = C
Yaad rakho: SOP ↔ 1s ↔ minterm m. POS ↔ 0s ↔ maxterm M. The variable rules are opposite.

2.3 Karnaugh maps (2, 3, 4 variables)

A Karnaugh map (K-map) is a grid of the truth table in which adjacent cells differ in exactly one variable (Gray-code order), so that adjacent 1s can be grouped visually to obtain a minimal SOP expression.

Hinglish: K-map basically truth table ko aise arrange karta hai ki pados wale boxes mein sirf ek hi variable badle. Isliye order 00, 01, 11, 10 hota hai (Gray code), 00, 01, 10, 11 nahi. Jab do padosi boxes mein 1 ho, toh jo variable badal raha hai woh cancel ho jaata hai (B + B' = 1). Isliye group jitna bada, expression utna chhota. Groups sirf 1, 2, 4, 8, 16 size ke rectangle hote hain, diagonal nahi chalega, aur map ke kinare aapas mein jude hote hain — left-right, top-bottom aur chaaron corners ek group ban sakte hain.

  • Order 00, 01, 11, 10 on both axes.
  • Group sizes 1, 2, 4, 8, 16 only; rectangles; wrap-around and 4 corners allowed; overlapping allowed; diagonal not allowed.
  • Make groups as BIG as possible and as FEW as possible.
A group of 2ᵏ cells removes k variables — keep only the variables that stay constant inside the group.
Example: Σm(0, 2, 5, 7, 8, 10, 13, 15) → corners 0, 2, 8, 10 have B = 0, D = 0 → B'D'; centre 5, 7, 13, 15 have B = 1, D = 1 → BD → F = B'D' + BD

Trick: Gray code = “00, 01, 11, 10” — the 11 comes before 10.

Yaad rakho: four corners = one quad. Group of 4 kills 2 variables, group of 8 kills 3.

2.4 De Morgan's theorems & bubble pushing

De Morgan's theorems state that the complement of a product equals the sum of the complements, (AB)' = A' + B', and the complement of a sum equals the product of the complements, (A + B)' = A'B'. Bubble pushing is redrawing a gate using these laws by moving inversion bubbles from output to inputs.
  • NAND = OR with inverted inputs. NOR = AND with inverted inputs.
  • Two bubbles on one wire cancel each other.
  • Nested: ~(AB + C) = (A' + B')·C'.
Yaad rakho: break the bar, change the sign — AND ↔ OR and every input flips.

2.5 Universal gates (NAND / NOR)

A universal gate is a gate from which every other logic gate (and so any Boolean function) can be built. NAND and NOR are universal.

Hinglish: NAND ke dono inputs jod do toh woh NOT ban jaata hai: (A·A)' = A'. Ab NOT mil gaya, toh NAND ke baad NOT lagao → AND (2 gates). OR ke liye pehle A aur B dono ko ulta karo (2 NAND) aur phir NAND karo: (A'·B')' = A + B (De Morgan se) → 3 gates. NOR ke liye bilkul ulta hisaab: NOT 1, OR 2, AND 3. Factories NAND isliye pasand karti hain kyunki CMOS NAND sirf 4 transistors ka hota hai, AND 6 ka.

NOTANDORXOR
NAND only1234
NOR only1325
SOP (AND–OR) → NAND–NAND; POS (OR–AND) → NOR–NOR. (A + B)(C + D) with 2-input NANDs needs 6.
Yaad rakho: NAND: 1-2-3 (NOT-AND-OR). NOR: 1-3-2. NAND = 4 transistors, AND = 6.

2.6 Don't-cares in K-maps

A don't-care (X) is an input combination whose output does not matter (because it never occurs or is never used); it may be taken as 1 or 0, whichever gives a simpler expression.
  • Sources: BCD codes 10–15, unused states, impossible sensor combinations.
  • Use an X only if it makes a group bigger; never make a group of only Xs.
Yaad rakho: X = “1 if it helps, 0 if it doesn't”.

2.E1 Prime implicants, essential PIs, consensus

A prime implicant (PI) is a group of 1s that cannot be enlarged further. An essential prime implicant (EPI) is a PI that covers at least one 1 that no other PI covers.
  • Minimal SOP = all EPIs + the fewest extra PIs to cover the remaining 1s.
  • A cyclic map (e.g. Σm(0,1,2,5,6,7)) has no EPI.
  • Consensus: XY + X'Z + YZ = XY + X'Z (YZ is redundant).
Yaad rakho: EPIs are always in the answer.

Unit 3 · Combinational Building Blocks

3.1 From gates to reusable blocks

A combinational building block is a standard circuit (MUX, DEMUX, decoder, adder) built from gates whose output depends only on its present inputs, reused again and again in larger designs.
  • Why blocks: abstraction, reuse, easier verification, scale to millions of gates.
  • In a CPU: MUX picks ALU operands and the next PC; decoder selects a register; adder does arithmetic and PC + 4.

3.2 Multiplexer (2:1, 4:1, cascading)

A multiplexer (MUX) is a combinational circuit that selects one of 2ⁿ data inputs and passes it to a single output, according to the value on n select lines (a “data selector”).

Hinglish: MUX ek railway switch jaisa hai — kai patriyaan aati hain par lever (select) decide karta hai ki kaunsi train aage jayegi. n select lines se 2ⁿ inputs choose ho sakte hain: 1 select → 2 inputs, 2 select → 4, 3 select → 8. Bade MUX chhote MUX jod ke bante hain (tree). Aur ek trick: n-variable ka koi bhi function ek 2ⁿ:1 MUX se ban sakta hai — variables ko select pe lagao aur har input pe 0, 1, C ya C' daal do.

2:1 → Y = S'·I0 + S·I1
4:1 → Y = S1'S0'·I0 + S1'S0·I1 + S1S0'·I2 + S1S0·I3
n selects → 2ⁿ inputs. 2ⁿ:1 from 2:1 MUXes needs 2ⁿ − 1 of them (4:1 → 3, 8:1 → 7).
Example: F(A,B,C) = Σm(1,3,5,6), S1 = A, S0 = B → for AB = 00, 01, 10 F = C; for AB = 11 F = C' → I0 = C, I1 = C, I2 = C, I3 = C'

Trick: MUX = many-to-one (Many → 1). DEMUX = one-to-many.

Yaad rakho: 8:1 MUX needs 3 select lines. Implementing a function = put variables on selects.

3.3 Demultiplexer and n-to-2ⁿ decoder

A demultiplexer (DEMUX) sends one data input to one of 2ⁿ outputs chosen by n select lines. A decoder converts an n-bit binary input into 2ⁿ outputs, exactly one of which is active (one-hot).
  • 1:2 DEMUX: Y0 = S'D, Y1 = SD.
  • Decoder output Dk = minterm k; built from 2ⁿ AND gates (+ n inverters).
  • A decoder = a DEMUX with its data input tied to 1 (enable).
  • Any function = OR of the decoder outputs for its minterms (full adder: Sum = D1 + D2 + D4 + D7, Cout = D3 + D5 + D6 + D7).
MUXDEMUXDecoder
In2ⁿ data + n select1 data + n selectn bits
Out12ⁿ2ⁿ (one-hot)
Yaad rakho: 3-to-8 decoder = 8 AND gates, each output one minterm.

3.4 Half adder

A half adder is a combinational circuit that adds two single bits and produces a Sum and a Carry; it has no carry input.
Sum = A ⊕ B, Carry = A·B (1 + 1 = 10 → Sum 0, Carry 1). One XOR + one AND.
Yaad rakho: no carry-in → cannot be chained for multi-bit addition.

3.5 Full adder & ripple-carry adder

A full adder adds three bits — A, B and a carry-in Cin — and produces a Sum and a carry-out Cout. An n-bit ripple-carry adder chains n full adders, each carry-out feeding the next stage's carry-in.

Hinglish: Sum tab 1 hota hai jab teen mein se odd number of inputs 1 hon — isliye Sum = A ⊕ B ⊕ Cin. Carry tab 1 hota hai jab kam se kam do inputs 1 hon (majority). Full adder do half adders + ek OR se banta hai: pehla HA A aur B jodta hai, doosra HA us sum mein Cin jodta hai, aur dono carries ko OR kar dete hain (dono ek saath kabhi 1 nahi hote). Ripple adder slow hai kyunki har stage ko pichli stage ke carry ka wait karna padta hai.

Sum = A ⊕ B ⊕ Cin    Cout = AB + Cin(A ⊕ B) = AB + BCin + ACin
Ripple delay grows linearly: ≈ 2 gate delays per bit (4-bit ≈ 8, 64-bit ≈ 128).
Example: A = 1, B = 1, Cin = 1 → Sum = 1 ⊕ 1 ⊕ 1 = 1, Cout = 1·1 + … = 1 → 1 + 1 + 1 = 11₂ = 3 ✓

Trick: Sum = “odd parity”, Cout = “majority vote”.

Yaad rakho: FA = 2 HA + 1 OR. Ripple delay ∝ n.

3.6 CPU preview — ALU and register file

The ALU (Arithmetic Logic Unit) is the combinational unit of the CPU that performs arithmetic (add, subtract) and logic (AND, OR, compare) operations on its operands. The register file is the small fast set of registers that supplies those operands.
  • 1-bit ALU = AND + OR + full adder + MUX choosing the operation. Subtraction: invert B and set carry-in = 1.
  • ALU control: 0000 AND, 0001 OR, 0010 add, 0110 sub, 0111 slt. Zero flag = 1 when the result is 0.
  • Register file: 2 read ports + 1 write port (Unit 7).
Yaad rakho: add 0010, sub 0110.

3.E1 Carry-lookahead adder

A carry-lookahead adder (CLA) computes all carries directly from the inputs using generate and propagate signals, instead of waiting for the carry to ripple.
Generate G = A·B (makes a carry), Propagate P = A ⊕ B (passes a carry), C(i+1) = Gi + Pi·Ci
C2 = G1 + P1G0 + P1P0C0
Yaad rakho: CLA = faster, more area. Ripple = slower, less area.

Unit 4 · Number Systems & Two's Complement

4.1 Number systems — binary, decimal, hex

A positional number system with base (radix) r represents a value as a sum of digits each multiplied by a power of r according to its position. Binary uses base 2, decimal base 10, hexadecimal base 16.
Value = Σ digit × baseposition (positions 0, 1, 2 from the right).
Binary → decimal: 101101 = 32 + 8 + 4 + 1 = 45
Decimal → binary: divide by 2, write remainders, read bottom-up: 42 → 101010
Binary ↔ hex: groups of 4 bits: 1011 0101 = B5 = 11 × 16 + 5 = 181 (A = 10 … F = 15)
Yaad rakho: 1 hex digit = 4 bits. Powers of 2: 1 2 4 8 16 32 64 128 256 512 1024.

4.2 Signed representations

A signed number representation encodes both positive and negative integers in binary. The three schemes are sign-magnitude, one's complement and two's complement.
SchemeNegative of xRange (n bits)Zeros
Sign-magnitudeflip the MSB±(2ⁿ⁻¹ − 1)two
One's complementinvert all bits±(2ⁿ⁻¹ − 1)two
Two's complementinvert + 1−2ⁿ⁻¹ to 2ⁿ⁻¹ − 1one
Yaad rakho: computers use two's complement — one zero, and the same adder works for + and −.

4.3 Two's complement — negation & range

In two's complement, the most significant bit has weight −2ⁿ⁻¹ and all other bits have their normal positive weights; the negative of a number is obtained by inverting all its bits and adding 1.

Hinglish: Kisi number ka negative chahiye toh do step: saare bits ulte karo (0 ↔ 1), phir 1 jod do. Jaise +18 = 00010010 → ulta 11101101 → +1 = 11101110 = −18. Check karne ka aasaan tareeka: MSB ka weight negative hota hai (8-bit mein −128), baaki sab positive. 11101110 = −128 + 64 + 32 + 8 + 4 + 2 = −18. Range yaad rakho: negative side ek zyada hoti hai — 4-bit mein −8 se +7, 8-bit mein −128 se +127.

−x = x' + 1  ·  Range = −2ⁿ⁻¹ to 2ⁿ⁻¹ − 1  ·  MSB weight = −2ⁿ⁻¹
4-bit −8…7 · 8-bit −128…127 · 16-bit −32768…32767
Example: −45 → 45 = 00101101 → invert 11010010 → +1 → 11010011. 0xB7 = 10110111 = −128 + 55 = −73 (unsigned 183).

Trick: shortcut — from the right, copy bits up to the first 1, then flip the rest.

Yaad rakho: 1111…1 = −1; 1000…0 = most negative.

4.4 Sign extension

Sign extension is increasing the number of bits of a two's-complement number while keeping its value, by copying the sign bit (MSB) into all the new higher bits.
+5 = 0101 → 0000 0101  ·  −5 = 1011 → 1111 1011 (zero-padding would wrongly give +11)
MIPS: 16-bit immediate 0xFFFB → 0xFFFFFFFB = −5.
Yaad rakho: signed → copy MSB; unsigned (lbu, andi, ori) → fill with 0.

4.5 Binary addition & subtraction

Binary subtraction in two's complement is done by adding the two's complement of the subtrahend: A − B = A + B' + 1. An adder–subtractor uses XOR gates on B and a mode bit M to do both with one adder.
A − B = A + B' + 1. Adder–subtractor: Bi ⊕ M, Cin = M (M = 0 add, M = 1 subtract).
Example: 5 − 3 = 0101 + 1100 + 1 = 0101 + 1101 = 1 0010 → drop carry → 0010 = 2
Yaad rakho: subtract = invert B + carry-in 1.

4.6 Overflow detection

Overflow occurs when the true result of an arithmetic operation is outside the range that can be represented with the available bits. Signed overflow is flagged by V (OF), unsigned overflow by the carry flag C (CF).

Hinglish: Signed overflow sirf tab hota hai jab do same sign wale numbers jodne par answer ka sign ulta aa jaye — do positive jode aur answer negative aaya, ya do negative jode aur positive aaya. Alag sign wale numbers jodne par kabhi overflow nahi hota. Hardware mein check: MSB column mein aane wala carry (C3) aur jaane wala carry (C4) alag hon toh overflow. Unsigned ke liye sirf C4 dekho.

V = Cin(MSB) ⊕ Cout(MSB) = C3 ⊕ C4 (4-bit)  ·  CF = C4
0111 + 0001 = 1000 → 7 + 1 = −8 → V = 1 (C3 = 1, C4 = 0)
1111 + 0001 = 0000 → CF = 1, V = 0 (signed −1 + 1 = 0 is fine)
Yaad rakho: same signs in, different sign out → overflow. Opposite signs never overflow.

Unit 5 · Latches, Flip-Flops & Timing

5.1 Combinational vs sequential circuits

A combinational circuit's output depends only on its present inputs. A sequential circuit's output depends on present inputs AND past history (stored state), which requires memory elements built with feedback.
CombinationalSequential
no memoryhas memory (state)
no feedbackfeedback loop
adder, MUX, decoderlatch, flip-flop, register, counter, FSM

Two inverters in a loop = bistable (two stable states) = simplest 1-bit memory.

Yaad rakho: sequential = combinational + memory (feedback).

5.2 SR latch & the forbidden state

An SR latch is a basic memory element made of two cross-coupled NOR (or NAND) gates with Set and Reset inputs; Set makes Q = 1, Reset makes Q = 0, and with neither asserted it holds its previous value.

Hinglish: Socho ek bulb jiske do button hain — S dabao toh ON (Q = 1), R dabao toh OFF (Q = 0), kuch mat dabao toh jaisa tha waisa rahega (memory). Dono ek saath dabana galat hai: NOR latch mein dono outputs 0 ho jaate hain (Q aur Q' barabar — rule tootta hai), aur dono ek saath chhodo toh race hoti hai, result unpredictable. NAND latch active-LOW hota hai — wahan 0 dabane ka matlab hai, aur 00 forbidden hai.

NOR: S R = 00 hold · 10 set · 01 reset · 11 forbidden (Q = Q' = 0)
NAND (active-low): 11 hold · 00 forbidden (Q = Q' = 1)
Characteristic equation: Q⁺ = S + R'Q, with SR = 0
Yaad rakho: NOR latch: 11 forbidden. NAND latch: 00 forbidden.

5.3 D latch (level-triggered)

A D latch is a gated latch with one data input D and an enable EN: while EN = 1 it is transparent (Q follows D); while EN = 0 it holds the last value. It is level-triggered.
  • Built as S = D·EN, R = D'·EN → S and R can never both be 1, so no forbidden state.
  • Glitches on D pass to Q while EN = 1 → unsafe for pipelines.
Q⁺ = EN·D + EN'·Q
Yaad rakho: latch = level (window open), flip-flop = edge (camera click).

5.4 D flip-flop (edge-triggered)

A D flip-flop is an edge-triggered memory element that copies its D input to Q only at the active clock edge (usually rising) and holds Q constant at all other times.

Hinglish: Latch khidki jaisa hai — jab tak khuli hai (EN = 1) bahar ka sab andar dikhta hai. Flip-flop camera jaisa hai — sirf click (clock edge) ke instant ki photo leta hai, beech mein kuch bhi ho, Q nahi badalta. Andar se flip-flop do latches ka bana hota hai (master–slave): ek ki khidki khuli toh doosre ki band, isliye data sirf edge pe hi aage jaata hai. Waveform mein har rising edge pe line kheencho, wahan D ki value padho, aur agle edge tak wahi Q rakho.

At the rising edge: Q⁺ = D. Verilog: always @(posedge clk) q <= d;
Master–slave: two D latches on opposite clock phases. Master open when CLK = 0 → Q changes at the RISING edge (class slide version: master open at CLK = 1 → falling edge).
Clock frequency f = 1/T; ring oscillator (odd number N of inverters) T = 2·N·t_pd.
Yaad rakho: FF = 2 latches, ≈ 2× gates, edge-triggered, used for every register and pipeline stage.

5.5 Setup time, hold time, metastability

Setup time is the minimum time the D input must be stable BEFORE the clock edge; hold time is the minimum time it must stay stable AFTER the edge; clock-to-Q delay (t_pcq) is the time from the edge until Q is valid. Metastability is the state in which a flip-flop's output stays between 0 and 1 for an unpredictable time because setup or hold was violated.

Hinglish: Photo khinchte waqt object ko click se thoda pehle (setup) aur thoda baad (hold) tak hilna nahi chahiye, warna photo blur. Waise hi D ko edge ke aas-paas stable rehna chahiye. Clock kitna fast ho sakta hai: data ko pehle flip-flop se nikalna hai (t_pcq), logic se guzarna hai (t_pd), aur agle edge se setup time pehle pahunchna hai — teeno ka sum hi minimum clock period hai. Hold violation clock slow karke theek nahi hota, short path mein delay daalna padta hai. Metastability ko poori tarah hata nahi sakte, sirf 2–3 flip-flop synchronizer se bahut rare kar sakte hain.

T_c ≥ t_pcq + t_pd + t_setup → f_max = 1 / T_c
Hold: t_ccq + t_cd ≥ t_hold (independent of the clock)
Example: 0.28 ns path + 0.05 ns setup → T = 0.33 ns → f = 1/0.33 ns ≈ 3.03 GHz (1/ns = 1 GHz)
Yaad rakho: setup = before, hold = after. Slow clock fixes setup, NOT hold. Metastability → synchronizer.

5.E1 JK and T flip-flops

A JK flip-flop is like SR but J = K = 1 toggles the output. A T (toggle) flip-flop toggles when T = 1 and holds when T = 0.
JK: 00 hold, 01 reset, 10 set, 11 toggle → Q⁺ = JQ' + K'Q
T: Q⁺ = T ⊕ Q. T from D: D = T ⊕ Q. T from JK: J = K = T.
Excitation: D = Q⁺, T = Q ⊕ Q⁺ (1 when the bit must change).
Yaad rakho: SR Q⁺ = S + R'Q · D Q⁺ = D · JK Q⁺ = JQ' + K'Q · T Q⁺ = T ⊕ Q.

Unit 6 · Registers, Counters & Shift Registers

6.1 From flip-flops to registers

A register is a group of n flip-flops sharing a common clock that stores an n-bit word, all bits being loaded at the same clock edge.
  • n-bit register = n D flip-flops + one common clock.
  • PC, IR, general registers, pipeline registers — all registers.

6.2 Load enable & reset

Load enable lets a register either load new data or keep its value at a clock edge, using a 2:1 MUX in front of each flip-flop. Reset forces the register to a known value (0): synchronous reset acts at the clock edge, asynchronous reset acts immediately.
Q⁺ = LOAD·D + LOAD'·Q (LOAD = 0 feeds Q back → hold). Priority in labs: reset > load > hold.
Yaad rakho: never gate the clock with LOAD (glitches, skew). Use the MUX.

6.3 Ripple (asynchronous) vs synchronous counters

A counter is a sequential circuit that goes through a fixed sequence of states (usually binary counting) on successive clock pulses. In a ripple counter only the first flip-flop gets the clock and each next one is clocked by the previous output; in a synchronous counter all flip-flops share the same clock.

Hinglish: Binary counting dekho: koi bhi bit tab badalti hai jab uske neeche ke saare bits 1 hon (0111 → 1000). Ripple counter mein domino ki tarah ek ke baad ek bit girti hai, isliye time lagta hai (n × t_pd) aur beech mein galat values dikhti hain: 7 → 6 → 4 → 0 → 8. Synchronous counter mein sab bits ek saath, ek hi clock pe badalti hain — fast aur glitch-free, bas thode AND gates extra lagte hain.

Ripple delay = n × t_pd, f_max = 1 / (n × t_pd)
Bit k frequency = f / 2^(k+1) (Q0 = f/2, Q1 = f/4)
Example: 4-bit, t_pd = 10 ns → 40 ns → f = 1000/40 MHz = 25 MHz
RippleSynchronous
ClockFF0 onlyshared
Speedslow (n·t_pd)fast
Glitchesyesno
Hardwarelessmore (AND gates)
Yaad rakho: ripple = dominoes, synchronous = soldiers marching together.

6.4 4-bit synchronous up-counter design

A synchronous up-counter is designed by writing its state table, finding each flip-flop input from the excitation table, and minimising with K-maps.
T flip-flops: T0 = 1, T1 = Q0, T2 = Q0·Q1, T3 = Q0·Q1·Q2
D flip-flops: D0 = Q0', D1 = Q1 ⊕ Q0, D2 = Q2 ⊕ Q1Q0
Down counter: T1 = Q0', T2 = Q0'Q1'
Flip-flops for mod-N = ⌈log₂ N⌉ = smallest k with 2ᵏ ≥ N (mod-12 → 4, mod-1000 → 10)

Trick: “a bit flips when everything below it is 1”.

Yaad rakho: T-chain = AND of all lower Q's.

6.5 Shift registers: SISO, SIPO, PISO, PIPO

A shift register is a chain of flip-flops on a common clock in which each flip-flop's output feeds the next one's input, so the stored bits move one position per clock pulse.
TypeIn → OutUse
SISOserial → serialdelay line

Yaad rakho: receive = SIPO, transmit = PISO.

6.E1 Ring, Johnson, mod-N, LFSR

A ring counter is a shift register whose last output feeds the first input (one circulating 1). A Johnson counter feeds back the complement of the last output. An LFSR feeds back the XOR of selected bits to generate pseudo-random sequences.
Ring: n states · Johnson: 2n states (unused 2ⁿ − 2n) · LFSR (maximal): 2ⁿ − 1 states · binary: 2ⁿ
Yaad rakho: 4-bit ring 4 states, Johnson 8, binary 16, LFSR 15.

Unit 7 · Register Files & Finite State Machines

7.1 From registers to register files

A register file is an array of registers inside the CPU with address-based access, allowing several registers to be read and one to be written in the same clock cycle.
  • Need: add R1, R2, R3 reads 2 and writes 1 register in one cycle.
  • MIPS/RISC-V: 32 registers × 32 bits, 2 read ports + 1 write port.
Address bits = log₂(number of registers) (32 → 5) · flip-flops = registers × width (16 × 8 = 128)

7.2 Register file architecture (1 write, 2 read)

The write port of a register file uses a decoder plus a write-enable signal so that exactly one register is loaded at the clock edge; each read port is a multiplexer that selects one register's contents using the read address.

Hinglish: Likhne ke liye: 5-bit address decoder mein jaata hai, decoder 32 mein se sirf ek line ON karta hai (kaunsa register), aur RegWrite batata hai likhna hai ya nahi — dono ka AND us register ka load enable hai. Padhne ke liye: har register ka output do bade 32:1 MUX mein jaata hai, address MUX ka select hai. Read ke liye clock ki zarurat nahi (combinational, turant), write sirf clock edge pe (synchronous) — isse ek hi cycle mein purani value padh ke nayi likh sakte hain.

  • Write: decoder picks WHERE, RegWrite picks WHETHER.
  • Read: two 32:1 MUXes, combinational (no clock); write: synchronous.
  • Register 0 ($zero / x0) always reads 0, writes ignored.
Yaad rakho: read = MUX = combinational; write = decoder + WE = clocked.

7.3 Finite state machines (FSM)

A finite state machine is a sequential circuit with a finite number of states that moves from one state to another according to its inputs and produces outputs; formally (S, I, O, δ, λ) where δ is the next-state (transition) function and λ the output function.
  • Hardware: next-state logic → state register (flip-flops) → output logic, with feedback.
  • Examples: traffic light, vending machine, the CPU control unit.
  • Design steps: spec → state diagram → state table → encode → equations → circuit.
Flip-flops: binary encoding ⌈log₂ N⌉, one-hot N
Yaad rakho: FSM = states + inputs + transitions + outputs; δ = next state, λ = output.

7.4 Moore vs Mealy

In a Moore machine the outputs depend only on the present state; in a Mealy machine the outputs depend on the present state and the present inputs.

7.5 Sequence detector 1011

A sequence detector is an FSM that outputs 1 when a specific bit pattern has appeared in its serial input. With overlap, the end of one match may start the next; without overlap, the machine restarts after a match.

Hinglish: Har state yaad rakhti hai ki ab tak pattern ka kitna hissa match hua: S0 = kuch nahi, S1 = “1”, S2 = “10”, S3 = “101”. Galat bit aaye toh S0 pe mat jao — dekho ki ab tak ke input ka aakhri hissa pattern ki shuruaat se kitna milta hai. Jaise S3 (“101”) pe 0 aaya → “1010” → aakhir mein “10” bacha → S2. Match hone pe overlap allowed ho toh aakhri “1” ko reuse karo (S1), nahi toh S0. Moore mein output ke liye ek extra state S4 lagti hai, isliye Moore = 5 states, Mealy = 4.

Mealy: S3 —1/1→ S1 (overlap) or S0 (no overlap). 4 states → 2 FFs.
Moore: S4 (out 1); S4 —1→ S1, —0→ S2 (overlap) or S0 (no overlap). 5 states → 3 FFs (5 one-hot).
Stream 10110110: overlap → 2 matches; no overlap → 1 match.
Yaad rakho: never jump to S0 after a match when overlap is allowed.

Unit 8 · SRAM vs DRAM & the Memory Stack

8.1 Why we need bigger memory

Register files are fast but tiny because each bit uses a flip-flop (20+ transistors); larger memories use denser cells — SRAM and DRAM — trading speed for capacity.
Yaad rakho: fast memory is small and expensive; big memory is slow and cheap.

8.2 SRAM — the 6T cell

SRAM (Static RAM) stores each bit in a bistable latch of two cross-coupled inverters (4 transistors) plus two access transistors — a 6-transistor cell — and keeps the data without refresh as long as power is on.
  • Word line (WL) selects the cell; bit lines BL and BL' carry data and its complement.
  • Read: precharge both bit lines, raise WL, sense amplifier detects which line drops — non-destructive.
  • Write: drive bit lines, raise WL, drivers overpower the latch.
  • Fast (few ns), low density, expensive → caches, register files.
Yaad rakho: 6T = 4 (latch) + 2 (access). Static = no refresh.

8.3 DRAM — 1T1C cell, refresh, destructive read

DRAM (Dynamic RAM) stores each bit as charge on a capacitor accessed through one transistor (1T1C); because the charge leaks, every row must be periodically refreshed, and a read drains the capacitor so the value must be written back.

Hinglish: DRAM mein bit ek chhote capacitor mein charge ki tarah rehta hai — charge hai toh 1, nahi toh 0. Capacitor dheere-dheere leak hota hai (lagbhag 64 ms mein data khatam), isliye controller har row ko baar-baar padh ke wapas likhta hai — isi ko refresh kehte hain, aur isi wajah se naam “dynamic”. Padhte waqt capacitor ka charge bit line mein bant jaata hai, toh value mit jaati hai (destructive read) — sense amplifier usse pehchaan ke turant wapas likhta hai. Sirf 1 transistor + 1 capacitor, isliye SRAM se ~6 guna dense aur sasta.

Refresh: every row about every 64 ms. Per-row interval = retention time ÷ rows
Example: 64 ms ÷ 8192 rows = 0.0078125 ms = 7.8 µs
Yaad rakho: DRAM = 1T1C, refresh, destructive read, 50–100 ns, main memory.

8.4 SRAM vs DRAM

SRAM vs DRAM: SRAM stores a bit actively in a 6-transistor latch (fast, no refresh, low density), while DRAM stores it passively as charge on a 1T1C cell (slower, needs refresh, high density and cheap).

8.5 Memory hierarchy & the memory wall

The memory hierarchy arranges storage in levels — registers, caches, main memory, disk — from small/fast/expensive to large/slow/cheap, exploiting locality so most accesses hit the fast levels. The memory wall is the growing gap between processor speed and memory (DRAM) latency.
  • Order: registers < L1 < L2 < L3 < DRAM < SSD < HDD (fastest → slowest).
  • Temporal locality: recently used data is used again soon. Spatial locality: nearby data is used soon.
  • Memory wall: CPU speed grew ~50 %/yr, DRAM latency only ~7 %/yr.
AMAT = hit time + miss rate × miss penalty · Example 1 + 0.05 × 80 = 5 ns

Unit 9 · Von Neumann vs Harvard

9.1 From gates to a complete machine

A complete computer consists of a CPU (compute), memory (store), I/O (communicate) and a bus (address, data and control lines) connecting them; computer organisation decides how they are connected.

9.2 Von Neumann architecture

The Von Neumann (stored-program) architecture keeps program instructions and data in the same memory and moves both over a single shared bus between memory and CPU. Described by John von Neumann in the “First Draft of a Report on the EDVAC” (1945).
  • Four classic components: control unit, memory, ALU, I/O.
  • Stored-program concept: programs are data — change the program by loading new numbers (enables compilers, loaders, JIT; also security risks).
  • Won because of simplicity and generality.

9.3 The Von Neumann bottleneck

The Von Neumann bottleneck (term by John Backus, 1977) is the limit on performance caused by instructions and data sharing one bus, so an instruction fetch and a data access cannot happen at the same time.

Hinglish: Ek hi sadak (bus) pe instructions aur data dono chalte hain, toh ek waqt mein ek hi ja sakta hai — ya instruction lao ya data. CPU bahut tez hai par sadak utni tez nahi, isliye CPU wait karta rehta hai. Solution: cache, chaudi/tez bus, ya Harvard jaisa alag rasta.

Bandwidth = bits per cycle × clock frequency ÷ 8 (bytes/s)
Example: 1 GHz, 32-bit instr + 32-bit data → 64 × 10⁹ bits/s ÷ 8 = 8 GB/s

9.4 Harvard architecture

The Harvard architecture uses physically separate memories and buses for instructions and data, so an instruction fetch and a data access can happen in the same cycle. Named after the Harvard Mark I (1944).

9.5 Modified Harvard

A modified Harvard architecture has split instruction and data caches (L1-I, L1-D) inside the chip but a single unified main memory outside — Harvard speed inside, Von Neumann flexibility outside. Used by almost all modern CPUs (x86-64, ARM Cortex-M4).
Yaad rakho: VN = one bus; Harvard = two; modern = split L1 only.

Unit 10 · CISC vs RISC

10.1 Recap and setup

Units 9 → 10: after deciding how the CPU connects to memory, the next question is what instructions it understands — the ISA.

The Instruction Set Architecture (ISA) is the set of instructions, registers and memory model visible to the programmer — the contract between software (which compiles to it) and hardware (which executes it).

10.2 RISC vs CISC

CISC (Complex Instruction Set Computer) provides many powerful, variable-length instructions that can operate directly on memory. RISC (Reduced Instruction Set Computer) provides a small set of simple, fixed-length instructions in which only load and store access memory.

Yaad rakho: RISC hallmarks = fixed length + load/store.

10.3 Historical context

The ISA family tree shows how instruction sets evolved along two lineages: the CISC line (VAX, 68000, x86 → x86-64) and the RISC line (IBM 801 → MIPS, SPARC, ARM, RISC-V).
  • CISC: VAX (1977), 68000 (1979), x86 (1978) → x86-64 (2003).
  • RISC: IBM 801 → MIPS (Stanford, Hennessy, 1984), SPARC, ARM (1985), RISC-V (Berkeley, 2010).
  • ARM won mobile (low power, licensing); x86 kept the desktop (compatibility).

10.4 Compiler implications & code density

Code density is how much work a program does per byte of instructions; CISC has higher code density, RISC is easier to pipeline.
  • RISC pipelines well: fixed length, uniform decode, one simple step each, only lw/sw touch memory.
  • ARM Thumb and RISC-V “C” (16-bit) improve RISC code density.
CPU time = Instruction count × CPI × clock period (iron law)

10.5 Micro-ops in x86

Micro-operations (µops) are simple RISC-like internal operations into which a modern x86 decoder splits each complex CISC instruction before executing them on a RISC-style pipelined core.

Hinglish: x86 bahar se CISC hai (purane software chalane ke liye), par andar se RISC jaisa. Decoder ek bada instruction, jaise add [mem], eax, ko teen chhote kaam mein todta hai — load, add, store — aur phir unhe RISC ki tarah pipeline mein chalata hai. Isliye kehte hain “CISC outside, RISC inside”.

10.6 Trends — RISC-V & AI ISAs

A domain-specific ISA is an instruction set designed for one class of workload (e.g. graphics or neural networks), trading generality for much higher efficiency.
  • RISC-V: open, royalty-free, modular (base + extensions), Berkeley 2010.
  • Domain-specific ISAs: NVIDIA PTX (GPUs), Google TPU (matrix multiply).
Yaad rakho: “RISC runs fewer instructions” is FALSE — it runs more, but each is simpler.

MIPS (Microprocessor without Interlocked Pipeline Stages) is a classic RISC ISA from Stanford (1984) with 32 registers and fixed 32-bit instructions in three formats, widely used for teaching.

Clean fixed 32-bit design with only 3 formats, MARS simulator, Patterson & Hennessy textbook, skills transfer to RISC-V/ARM. Used in PlayStation 1, N64, PS2.

RISC-V is an open, royalty-free RISC ISA built as a small base (RV32I, ~40 instructions, x0–x31) plus optional standard extensions.
Formats R, I, S, B, U, J · Extensions M multiply, A atomic, F float, D double, C compressed, V vector (e.g. RV32IMAFD)

11.E1 Assembly toolkit (Lab 11)

An assembler directive (.data, .text, .word, .asciiz) instructs the assembler how to lay out the program; a pseudo-instruction (li, la, move, blt) is a convenience the assembler expands into real instructions; a syscall asks the operating system for a service (print, read, exit) chosen by the code in $v0.
  • syscall: 1 print int, 4 print string, 5 read int, 10 exit, 11 print char (put code in $v0).
  • div → LO = quotient, HI = remainder (mflo, mfhi). mult → HI:LO.
  • la loads an address, lw loads a value. lw/sw addresses must be multiples of 4.
  • Pseudo-ops: li, la, move, blt, bge, nop. srl fills 0s, sra copies the sign bit.
  • Endianness of 0x12345678: big-endian first byte 12, little-endian first byte 78.

Unit 12 · C to MIPS Translation

12.1 Translation pattern

Translating C to MIPS means mapping variables to registers, conditions to compare-and-branch instructions, and control structures (if, loops, functions) to labelled blocks connected by branches and jumps.
  • Variables → registers. Conditions → slt + beq/bne. Structure → labels.
  • Reverse the condition: branch AWAY from the body when the test fails.
  • Array: address of A[i] = base + 4 × i.

12.2 if / else

A conditional branch (beq, bne) changes the program counter to a label only if its condition is true; otherwise execution continues with the next instruction. An if/else is translated with one conditional branch and one unconditional jump.

Hinglish: MIPS mein sirf beq (barabar) aur bne (barabar nahi) hote hain. “Agar a == b toh body chalao” ko aise likhte hain: “agar a != b toh body ko skip karo” (bne). Isko condition ulta karna kehte hain. Chhota-bada check karna ho toh pehle slt se flag banao (a < b ho toh 1) phir flag ko $zero se compare karo. a > b ke liye operands ulte kar do: slt t, b, a. if/else mein if-block ke end mein “j Done” zaroori hai warna else-block bhi chal jayega.

    bne  $t0, $t1, Else    # if (a == b)
    li   $t2, 1            #   c = 1
    j    Done              # skip the else part
Else: li $t2, 0            # else c = 0
Done:
Yaad rakho: a > b → slt t, b, a. Always end the if-block with j Done.

12.3 Loops

A loop in assembly is a labelled block that tests a condition, executes its body, updates the loop variable and jumps back to the label until the condition fails.
Loop: bge  $t0, $t1, End   # while (i < n): leave when i >= n
      add  $s0, $s0, $t0   #   sum += i
      addi $t0, $t0, 1     #   i++
      j    Loop
End:
Yaad rakho: init → test (branch out) → body → increment → jump back. (The class slide's blt $t1,$t0 version runs one extra time.)

12.4 Calling convention

The calling convention is the agreed set of rules for function calls: arguments in $a0–$a3, return values in $v0–$v1, the return address in $ra set by jal, and return with jr $ra.
jal Label: $ra ← PC + 4, then jump · jr $ra: return

12.5 Stack frames — leaf vs non-leaf

A stack frame is the block of stack memory a function allocates to save registers and local data. A leaf function calls no other function; a non-leaf function calls others and must save $ra (and any needed $a/$s registers) on the stack.

Hinglish: Stack neeche ki taraf badhta hai — jagah banane ke liye $sp ghatao (addi $sp, $sp, −8), wapas dene ke liye badhao. Jo function khud kisi aur ko call karta hai, uska $ra jal se overwrite ho jaata hai, isliye pehle $ra stack pe save karo. Recursive factorial mein har call apna $ra aur n save karta hai; fact(3) mein 3 frames bante hain, phir ulte order mein khulte hain: 1 → 2 × 1 = 2 → 3 × 2 = 6.

Push: addi $sp, $sp, -8; sw $ra, 4($sp); sw $a0, 0($sp) · Pop: lw back, addi $sp, $sp, 8
fact(n) peak stack = n frames × 8 bytes (fact(3) = 24 bytes)
Yaad rakho: stack grows DOWN. Non-leaf must save $ra. Keep the stack balanced.

Unit 13 · Single-Cycle MIPS Datapath

13.1 ISA → hardware

The datapath is the hardware that stores and processes data (PC, memories, register file, ALU, MUXes); the control unit generates the signals that tell the datapath what to do for each instruction. In a single-cycle design each instruction completes in one clock cycle.
  • CPI = 1, but clock period = slowest instruction (lw).
  • Separate instruction and data memories, because each unit is used once per cycle.

13.2 Fetch–decode–execute cycle

The instruction cycle is the repeated sequence a CPU follows for every instruction: fetch it from memory, decode it and read registers, execute it in the ALU, access memory if needed, and write back the result.
Fetch: IR ← Mem[PC], PC ← PC + 4 · add skips Memory · sw skips Write-back · beq may change the PC

13.3 Building the datapath

The single-cycle datapath connects the PC, instruction memory, register file, sign-extender, ALU, data memory and multiplexers so that every instruction type (R-type, lw, sw, beq) can use the parts it needs; the main control unit decodes the opcode into control signals and the ALU control uses ALUOp and funct to select the ALU operation.

Hinglish: Instruction ke bits alag-alag jagah jaate hain: [31-26] opcode → Control; [25-21] rs → Read reg 1; [20-16] rt → Read reg 2; [15-11] rd → RegDst MUX; [15-0] → sign extend. Chaar MUX yaad karo: RegDst (rt ya rd — kis register mein likhna), ALUSrc (register ya immediate — ALU ka doosra input), MemtoReg (ALU result ya memory data — register mein kya likhna), PCSrc (PC + 4 ya branch target). Branch tabhi hota hai jab Branch = 1 AND ALU ka Zero = 1.

13.4 Tracing instructions

Tracing an instruction means marking the path its data takes through the datapath and writing the value of every control signal for it.
  • Step 1 fetch path → step 2 follow the fields → step 3 mark the MUX inputs used → step 4 fill the control row.
  • Never leave ALUOp blank (lw/sw 00, beq 01, R-type 10).

13.5 Critical path & clock period

The critical path is the longest delay path through the circuit between two clock edges; it sets the minimum clock period. In the single-cycle datapath it is the path of lw.
lw = IMem + Reg read + ALU + DMem + Reg write = 200 + 100 + 200 + 200 + 100 = 800 ps (P&H)
sw 700 · R-type 600 · beq 500 · j 200 → clock = 800 ps = 1.25 GHz
Yaad rakho: lw is the slowest → it decides the single-cycle clock.

Unit 14 · Pipelining (shorter — no class slides)

14.1–14.2 The idea

Pipelining is a technique in which the execution of an instruction is divided into stages and several instructions are overlapped, each in a different stage, so that one instruction can complete every clock cycle.

Hinglish: Laundry socho — ek load dhul raha ho toh doosra dryer mein, teesra fold ho raha. Har load ka time utna hi hai (latency same), par har 30 minute mein ek load ready (throughput badha). CPU mein bhi ek instruction fetch ho rahi hoti hai, doosri decode, teesri execute.

14.3–14.6 Five stages, diagrams, speedup, hazards

A pipeline register is a register placed between two pipeline stages that holds everything one stage produced (data, register numbers, control signals) for the next stage. Throughput is instructions completed per unit time; latency is the time for one instruction to pass through all stages.
  • Stages IF, ID, EX, MEM, WB; pipeline registers IF/ID, ID/EX, EX/MEM, MEM/WB.
  • Pipeline diagram: rows = instructions, columns = clock cycles.
  • Hazards: structural, data, control (Unit 15).
Cycles = k + (n − 1) · Speedup = n·k ÷ (k + n − 1) → k · Clock = slowest stage (+ register overhead)
Example: stages 200/100/200/200/100 ps → clock 200 ps → speedup 800/200 = 4
Yaad rakho: pipelining improves throughput, not latency.

Unit 15 · Pipeline Hazards (shorter — no class slides)

15.1–15.2 Hazard types

A hazard is a situation in which the next instruction cannot execute in its planned clock cycle. Structural: two instructions need the same hardware. Data: an instruction needs a result not yet produced. Control: the next instruction depends on an unresolved branch.
  • RAW (read after write) is the only data hazard in the in-order 5-stage pipeline; WAR and WAW occur only in out-of-order machines.

15.3–15.6 Stalls, forwarding, load-use, scheduling

Stall (bubble): delaying an instruction until its operand is ready. Forwarding (bypassing): sending a result directly from a pipeline register to the ALU input of a later instruction instead of waiting for write-back.

Hinglish: Bina forwarding, agla instruction tab tak ruka rahega jab tak result register mein likha na jaaye — 2 cycle ka wait. Forwarding mein result seedha EX/MEM ya MEM/WB register se ALU tak bhej dete hain, toh wait nahi. Sirf load ke turant baad use karne pe (load-use) 1 cycle rukna padta hai, kyunki memory se data MEM stage ke end mein aata hai. Compiler instructions ka order badal ke ye stall bhi hata sakta hai.

No forwarding: dependent next instruction → 2 stalls · Forwarding: ALU → ALU 0 stalls · Load-use: 1 stall
Paths: EX/MEM → EX, MEM/WB → EX · Scheduling example: 13 cycles → 11 cycles
Yaad rakho: 2 / 0 / 1 — stalls without forwarding / with forwarding / load-use.
